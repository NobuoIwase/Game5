# 依頼書：拘束された姿勢の汎用モーション（Codex / GPT 向け）

作成：Claude（2026-09-26、v3）。参考資料は `references/restraint-v1/`（一覧は同フォルダの README、全モーションの一覧ページは `references/index.html`）。

## 1. 目的

捕まって手足を拘束されたキャラクターの姿勢と動き。アリアだけでなく**ほかのキャラクターにも使う汎用モーション**なので、骨格（関節の3D座標）で姿勢を決めてある。各キャラクターの原画・部位を、この骨格に沿って描いてほしい。

- **向き**：拘束中は正面（こちら）を向く。前屈みの姿勢（`bent_over`）だけは斜め後ろ（`up_right`）または真後ろ（`back`）から見せる。各モーションの向きは `motions.<id>.view` にある。
- **服装**：キャラクターごとの衣装のまま。剣と盾は持たない（捕まった時点で手放している）。
- **拘束具**：描かない。手首・膝などの拘束はゲームが別に描く。位置は下の `binds`。手首や膝に巻かれた部分の、服や肌のわずかな押されは描いてよい。

- **出力**
  - 各キャラクター・各モーションについて、向きの1方向分のシート `exports/<character>/pose_<id>.png`（横にコマ）
  - 個別コマ
  - `exports/manifest.json` への追記：`frame_ms` の配列、`loop`、`view`
- **コマの大きさ**：攻撃モーションと同じ **576×576 px、透過**。足裏の基準点は `feet_anchor [288,470]`。体の大きさは歩きのシートと同じ。

- **使い回し**：ほかのコマと同じ絵で済むコマ、顔や頭だけ描き替えればよいコマは `REUSE_LIST.md`（機械が読む版は `motion/reuse.json`）にまとめてある。「同じ絵」のコマは描かずに元のコマを使い、「顔だけ」「頭だけ」はその部分だけ描き替える。

## 3. 骨格データ

`motion/restraint-poses.json`（生成元は `motion/restraint.mjs`、再生成は `node tools/render_restraint_svg.mjs`）。

- 形式・キャンバス（288×288、中心 x=144）・投影式は `motion/attack-poses.json` と同じ。576×576 のコマでは座標を2倍する。
- `poses.<id>.<direction>[frame]` の中身
  - `joints`：各関節の `position`・`depth`・`world`
  - `phase`：コマの狙い
  - `binds`：拘束の位置
- 追加の点
  - `face`：頭の中心から見ている方向へ9pxの点
  - `eye_left` / `eye_right`：両目の位置。頭を反らせても左右に並ぶ
  - `crotch`：腰のすぐ下。図の赤い点線は、この点の動きの軌跡
- **拘束 `binds`**
  - `joint` と `joint2`：2つの関節をまとめて縛る帯（後ろ手の両手首など）
  - `joint` と `anchor`：関節をその点の方へ引く拘束（上から吊る手首、左右へ引く膝など）

  `anchor` は `joints` の中の点を指す。

## 4. 部位ごとの描き方

1. **顔・上半身は正面**：身をよじっても、顔と肩は正面から大きく外さない。顔をそむけるのは首から上だけ。
2. **膝を閉じた姿勢**：膝どうしが触れ、足先はハの字に離れ、爪先はやや内向き。**脚を交差させない**（膝は触れる程度で重ならない）。
3. **脚を開かれた姿勢**：膝が爪先と同じ外向きに開き、腰が低く落ちる。`legs_pulled_open` の流れは次のとおり。
   - 膝をいったん強く閉じて抵抗する（1〜2コマ目）
   - 膝から左右へ引き開かれ、足が外へ滑る（3〜7コマ目）
   - 閉じようとして（9コマ目）、また引き開かれる（10コマ目）
4. **振りほどこうとする**：
   - `arms_behind_wrench`：肩を左右交互にひねり、胸を張り、押す側の爪先で伸び上がる。力を抜いて息をつく間もある。
   - `elbows_up_strain`：肘を曲げて前腕を立てたまま、片腕ずつ引き下ろそうと力む。力むと背を丸めて膝を曲げ、拘束に引き戻されると爪先立ちになる。
5. **腰の前後の揺れ**（`hip_rock_*`）：
   - 腰が前へ出るときは肩が後ろへ、腰が引くときは胸が前へ出る（上体は腰と逆向きに動く）
   - 頭は少し遅れてついてくる
   - 膝を閉じた版は揺れが小さく、前へ出るたびに爪先立ちになる
6. **上下の揺れ**（`bounce_*`）：
   - 下では膝が曲がって体重が落ち、上では爪先立ちになる
   - 頭と胸は少し遅れてついてくる
   - 手首を吊られた版は、沈むたびに腕が伸びる
7. **こわばりと脱力**：
   - `tension_tiptoe`：踵が上がる→脚が伸びる→爪先をピンと伸ばして全身が固まる（頂点）→小刻みな震え→力が抜けて膝が折れ、拘束に支えられる
   - `tension_arch`：腰を前へ出しながら背中を大きく反らせ、頭を後ろへ倒す（頂点）→震え→前へ崩れて膝が内に入る
   - 頭を後ろへ倒したときも、両目は左右に並ぶ
8. **脱力のあと**：
   - `afterglow_*`：`tension_*` の最後のコマと同じ姿勢から始まる。
     - 頭を垂れ、肩を上下させて息をつく
     - 6コマ目だけ、体が一度ぴくっと跳ねる（爪先が伸びる）
   - `recover_*`：
     - 顔を上げて我に返る
     - `recover_spread`：膝を閉じようとして、また開かれる
     - `recover_slump`：膝を伸ばして立ち直る
     - 最後のコマは、次の拘束モーション（`legs_held_open`、または手首を吊られて立つ姿勢）の最初のコマにつながる
9. **前屈み**（`bent_over`）：脚を伸ばしたまま上体を前へ倒し、腰を高く後ろへ引く。手首は床の前方に縛られている。腰を左右に揺らし、肩越しに振り返る。
10. **体の後ろにある部位**：後ろ手の手首や腕は、正面から見て胴体の陰に隠れる。胴体の前に描かないこと（骨格の `depth` と、胴体の向きで判断する）。
11. **表情**：`phase` に合わせて変える。抵抗は歯を食いしばる・目をそらす、揺れは困った顔で口が開く、こわばりの頂点は目を固く閉じて口を開く、脱力は焦点の合わない目。
12. **髪・服の揺れ**：体の上下・前後の動きより1〜2コマ遅れて揺れる。
13. **痛み・流血の表現はしない**。
14. **脚を交差させない**：どのコマでも、左右の膝は触れる程度まで。骨格データは膝どうしが8px（576pxのコマでは16px）より近づかないようにしてある。

## 5. つなぎ

モーション同士（拘束 → 絶頂 → 余韻 → 回復、拘束 → 振りほどき など）をつなぐ短いコマは、`SCENE_MOTION_REQUEST.md` の5章にまとめてある。ループするモーションには0コマ目から入り、0コマ目で抜ける。

## 6. 受け入れの確認

- [ ] 16モーションそれぞれ、向きの1方向分のシートがある（576×576・透過）
- [ ] 足裏が `feet_anchor` にあり、体の大きさが歩きのシートと同じ
- [ ] 正面向きのモーションで、顔と上半身がこちらを向いている
- [ ] 膝を閉じた姿勢で脚が交差していない。開いた姿勢では膝が爪先と同じ向きに開いている
- [ ] 骨格データの腰・膝・足首・爪先・頭の位置に沿っている（爪先立ち・爪先を伸ばすコマを含む）
- [ ] 拘束の位置（`binds`）に手首・膝が来ている
- [ ] 体の後ろにある腕が胴体の前に出ていない
- [ ] ループは最後のコマから最初のコマへ自然につながる
- [ ] 痛み・流血の表現がない
