# GAME5 — v0.27.0

戦乙女リアルタイム・コマンドRPG。ヒロインは直接操作せず、自律探索・自律戦闘する。プレイヤーは敵側ディレクターとして罠・環境干渉を配置できる。

現在のパイロット版は `game/`。

## ⚠ ChatGPT（および他のAI）への作業ルール — 必ず最初に読むこと

> 画像素材は、今後は**ローカルの Claude（デスクトップアプリ）がチャット版 ChatGPT を操作して作る**。手順は `LOCAL_CLAUDE_GUIDE.md`、検品は `python3 tools/check_final.py`、見本の画像は `game/asset-refs/png/`（`node tools/export_ref_png.js` で再出力）。

このリポジトリのコードは Claude Code が管理している。ChatGPT がコードや設定を書き換えると、ほぼ毎回ゲームが起動しなくなっている（v0.16.1 と v0.18.0〜v0.18.1 で実際に起きた）。**ChatGPT の担当は素材づくりだけ**とし、以下を守ること。

### ChatGPT の担当（2026-09-26〜）: 設定を書き溜める

画像はローカルの Claude が NovelAI で作る（`LOCAL_CLAUDE_GUIDE.md`）。**ChatGPT は画像もコードも作らない**。
ChatGPT の仕事は、世界観・区画・魔物の生態・台詞などの**設定を `lore/` に書き溜めること**。書き方は `lore/README.md`。Claude Code がそこから新しい魔物・区画・台詞をゲームに起こす。

### 触ってよいもの

`lore/` と `game/assets/requested/` の中だけ。

- `lore/` の Markdown の追加・追記（`lore/README.md` のルールに従う）
- `species.json`（新モンスター）、`dialogues.json`（台詞）、`room_ideas.json`（区画の一言）の追加・編集
- `manifest.json` の `monsters` / `floors` / `species` の項目の追加（既存のキーは消さない）
- 連絡メモ `game/assets/requested/NOTES_FROM_CHATGPT.md` に、何を追加したかを書く

届いた素材の組み込み・バグ修正・README 更新は Claude Code が行う。

### 画像の条件

- **画像生成で描いた PNG** にする。SVG をコードで組み立てない
- **縮小・減色しない**。v0.18.0 の画像は魔物1体が約40px・16色まで落とされ、紫の点の集まりにしか見えず使えなかった
- **1体（1個）につき1ファイル**。格子状の1枚画像にまとめない（切り出し位置がずれる）
- **ドット絵にしない**。柔らかい手描きイラストで
- 魔物は 256×256px 以上、宝箱・塔・階段は 128px 以上、アイコンは 64px 以上
- **背景は完全な透過**（アルファ付き PNG）。白・黒の背景や、透過を表す市松模様を絵として描き込まない。地面の影・台座・枠・文字も入れない（床タイルだけは不透明）
- **形・配色・サイズは `game/asset-refs/` の見本（Claude 作成の SVG）に合わせる**。一覧は `game/asset-refs/index.html`、詳しい仕様は `game/asset-refs/README.md`
- 依頼文の雛形は `game/ASSET_REQUESTS.md`

### 文字化けを防ぐ

- 日本語を含むファイルは **UTF-8 のまま** 保存する。変換してからアップロードしない
- 既存のファイルを部分的に書き換えるツールで日本語ファイルを編集しない（v0.16.1 の `ASSET_PACK_v0161.md` と v0.18.1 の README が途中から化けた）

## v0.40.0 — 生きている感じ：足音、汗と吐息、決着の一瞬、逃げる魔物

### 演出（新規 `game/fx-v040.js`）
- **足音**：足が床に着くたびに小さな土ぼこり。水の上では水しぶき、粘液で濡れているときは濡れた足跡が残る
- 石の番兵などの重い魔物は、一歩ごとに土ぼこりが立ち、近くだと画面がわずかに揺れる
- **汗**：SPが35%を切ると、額から汗が飛ぶ
- **吐息**：ヌテラが60以上のとき、口元から桃色の吐息がこぼれる
- **決着の一瞬**：アリアに気づいている最後の魔物を倒すと、一瞬スローになり、白い輪が広がる

### AI
- **弱った魔物は逃げることがある**（新規 `game/ai-v040.js`）：体力が25%を切ると、悲鳴をあげて数秒逃げ、また戻ってくる。悲鳴は遠くまで届き、まだ気づいていない仲間も気づく。誘い茸・石の番兵・女王は逃げない
- **ヒットアンドアウェイの下がる方向**：敵が複数いると、近い敵ほど重く見て全員から離れる方向へ下がる。壁に向かうときは壁沿いに逃げる（挟み撃ちされにくい）

## v0.39.0 — モーションを自然に

### ヒロイン（新規 `game/motion-v039.js`、`game/warrior-motion-extra.js`、`game/warrior-motion.js`）
- **姿勢がパッと切り替わらなくなった**：待機・構え・被弾・回避・痙攣などの姿勢は、直前の姿勢からなめらかに移る。のけぞりや痙攣は速く、構えに入るのはゆっくり
- **構えから斬撃へのつなぎ**：振りかぶりが、直前の腕の角度から始まる
- **歩幅と移動距離が連動**：歩き・走りのコマ送りを実際に進んだ距離で進めるので、足が滑らない。ゆっくり歩くときは足取りもゆっくり
- **体の傾き**：横に走るとき少し前傾し、急に止まると一瞬のけぞる
- **被弾ののけぞり**が、殴られた方向と反対へ押される
- **後ずさり**：ヒットアンドアウェイで下がるとき、敵を向いたまま後ろ向きに歩く（背中を見せない）
- **構えを自然に**：剣の腕が真横に棒のように伸びていたのを、前下へ剣先を向ける形に。軽いステップも踏む
- **待機に気分が出る**：SPが少ないと肩で息をし、ヌテラが高いと膝を寄せて腰をもじもじ動かす。何もないときは、ときどき横を見回す

### 魔物
- 斬られると、アリアと反対側へ押されてひしゃげる
- アリアに気づいた瞬間、びくっと跳ねる
- 近づいてくるとき、アリアの方へ体を傾ける

## v0.38.0 — 拘束の猶予、連続絶頂しやすく、間合い、状態異常を分かりやすく

### 拘束と絶頂（`game/grapple-v026.js` / `game/climax-v037.js` / `game/balance-v012.js`）
- **拘束されてから絶頂するまでの時間を延ばした**（拘束中の責めで上がるヌテラを0.6倍に）。振り払う猶予が増えた
- **快感が下がりにくくなった**（自然減少 8→4.5/秒、減り始めるまで 1.0→2.0秒。エステラ後に残るヌテラ 22〜30→32〜40）
- **連続絶頂しやすくなった**：次の絶頂が「連続」扱いになる間隔を 10→14秒に。拘束中に絶頂が終わった後のヌテラも少し高めに残る
- **拘束中に絶頂しても自動で振りほどかれない**。拘束はエステラの間とその後2.5秒続き、振り払いは最初（0）からやり直し。延長は1回の拘束につき1度だけ
- **即死しにくく**：エステラ1回で失うSPを 18→10 に。SPの自然回復も 6.6→8 に上げた
- 「ドキッ」の連打を修正：好きな魔物が2.5秒以上見えなくなってから再び見えたときだけ、しかも同じ魔物には20秒に1回まで
- 触手・拘束の描画を立体的に：落ち影、グラデーションの胴、ハイライト、吸盤、光の当たったループ。押し倒されているときはループが横たわった身体に沿う

### 間合い（新規 `game/range-v038.js`）
- **魔物の技は、近いほど早く着弾し、威力も上がる**（近距離で詠唱時間が最大15%短く、ダメージが最大20%増。遠いと少し遅くなる）
- **アリアもそれを知っていて、ヒットアンドアウェイで戦う**：斬ったら一歩下がり、近すぎるときはまず間合いを取る。回避・防御・構えは常にこちらより優先

### 状態異常を分かりやすく（新規 `game/status-v038.js`）
- 足元にバッジ：**発情**（ヌテラ40%以上、70%以上で「発情＋」）、**敏感**（セイル30%以上、または絶頂後14秒）、**催眠**、**魅了**
- なった瞬間に頭上へ大きく「発情！」「敏感！」とポップアップし、メッセージ欄にも出る（Game4 はこのセッションから見られなかったので、雰囲気を想像して作った）
- **魔物の技名に、何を起こすかが付く**：〔媚薬〕（ヌテラ）〔敏感化〕（セイル）〔発情〕（ルマネ）〔催眠〕〔魅了〕。例：「まとわり吸着〔媚薬〕」「泡膜包み〔媚薬・敏感化〕」

### そのほか
- **吸着羽虫の吸い付く位置を修正**（胸と陰核の位置をスプライト上で測り直した）。1匹につき1か所
- **死んだ魔物は潰れずに、暗く半透明になって**転がる。倒れている時間も短くした（3.2→1.8秒）
- **魔物同士が呼び合う距離を 200→300 に**（音で気づくイメージ）
- AUTO指揮の強さを調整（配置の間隔：やさしい 9秒／ふつう 7.5秒／きびしい 4秒）
- 拘束中のズームでヒロインが顔窓・メッセージ欄に重ならないようカメラ位置を調整
- `tools/sim.js` に `SIM_SKIP=a.js,b.js`（スクリプトを外して試す）を追加

### バランス（`node tools/sim.js 40`）
- AUTOなし：勝率 65%／AUTO（ふつう）：勝率 35%

## v0.37.0 — 連続絶頂、押し倒し、誘惑のポーズ、欲求の波、死に方

### 絶頂（`game/climax-v037.js`）
- **連続絶頂**
  - エステラが終わって10秒以内に次のエステラが来ると連続になる。「連続絶頂 ×3」と出る
  - 拘束されたままエステラが終わると、ヌテラが下がりきらず、次がすぐ来る
  - 地の文と台詞が回数に合わせて変わる（「三度目。脚が勝手に開いて、がくがくと震えている。」）
- **3回目からはガニ股**になり、脚と腰がガクガク震える
- **痙攣を分かりやすく**
  - エステラ中は、0.5秒ほどごとに全身がびくんと跳ね、画面が揺れ、「びくんっ」と出る
  - これまでエステラ中は「気絶」のモーションが優先され、痙攣の姿勢が一度も表示されていなかったので直した
- **絶頂の後遺症**
  - エステラのたびに、その探索の間だけ最大SPが本来の5%ずつ下がる（最大25%まで）。階を降りるたびに5%戻る
  - 「最大値」は、SP（体力）の上限と解釈して作った
- 好きな魔物へのハートは、その魔物が見えているときだけ出る。目に入った瞬間に「ドキッ」とする

### 拘束（`game/grapple-v026.js`）
- **振り払いは、ヌテラが溜まるほど弱くなり、限界で0になる**。エステラ中は、それまでのもがきが0へ下がっていく
- **押し倒し**
  - 重い魔物（石の番兵・灰冠の粘魔・ワーム・水妖・灰冠の従者・女王）に捕まると押し倒される
  - 横たわって、下敷きのままもがく。ヌテラが高いほど、もがきが弱くなる
  - 魔物の手前に描き直すので、下敷きでも見える
- **キノコ（誘い茸）は動かない**。捕まると、アリアのほうが引き寄せられる
- **影杭は「隙を作るもの」になった**
  - 影の手が足を一瞬つかみ、近くの魔物が気づいて駆け寄ってくる
  - それ自体では拘束しない

### 吸着羽虫（`game/attach-v029.js`）
- 左右の乳首と陰核に、1匹ずつ吸いつく（メッセージ窓に「吸着羽虫が 左の乳首に 吸いついた！」）
- 3か所すべてに吸いつかれると、専用の台詞と称号「三点を吸われて立ち尽くした戦士」
- 吸着羽虫の拘束中も、3か所に吸いついた姿で描く

### 欲求と誘惑（`game/desire-v037.js`）
- **欲求の波は、約30秒の周期でゆっくり上下する**。ヌテラが高いほど上がりやすく、下がりにくい
- 波が高いと正常な判断ができない
  - その場でぼうっと立ちつくす
  - ふらふらと魔物の方へ歩いていく
- **誘惑のポーズ**
  - 立ち止まっているときに、ヌテラ 75% 以上・波が高い・好きや魅了が強い魔物が見えている、のどれかに当たると取る
  - 脚を大きく開き、腰を突き出して揺らす。相手がいればそちらを向く
- **好き・魅了の一覧**を、アリアの状態欄（欲求波の下）に出す
- **霧は毒ではなく、発情（ヌテラ）を上げる**ようにした（名前も「発情の霧」）

### 魔物の死に方（`game/polish-v014.js`）
- 死ぬときに一瞬大きくなって見えていた不具合を直した。死ぬ前だけ、種ごとの大きさを無視して描いていたのが原因
- 攻撃された方向へ、種ごとの転がり方で転がり、止まって3秒ほど倒れたまま、消えていく
  - 粘体: 潰れて滑る
  - 飛ぶもの: 落ちて回る
  - 球: 転がる
  - ワーム: ごろりと転がる
  - 植物: 根元から倒れる
  - 蜘蛛・手: ひっくり返る
  - 番兵: 崩れ落ちる

### バランス（各40戦）
- AUTO なし 80%、AUTO ふつう 33%
- 調整したこと
  - 影杭の隙は短く狭くし、呼ばれた魔物は駆け寄るだけにした
  - AUTO（ふつう）の行動間隔を少し広げた（2.2 → 2.6）

## v0.36.0 — 階段は見つけたら降りられる、魔物の配置を簡単に、魔物の大きさと個性、文章を濃く

### 階段（`game/stairs-v036.js`）
- 区画の魔物を全滅させなくても、**下り階段を見つけたら降りられる**
- 探索を続けるか降りるかは、アリアが2秒ごとに自分で決める
  - **逃げる**: ヌテラ 65% 以上、SP 4割未満、疲労、余韻の最中、魔物2体以上に追われている
  - **残る**: まだ探索が半分未満で、調子がいい（宝箱や経験値のため）。勇気のある日は少し長く
  - **降りる**: 8割ほど探索した、区画に長くいた、魔物がいなくなった
- 残した魔物は置いていく。「区画制圧」の表示は、本当に全滅させたときだけ出る
- 階段の前での報告は、魔物に追われていなければ最後まで言う

### 魔物の配置を簡単に（`game/place-v035.js`）
- 「8 増援召喚」を EN 50 → 30、待ち時間 18秒 → 8秒、同時に6体まで
- 道具ボタンの下に「おまかせ／この区画の魔物」のボタンを並べた。選んでから画面をタップすると、その魔物が置かれる
- 置いた魔物は、気づくまで待ち伏せる（最長25秒。そのあとは彼女を探しに動く）
- **AUTO も魔物を置く**（第1区画から、1区画2体まで）。彼女の進む先に先回りして置く

### 魔物の大きさと個性（`game/swarm-v035.js`）
- 種ごとに大きさを変えた。粘魔・石の番兵・ワームは大きく、羽虫は小さい。同じ種でも1体ずつ少し違う
- **吸着羽虫は群れで出る**（小さな吸着羽虫を連れている）
- **第3区画からは、吸着羽虫の女王が出ることがある**
  - 大きくて遅く、自分ではあまり攻撃しない
  - 羽音で小さな羽虫を呼び寄せる（最大3体）
  - プロファイルの NG（産卵・産み付け）に当たらないよう、「産む」のではなく「呼び寄せる」形にした
- 動き方
  - 羽虫: ジグザグに突進する
  - 蛾: ふらふら飛ぶ
  - 蜘蛛: 走っては止まる
  - 手: 小刻みに素早く這う
  - ワーム: 尺取りのように進む
  - 番兵: どしんどしんと歩く
  - 霊: 漂う
  - 粘体: じわじわ這う

### 文章を濃く（`game/lewd-v035.js`）
- **メッセージ窓に地の文**
  - 拘束中は、特殊攻撃のたびに身体の描写が1行出る
  - 描写は拘束の種類（呑み込み・巻きつき・吸い付き・胞子・鱗粉・凝視・泡・冷気）ごとに違い、回を重ねるほど深くなる
  - エステラは、その拘束のされ方に即して数行で描く（呑まれていれば「跳ねる先がない」）。最後の一行は本人の意地（「……それでも、剣の柄だけは離さなかった。」）
  - ほかに、余韻、ヌテラの段階、濡れて歩く様子も描く

## v0.11.0 — Dungeon / Monster Ecology

v0.11.0 では「1画面の戦闘試験」から「区画を連続攻略するダンジョン」へ拡張した。

- 7区画を自律攻略。敵編成を全滅させると階段を発見し、アリアが自分で階段へ移動して次区画へ進む。
- 部屋ごとに壁・通路・階段・沼・霧・胞子・輪紋・花蜜・夢鱗などの環境差を持つ。

- アリアは距離だけでなく、詠唱中・視界内・phase 2 の脅威を加味して主対象を自動切替する。
- 敵ごとの攻撃学習を種族別に保持。支援敵の攻撃経験が別種族へ混ざらない。

- 拘束・粘霧・輪紋・環境床・照明を実グラフィック層へ統合。
