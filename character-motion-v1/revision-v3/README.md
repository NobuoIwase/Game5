# 参考姿勢から組み直した走行 v3

今回届いた参考ファイルは、1025×1280 pxのJPEG・1フレームでした。GIFの全周期を取得したものではなく、提示された走行姿勢をもとに8コマの周期を組んでいます。

戦士の女性としての体格、顔、衣装と左右非対称の装備を維持。誇張した腰振りや内股、胸の独立した揺れは追加していません。

- 頭と髪を胴から分離し、顔の縦横比と進行方向への視線を保つ。
- 胴は13度の穏やかな前傾。頭まで一枚の絵として潰す処理を止める。
- 肘を曲げて握りを腰～下胸へ上げ、剣を顔・脚から離れた前上方へ保持する。
- 盾は曲げた左前腕へ装着し、形を潰さずに追従。後方では裏面を表示する。
- 脚は着地・圧縮・蹴り出し・空中・反対脚の着地を持つ。足先はすねから分け、正面からの短縮でも靴の形を残す。
- 接地コマは実際の靴底を基準線へ合わせる。ゲーム内の移動速度との同期は別途必要。

## 原画と再出力

人物原画は描き直さず、既存の8方向原画から頭・胴・腕・脚・足先を分けて組み立てています。方向による微小な描き分けの差や、折り畳んだ脚の短縮表現は残ります。左右の全身反転は使っていません。

盾の裏面のみ内蔵画像生成ツールで作成しました。[保存した原画](../art/shield-rear-v3.png)、[生成指示文](../art/shield-rear-v3-prompt.txt)。左右の武器は本人基準の右手・左前腕に固定しています。

再出力: `node motion/export.mjs` → `python generic/render.py` → `node tools/render.mjs warrior` → `python tools/export_previews.py` → `python tools/build_player.py` → `python tools/build_run_v3_review.py`。
