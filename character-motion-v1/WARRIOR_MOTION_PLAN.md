# Warrior motion plan — v0.5.0

Date: 2026-09-23  
Model: GPT-5.6 Sol

## 目的

最初のプレイアブルキャラクターである戦士アリアのモーションを、Game5 の基準品質として完成させる。
以降のキャラクターはこの骨格・支点・検査手順を再利用する。

## 今回確認した既存資産

`walk-graphics-handoff/` の引き継ぎ記録と `character-motion-v1/` を確認した。

歩行で守るべき基準:

- 撫で肩を維持し、首を棒のように延長しない。
- 脚は股関節から運び、前方への下腿伸展 → 踵接地 → 支持 → 蹴り出しを読めるようにする。
- 腕は一本の棒として振らず、上腕の振りに対して肘・手首を遅らせる。
- 斜め方向の頭を全方向で同じ高さへ強制しない。
- 関節の数値が正しくても、シルエット・接地・装備の繋がりを目視確認する。
- 良い方向を直すために全方向へ一括補正をかけない。

戦士素材はすでに8方向に分離されている。

`character-motion-v1/parts/warrior/<direction>/`

主なパーツ:
`body / arm_left / arm_right / leg_left / leg_right / sword / shield / scabbard`

つまり歩行・走行については、元絵から切り抜きをやり直す必要はない。

## 歩行・走行

歩行と走行はすでに汎用骨格へ移植済み。

- walk: 8方向 × 8コマ、120 ms/frame
- run: 8方向 × 8コマ、80 ms/frame
- 汎用素体にも walk/run が存在する。
- `motion/rig.mjs` の run は全方向へ同一の走行力学を投影する。
- 走行には接地、圧縮、蹴り出し、回収、伸展、空中局面がある。
- `motion/test.mjs` が歩行の回帰、脚長、空中局面、着地圧縮、腕の逆振り、体幹前傾を検査する。

v0.5.0 ではゲーム側が読み込んでいるのに使用していなかった `exports/warrior/run.png` を実際の高速移動へ接続する。
低速追跡・音源確認・旋回は walk、高速接近・逃走・回避移動は run を選ぶ。

## 目視検査

`reviews/run-v4-final/warrior-run-all-frames.png` の8方向×8コマを確認。

現時点で次の大きな破綻は見つからない。

- 首が棒状に伸びる
- 頭だけ前方へ滑る
- 膝が逆へ折れる
- 接地脚が突然消える
- 左右方向で全身の向きが反転する
- 空中局面がなく歩行の早回しに見える

ただし静止レビューだけではタイミングの違和感を見落とすため、
`warrior-motion-lab.html` を追加し、戦士と汎用素体を同一フレーム・同一方向で再生、停止、コマ送りできるようにする。

## 攻撃モーション方針

既存の `arm_right.png` は肩から手まで一枚である。
歩行・走行では既存レンダラーが関節情報を使って自然に変形できるが、
攻撃を単純な「肩一軸回転」にすると棒振りに見えやすい。

そのため以下の順で作る。

1. 既存の右腕・剣を肩支点で動かす front 試作を Motion Lab に置く。
2. 肩口、剣の柄、体重移動をコマ送りで検査。
3. 棒振りが目立つ場合は本番攻撃用に
   `upper_arm_right / forearm_right / hand_right / sword`
   へ論理分割し、肩→肘→手首→剣の遅れを作る。
4. front で確定した時間設計を、8方向へ投影して各方向の装備レイヤーだけ調整する。
5. 命中判定フレームと絵の最大速度フレームを一致させる。

通常斬りの基本位相:
予備動作 → 踏み込み → 加速 → 命中 → 振り抜き → 回収。

## 拘束モーション方針

「拘束」を一種類の絵にはしない。
敵の拘束点をデータとして持ち、同じ戦士リグへ適用する。

最低でも:

- 両腕拘束
- 脚拘束
- 胴体巻き付き
- 背後からの拘束
- 体表への付着

Motion Lab の front 試作では両肩と両股関節を別支点で動かし、
「全身を一枚で揺らすだけ」にならないかを先に確認する。

## エステラモーション方針

エステラは一つのループではなく三相へ分ける。

1. onset: 発生。姿勢が崩れ、操作・AI行動を失う。
2. loop: 非対称な短周期収縮。MP漏出とSP低下の時間帯。
3. recovery: 痙攣が収まり、脱力してから姿勢を戻す。

完全な左右対称振動にはしない。
頭・肩・肘・膝の位相を少しずらし、「画像全体を上下に震わせるだけ」を避ける。
