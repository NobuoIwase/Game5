# 歩行素体 03 — 正面・右向き

前版の分割構造と歩行周期を引き継ぎ、首・肩の接続、正面の腕の余裕、足裏の見え方を修正しました。各方向17部位に加え、正面の足に3種類の差分があり、全37枚の透過PNGから各コマ29個の描画パーツを組み立てます。

## 今回の修正

- 正面の肩の支点と撫で肩の形を保ち、肘を内側へ押し込む配置を取りやめました。肘は肩より約4 px外、手首は約7 px外へ置き、腕と胴の間に余裕を持たせています。上腕・肘・前腕・手首の前後運動と時間差は引き継いでいます。
- 横向きの肩を前版から2.5 px後ろへ戻しました。高さは保っています。
- 横向きの首を、胸郭画像の実際の首の付け根に接続しました。首の下端を胸郭の奥、上端を頭の奥へ重ね、四角い縁や段差が見えにくい順序にしています。頭もこの接続に合わせて位置を調整しました。
- 正面の足に、足裏の見える着地前・踵の接地・足を下ろした状態・蹴り出しの4種類を用意しました。足首の支点を合わせて切り替え、足裏が常に正面を向かないようにしています。
- 股関節からの脚運び、着地前に膝を伸ばす動き、少し低くした等身、1歩4コマ・1コマ120 msは引き継いでいます。

正面の足の切り替えは、片足の位相を0〜7として次のとおりです。

| 位相 | 足の絵 | 動作 |
| --- | --- | --- |
| 0 | foot_heel | 踵が着き、足裏が少し見える |
| 1〜2 | foot | 足を下ろして体を支える |
| 3〜5 | foot_toe | 蹴り出しから後方の遊脚へ |
| 6 | foot_heel | 前へ運ぶ途中でつま先を上げる |
| 7 | foot_swing | 着地直前、足裏が見える |

画像生成の方法とプロンプトは `generation-prompts-v3.txt` に収録しています。

## 開く

`plain-walk-player.html` をブラウザーで開いてください。画像・設定・動作コードは埋め込み済みで、インストールやサーバーは不要です。

- 正面と右向きの同時再生、一時停止、1コマ送り、コマ選択。
- 関節の位置・接続の表示。肘は橙、ほかの関節は緑です。
- 分割パーツの一覧。腕や脚は現在のコマの回転・縮み方を反映します。
- 再生速度、腕振り、肘の曲げの変化量を調整できます。
- 現在の両方向の関節・部品配置をJSONで保存できます。

肘の変化量を0%にすると26度固定になり、100%では14〜42度で変化します。動きを抑えるOS設定が有効な場合は停止状態で開きます。

## 分割とつながり

ご指定の腕の並びは「上腕 → 肘関節 → 前腕 → 手首 → 手」として実装しています。

| 部位 | 素材名 | 接続先・役割 |
| --- | --- | --- |
| 頭部 | head | 首の支点に接続 |
| 首 | neck | 頭と胸郭の接続 |
| 上半身・胸郭 | upper_body | 腰から上、肩と首の親 |
| 下半身・骨盤 | lower_body | 腰・左右の股関節をつなぐ |
| 腰関節 | waist | 胸郭と骨盤の接続 |
| 肩関節 | shoulder | 胸郭から上腕へ |
| 上腕 | upper_arm | 肩から肘へ |
| 肘関節 | elbow | 上腕と前腕の接続 |
| 前腕 | forearm | 肘から手首へ |
| 手首 | wrist | 前腕と手の接続 |
| 手 | hand | 手首の角度を受ける |
| 股関節 | hip | 骨盤から上腿へ |
| 上腿 | thigh | 股関節から膝へ |
| 膝関節 | knee | 上腿と下腿の接続 |
| 下腿 | shin | 膝から足首へ |
| 足首 | ankle | 下腿と足の接続 |
| 足 | foot / foot_heel / foot_swing / foot_toe | 足首に接続。正面は足裏が見える差分を切り替える |

肩以下と股関節以下の部品は左右に配置します。`far` / `near` は、正面では画面左 / 画面右、横向きでは奥 / 手前です。

## 歩行の引き継ぎと変更

- 1歩4コマ、1周期8コマ、1コマ120 ms。コマ間の補間は行いません。
- 頭・胸郭・骨盤は歩行に合わせて上下します。正面の左右の揺れ、右向きの軽い前傾も継承しています。
- 正面では腕の前後運動を、奥行きによる縮み方と胴体との重なり順で表現します。腕を左右に大きく広げません。足幅と前後の高さ変化を引き継ぎ、足首から先の絵を位相に合わせて切り替えます。
- 右向きは膝を先に前へ運び、着地直前に下腿を前へ伸ばしてから踵を接地します。足の向きは接地・蹴り出し・遊脚で変わります。
- 右向きの支持脚は、足画像の実際の輪郭から接地高さを計算します。地面は y=242 です。正面は奥行きを高さに投影するため、前後の足で見かけの接地位置が変わります。
- 上腕の振りに対し、肘の曲げが遅れて変化します。最も前へ振るコマの次に肘の曲げが最大になります。手首にも別の角度変化があり、腕全体を一つの形で固定しません。
- 関節用の部品を接続位置に重ねることで、回転時に切断面や隙間が出ないようにしています。

これはマップ上で移動させる前提の、その場歩き素材です。マップの座標移動や速度との同期は、ゲーム側で組み合わせてください。

## 差し替え・調整

画像は `parts/`、動きは `config.json` と `rig.js` に分かれています。別の見た目を同じ支点に合わせれば、歩行を再利用できます。

部品の `pivot` はローカルの支点です。上腕・前腕・上腿・下腿は `pivot` から `end` までを隣り合う関節間に配置します。`scale[1]` は投影後の長さに合わせる拡縮です。正面の短縮は奥行き表現を含みます。正面の右側の上腕・前腕・手は左右反転し、左右の輪郭を揃えています。

`rig.json` の `frames[方向][コマ].ops` は奥から手前の描画順です。画像を `pivot` だけ引き、拡縮、回転、`position` への移動の順に描画します。角度は度単位、画面座標の正の回転は時計回りです。横向きの足は独立した足首の回転を使います。正面の `foot_far` / `foot_near` はIDを保ち、`asset` が足の差分名へ変わります。関節の `foot_pitch` は前後方向の足首角度、`foot_angle` は画面上の描画角度です。

`joints` には親のIDと位置が入っています。胴は `sacrum` → `lumbar` → `thorax` → `cervical` → `neck` の順で接続します。`body.spine_side` は骨盤中心に対する支点位置です。横向きの頸部は `assets.side.upper_body.neck_socket` を胸郭の回転・位置で変換して求めます。首の上端と頭の位置は `side.neck_tip_offset`、`side.head_offset` で調整します。肩は胸郭に、頭は首に接続します。肘は肩に対する上腕の回転から前腕の角度を計算し、手首の曲げをさらに加えます。脚は股関節と足首の目標位置から膝を計算します。正面の腕は同じ前後の角度を縦方向の縮み方と描画順に投影します。

`config.json` で主に調整する項目は次のとおりです。

| 項目 | 調整内容 |
| --- | --- |
| body | 骨盤・腰の高さ、肩の接続位置、脊柱の支点、骨盤の傾き |
| lengths | 上腕・前腕・上腿・下腿の長さ |
| front | 肩幅・足幅、腕の余裕 arm_clearance、上下動、足の差分 foot_assets と拡縮 foot_scale |
| side | 横向きの基準位置・前傾・上下動、首上端と頭のオフセット |
| gait | 足の前後位置、足首の角度、遊脚の高さ |
| arms | 8コマ分の上腕角度、肘・手首の曲げ |
| frame_ms | 1コマの時間 |

素材PNGを直接差し替えた場合は `node render.cjs` と `python assemble.py` で出力してください。`rebuild.py` は元アトラスから `parts/` を作り直します。

## 再生成

Python 3 と Node.js が必要です。最初に依存パッケージを用意します。

```bash
python -m pip install -r requirements.txt
npm install
python rebuild.py
```

アトラスの切り出し、関節検証、透過フレーム・プレイヤー・プレビューの生成を行います。プレイヤーと画像書き出しは同じ `rig.js` を使います。

## 確認

正面・右向きの全8コマを拡大して確認しました。すべての描画パーツが画面内に収まり、各フレームの素体の画素は一つにつながっています。前版の股関節・膝の重なりの切り替えを維持しています。今回の首の接続先、腕の余裕、足の差分選択も検証しました。分割した上腕・前腕・上腿・下腿の両端が関節に一致し、支持中の足裏が計算上 y=242 に揃うこと、着地前に足首が膝より前へ出ることを検証しています。

再生、コマ送り、関節・パーツ表示、腕振り・肘の変化量・速度の調整、標準設定への復帰、JSON保存をNodeのCanvas実装で確認しました。ブラウザー上のページレイアウトの実機確認はしていません。

素体の部位絵には組み込み画像生成を使用し、切り出し・関節計算・アニメーションの組み立てにはコードを使用しています。
