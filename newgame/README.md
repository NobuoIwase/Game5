## 1. 壁打ちで決まったこと（作者の答えのまとめ）

### 立場・目的
- プレイヤーは**ギルドの監査官**で、裏では**敵側の指揮者**。
- 目的はギルドをじわじわ澱ませ（**澱み**）、裏の資源（**澱晶**）を得ること。**ゲームオーバーは無い。区切りも無い**（1日の流れは Game2 と同じで、ずっと続く）。

### ヒロイン
- **星野ひかり 1人**。Game2 と同じ人物。**セーラー服を着ている、18歳以上の大学生**。口調は Game2 のまま。
  - Game2 の表記は作者がそう作らせたもの。設定は「18歳以上の大学生」で確定。**ここに異論を挟まない**。
- 変身すると「ルミナ」。素の状態で**惑**に強い。変身中は**絡**にも強い。**変身が解けるとかなり危ない**。
- 攻め筋は「魔力を削って変身を解かせ、そこへ絡や惑をぶつける」。

### 依頼書の書き換え
- ひかりが希望する依頼の中から1枚選び、**中身を書き換えて渡す**：主な魔物・規模（小さな群れ／群れ／大群）・脅威度（弱い／普通／手練れ）・長の有無。
  - 例：「ゴブリンの長が率いる、手練れの大群の討伐」→「弱いゴブリンの小さな群れの駆除」
- 行き先のすり替えは、裏の取引で買う追加機能。
- ひかりは依頼書から**万全の準備**をする。準備には**持ち込みアイテムも含む**（装備や能力だけではない）。偽の情報で準備させると、その準備が弱点になる。
- 三すくみ：惑（催眠・魅了）→対策「鎮心の香」は蕩に弱くなる。蕩（媚薬・粘液）→「封肌の衣」は絡に弱くなる。絡（触手・拘束）→「覚醒の薬」は惑に弱くなる。外枠に**削**（魔力を削る）。

### 信頼と違和感
- 違和感（表に出さない）：書かれた依頼と違うことが続くと溜まる。公文書なので簡単には疑わない。
- 確信されたら**矯正**：信頼を最大にし、澱晶を0にする。ひかりが堕ちていれば黙る。

### 潜行
- **10階、1階は小さめ**。初期配置はランダム生成。そこへプレイヤーが潜行中に魔物・罠を置き足す。
- デッキはダンジョンごとに別（固定枠＋自由枠）。
- 置く時の制限：同時に出せる数の上限、カードごとの待ち時間、階ごとのコスト上限。オート指揮あり。
- ダンジョン名は**基本は系統特化、たまに種族特化**（例：ゴブリンの巣穴。その種が大半）。
- 場面：軽いものは流す、重いもの（捕まった・変身が解けた・敗北）は止めて読ませる。
- 敗北したら潜行は終わり。**救出までの一晩を観測**でき、夜のコストで魔物を呼び足せる。飛ばしてもよい。
  翌日救出され、報告で**敗北後に何をされたかまで話す**。

### 罠（Game2 をなぞる）
- 罠は**置いてある物**。堂々と置いてよい。
- **罠部屋は Game2 と同じく「1つの罠に特化した部屋に、魔物が大量に潜む」**。罠が沢山置いてある部屋ではない。
  階まるごと罠部屋の「罠の階」もある。

### 報告と監査
- 流れは Game2 のまま（口頭報告 → 書類監査 → 再報告 → 処置）。報告書は口語体。
- **ライフシミュのように毎回違う**。その日の状態・起きたこと・ステータスで、話し方も順番も変わる。パターンを大量に。
- 「その……いえ、言います。部位、です。○回」の語り口は**型の1つにすぎない**。

### 画面の流れ
- 監査官室から始まる → ひかりが入ってくる → 軽い会話 → 依頼書を選ぶ → 書き換える → 手渡す → 見送る → 潜行 → 帰ってきて監査官室で報告。
- 帰ってきた後（報告・監査・処置）は**改善を続ける**。

### 戦い方と動き（作者の指摘で直してきたこと）
- 動きは旧 Game5 の AI を移した。**地に足の着いた**動き（ふわっと滑らない）。
- 画面下にドラクエ風のメッセージ窓。魔法を使う時は技名を叫ぶ。
- 引き撃ちだけが強くならないように：近接（魔力消費が低い）と遠距離（高い）を使い分ける。
- **MP を切らさない立ち回り**：半分を切ったら近接中心、安全な所で休む、危ない時は水薬。
- 囲まれた時の反応は Game4 の AI を参考に（隙間を探して抜ける、ルミナ・フラッシュで押し返す）。
- 変身が解けたらすぐには戻れない（25秒）。
- **状態異常は一気に上がって下がりにくい**（Game4 は敵が大量なので短くしたが、このゲームは敵が少ない）。
- 状態異常はステータス欄で見える。催眠は分かりやすく（頭上の表示、画面の縁の紫）。
- 敵がいる部屋で自分から寝るのは不自然なのでやめた。寝台の罠は**催眠の香で眠らせる**。
- 催眠のゲイズ等は、弾ではなく **Game2 のようにパッと光の扇が出る**。
- 拘束はすぐ抜けず、**何が起きたか分かるようにじっくり**。
- **発情だけでは撤退しない**（発情しているだけなら問題ない、と考える方が自然）。
- 壁と暗い床は区別がつくように。
- 装備欄は、今は飾りでよい。

## 2. 遊び方（今の実装）
1. **ギルド（朝）**：受付嬢の話、ひかりの様子（肉体・精神・信頼・疲労・状態異常）を見る。
2. **監査官室**：ひかりが来て軽く話す。依頼書を1枚選び、中身を書き換えて渡す。
   - ひかりは依頼書を見て、次の2つを決める。
     - 対策の品：鎮心の香・封肌の衣・覚醒の薬
     - 持ち込みアイテム：星の雫・治癒の軟膏・気付けの香・魔力の水薬・冷ましの薬・縄抜けの小刀
   - 持ち込み品はギルド資金から買う。手強いと書くほど多く持ち込み、系統に合わせた品を選ぶ。
   - 渡したら見送る。
3. **潜行（10階）**：ひかりは自分で考えて動く。プレイヤーはカードを選び、**ひかりに見られていない所**を押すと魔物・罠を置ける。「帰還を勧告」で引き返す。
4. **敗北したら観測フェーズ**：救出までの一晩。
5. **口頭報告**：嘘の行は「追及する」で問い詰める。
6. **書類監査**：嘘だと思う行に印を付けて確定する。
   - 「特に何もなし」は本人が覚えていないだけの欠落で、嘘ではない。
   - 摘発すると信頼が上がり、再報告へ。見逃した嘘は、ひかりの心に積もる。
7. **処置**：状態異常を治すか、残すか。
8. **裏の取引**：澱晶で、デッキの自由枠・同時に出せる数・階のコスト・行き先のすり替えを増やす。

## 3. 中身の地図（コード）

素の JS。ビルドなし。すべて `G` という1つのグローバルに載る。
読み込み順（`index.html`）：`util → data → map → text → field → report → game → render → ui`。
`util〜game` は DOM を触らないので、Node の `vm` でそのまま動く（検査ツールはこれを使う）。

| ファイル | 中身 |
|---|---|
| `js/util.js` | `G.U`：シード付き乱数（`setSeed`）、`rand/ri/rf/pick/shuffle/weighted/clamp/dist/angle/angDiff/fill` |
| `js/data.js` | `G.MONSTERS`（44体）、`G.TRAPS`（49種）、`G.TRAP_ROOMS`（55部屋）、`G.DUNGEONS`（4つ）、`G.LAWS`（迷宮の法則8）、`G.TRAITS`（性癖14）、`G.PREP`（対策の品）、`G.HIKARI`（ひかりの技・数値・持ち込み品の初期値・装備名）、`G.BAL`（全体の数値） |
| `js/map.js` | `G.Map`：1階の生成（部屋・L字通路・柱、26×20タイル）、見通し `los`、A* `path`（危険を避ける重み付き） |
| `js/field.js` | `G.Field`：潜行の中身すべて（下に詳しく） |
| `js/text.js` | `G.Text`：吹き出し、メッセージ窓（`MSG`）、技名（`SKILL`）、重い場面（`SCENE`）、一晩の場面（`NIGHT`・魔物ごとの `NIGHT_MON`）、監査官室の会話（`OFFICE`）、アイテム名。**配列に書き足すとそのまま候補に入る**。<br>魔物ごと・姿ごとの差し替え：吹き出しは `BUBBLE["spot@種"]`、捕まった場面は `SCENE["hold@種"]`、素の姿だけの場面は `SCENE["鍵#civilian"]`。無ければ共通のものを使う |
| `js/report.js` | `G.Report`：口頭報告・報告書・監視記録・再報告を組み立てる。文章の在庫もここ。日をまたいで同じ文を避ける（`save.reportMem`）。<br>魔物・罠ごとの言い方は `WHAT_KIND["種:件の種類"]`（例 `"nikubana:hold"`）、件の種類ごとの嘘は `DOWNPLAY_KIND`／`DOC.falseKind` |
| `js/game.js` | `G.Game`：1日の流れ。`newSave, morning, assign（書き換え）, prep（準備と持ち込み品）, startDive, makeFloor, afterFloor, finishDive（違和感・堕ち・報酬）, audit, rereportChoice, treat, endDay, buy`、`ITEMS`、`AILMENTS`、依頼名 `requestTitle`、種族特化の名前 `placeName` |
| `js/render.js` | `G.Render`：キャンバス描画。床の質感画像、壁の上面（石積み）、明かり、魔物の動きの味付け、攻撃の予兆（線・円・**扇**）、ひかりの頭上の状態表示 |
| `js/ui.js` | 画面すべて（監査官室・依頼書の編集・手渡し・潜行・観測・報告・監査・再報告・処置・デッキ・取引・履歴）。`G.debug.dive` で潜行中の世界を覗ける |
| `css/style.css` | 見た目。監査官室は CSS で描いた部屋 |

### `js/field.js` の主な部分
- `createWorld / populate`：1階を作り、魔物・罠・罠部屋・宝箱を置く。種族特化の依頼ならその種を7割に。
- **罠部屋**：`makeTrapRoom`、`enterTrapRoom`（入ると封鎖、眠っていた魔物が起きる、部屋の気）。
- **効き目** `applyEffect(w, 系統, 強さ, 出どころ, how)`：
  - 惑：**催眠度 `h.hyp`**（0〜100。1回で 26×強さ×耐性 上がり、毎秒0.35ずつ下がる。ひかりは惑に強いので、実際は1回で十数〜30ほど）と、立ち尽くし `h.trance`（秒）。
    催眠度が高いほど反応・狙いが鈍り、気力が戻りにくく、ときどき放心する。
  - 蕩：発情 `h.arousal`（毎秒0.12しか下がらない）、快感 `h.pleasure`（100で絶頂）、鈍足 `h.slow`。
  - 削：魔力 `h.magic` を削る（0で変身が解ける）。
- **拘束** `grab / updateBound / release`：捕まって最初の2.4秒はほぼ抜けられない。抜けかけると表示。抜けたらよろめく。
  縄抜けの小刀、ルミナ・フラッシュ（2体以上に捕まれた時など）で抜ける。
- **ひかりの頭** `hikariThink`：危険を読んで避ける（`castHits / danger / bestDodge`）、囲まれ判定（`pressure`）、持ち込み品を使う、撤退の判断、MP 節約、探索。
- **ひかりの体** `updateHikari`：加速・減速（地に足）、向き、詠唱。
- **魔物の頭**：役割ごとの間合い、左右に散る、同時に撃つ数の制限、飛びかかり、逃げて仲間を呼ぶ。`startCast` → `fire`。
  攻撃の型：`grab`（掴む）、`shot`（弾）、**`shot` に `fan` があれば光の扇**（弾ではなく一瞬で届く扇形）、`lure`（誘う）、`aura`、`drain`、`possess`（腕に憑く）。
  追加の性質：`spread`（扇に何発も撃つ）、`surge`（当たると快感が跳ね上がる）、`sigil`（当たると淫紋）、`breath`（甘い息。発情が強いと寄っていってしまう `h.drawn`）、`cloud`／`popCloud`（媚薬の靄 `w.clouds` を残す）、`film`（見られながら達すると記録される）。
- **罠** `updateTraps / triggerTrap`。寝台（偽りの褥）は傍を通ると催眠の香で眠らせる。
  拘束型の罠は `h.bound` に印を付けて、`updateBound` で中身を変える：`hang`（吊花：蜜が垂れる）、`root`（蝕根：床下）、`cocoon`（白繭：小刀が効かない）、`ratchet`（爪車：もがくと抜けかけが戻る。13秒で開く）、`shadow`（影腕：腕が増える。4本からルミナ・フラッシュの対象）。
  淫紋の祭壇は拘束ではなく足止め（`h.altar`）。終わった時に気力が55より多い（＝強く踏ん張った）と2段刻まれる。囁きの塔は `emit`（踏まなくても、近くで見通せる間は3.2秒ごとに波。4回で休む）で、`updateTower`。
- **憑き手** `possess / endPossess`：憑かれている間は光弾が撃てない（近接で戦う）。絶頂すると離れる。**淫紋** `engraveSigil`：`h.sigil`（1〜3）で蕩の効きが1段15%上がる。
- **配置** `canPlace / place / autoDirect`（オート指揮）。
- **観測フェーズ** `startNight / nightBeat`。
- `statusList(w)`：ステータス欄のチップ（状態異常の一覧）。

### 状態異常（潜行中・帰還後・性癖）— 「状態異常まみれ」が華（作者の指示）
Game2 の AILMENTS／TRAITS と Game4 の状態異常を参考にした。三段になっている。
- **潜行中**（`h.*`、ステータス欄のチップ・`field.js` の `tickStatus`）：敏感化（1〜5、快感の入り+7%ずつ）、疼き、痺れ、ハイ／中毒（咳き茸）、時間停止、嗅いでしまう（雄臭）、敬礼（常識改変）、
  絶頂禁止（寸止めの淫魔。溜まった分は解けた時に `releaseOverflow` でまとめて来る）、おあずけ（夢魔の女王。三度止められるとねだる）、誓い（この階を出るまで達せない）、
  付着体（震え珠・纏い衣・星喰み・吸盤。纏い衣は本人が「装備」だと思っている＝報告に出ない）、魅了Ⅰ〜Ⅲ（種族ごと。その種を撃てない・寄っていく）、暗示の引き金（発作）、洗脳（ワルドー。100で戦闘員化）、装束損壊、思考汚染、淫紋。
- **帰還後**（`game.js` の `AILMENTS`、処置で治す）：発情・催眠残滓・汚濁・魔力枯渇・淫紋・過敏・疼き・おあずけ・魅了・付着体・装束損壊・麻痺・疲弊・思考汚染・中毒、
  深層処置（高い）の刷り込み：暗示の引き金・常識改変・敗北洗脳。どれも**次の潜行の始まりに持ち越す**（`startDive`）。付着体・おあずけ・疼きは**報告の最中にも効いて**、台詞に声が割り込む（`report.js` の `ONGOING`）。
- **性癖**（`G.TRAITS`、`save.traits`、消えない）：負け癖・拘束癖・焦らし弱・決壊癖・見られ熱・吸われ悦び・雄臭への発情・紋を灯す悦び・忘れる従順・待ち堕ち癖・弱擽過敏・丸呑まれ安堵・律動従属・淫魔好き。
  回数（`save.counts`）で芽生え→癖→刷り込みと進む。Game4 と同じく**戦力は減らさない**：その場面の快感の入りが増え（`intake`）、同じ責めからの抜け方も上手くなる（`resist`）。ギルドの画面に出る。

### 迷宮の法則（Game2）
依頼の半分くらいで、入口で一つ決まる（`startDive` の `law`。ワルドーの支部には無い）。入口で止めて読ませる。
衆目（見物が増え、視線が強い）・潤沢（空気が媚薬）・禁絶（中では達せない。門を出た瞬間に全部返る）・静止（拘束が長い）・忘却（出来事が本人の記憶から消える＝報告の欠落）・鋭敏（降りるたび敏感化）・剥奪（2階から装束損壊）・刻印（入口で淫紋）。

### 本人の記憶に残らない出来事
