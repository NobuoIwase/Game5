# Game5 アセット依頼書（ChatGPT 向け）

Game5 v0.13.0 の画面を良くするために、画像生成で作ってほしい素材の一覧です。
各節の「依頼文」をそのまま ChatGPT に貼って使えます。

- ★ = 置くだけで反映される（`assets/requested/manifest.json` に1行書くだけ。コード変更なし）
- ☆ = 受け取った後にコード側の組み込みが必要

---

## 0. 全素材に共通する条件（毎回、依頼文の先頭に付ける）

```
【共通仕様】
・用途: ブラウザ用 2D トップダウン（やや斜め上から見下ろす 3/4 視点）ダンジョンRPG
・画風: 手描き風のドット寄りイラスト。輪郭ははっきり、陰影は2〜3段。光源は左上
・背景: 完全な透過PNG（アルファ付き）。床タイルだけは不透明
・文字、ロゴ、枠線、影の地面は入れない（影はゲーム側で描く）
・グリッド: 指定のマス目にきっちり収め、マスの間に余白や線を入れない
・色調: 暗いダンジョン。石は冷たい灰青、魔物は彩度高めで発光部あり
・全年齢向けの表現にする
```

## 1. 優先度A — 区画ごとの床タイル ★

いまの床は、元の苔石と Game4 の石板から「石の表面」だけを切り出して区画ごとに焼き上げています。専用の床が届けば、それをそのまま並べます。
区画の名前に合う専用の床がほしい。

**形式**: 256×128px、64px のマスが 4列×2段。左3列が普通の床（6種）、右端の列が紋様入りの床（2種、まれに出る）。

| ファイル名 | 区画 | 内容 |
| --- | --- | --- |
| `floors/room1.png` | 石の前室 | 苔むした灰色の石畳。ところどころ湿った苔 |
| `floors/room2.png` | 湿った回廊 | 濡れて光る黒い石板。水たまりの反射 |
| `floors/room3.png` | 絹輪の間 | 白い絹糸が薄く張り付いた石床。紋様は輪 |
| `floors/room4.png` | 胞子庭 | 黄緑の菌床と石が混ざった床。紋様は胞子の輪 |
| `floors/room5.png` | 粘花苑 | 桃色の花弁と蔓が這う石床 |
| `floors/room6.png` | 夢鱗回廊 | 紫がかった石に鱗粉のきらめき |
| `floors/room7.png` | 灰冠の深室 | 灰色の大理石に冠の紋章。最深部らしい重さ |

**依頼文**
```
（共通仕様）
256×128ピクセルのトップダウン床タイルシートを作ってください。64×64のマスが横4列×縦2段です。
左の3列（6マス）は同じ素材の床のバリエーション。どのマス同士を並べても継ぎ目が目立たないように、四辺がシームレスに繋がるようにしてください。
右端の列（2マス）は、同じ床に紋様が刻まれた特別なマスです。
素材: 【ここに上の表の「内容」を入れる】
```

`manifest.json` への書き方（区画番号は 0 始まり）:
```json
{ "monsters": {}, "floors": { "0": "floors/room1.png", "1": "floors/room2.png" } }
```

```
キャラの足元（接地点）がキャンバスの下端から約15%の位置に来るようにし、周囲に余白を少し残してください。

```

**☆ アニメ版（1枚絵の後で）**: 1024×256px、256px のマスが横4つ（待機1・待機2・詠唱・被弾）。
