## 現行素材の由来

生成された原画像27枚は `workspace/generated_images/` に残っています。ファイル名は生成時のものです。各版の `source-atlases/` には再生成用に名前を付けたコピーがあり、`generation-prompts*.txt` に指示が残っています。

同一SHA-256で照合できる生成画像・添付画像との対応を `data/source-atlas-provenance.csv` に記載します。ハッシュ一致がないものは由来不明と断定せず、加工済みまたは別の元データの可能性として扱います。

| 現行の部位 | 主な元絵・処理 |
| --- | --- |
| 正面・横の頭 | front-v1.png / side-v1.png |
| 正面・横の一般部位 | front.png / side.png（v2で肩・胴・骨盤などを修正） |
| 正面の足差分 | front-feet-v3.png |
| 追加3方向の基本部位 | down_right.png / up_right.png / back.png |
| 斜め下の胸郭・首・足差分 | down-corrections-v5.png |
| 斜め後ろの胸郭・首・手 | up-corrections-v5.png |
| 現行の斜め頭 | down-head-v7.png / up-head-v7.png |
| 胸郭の首開口の横線修正 | down-neck-open-v8.png / up-neck-open-v8.png の上端の明るい部分だけを組み込む |
| 腰の接続部品 | 各方向のhip素材を18×10へNearest Neighborでリサイズ |

v8の修正は胸郭全体の差し替えではありません。既存胸郭の最上部2行の内側、斜め下6×2 px・斜め後ろ8×2 pxだけを生成素材から置き換え、元の透過輪郭と他の画素を保持しています。v9以降は位置の変更で、部位絵を新しく生成していません。

切り出しはアルファ210以上を不透明とし、最大の8近傍連結成分を残して外周の不要画素を取り除きます。その後、決めた部位サイズへNearest Neighborで縮小します。アトラスの列・行の境界や上書き順は `extract_parts.py` にあります。

## ルミナへ戻す場合の注意

最新素体へ衣装・髪・翼を載せる作業は、現行版で完了していません。旧ルミナの見た目は `workspace/lumina-walk-v6/` を参照できますが、肘を含む最新の一般化した動きをそのまま持つとは限りません。

元のユーザー要望として、翼が髪の後ろへ隠れすぎないこと、手と指を伸ばしきらないこと、首の切り口・髪の束が喉元の突起に見えないことを引き継ぎます。頭・髪・輪・翼の前後関係は、方向と体の動きに合わせて決めます。

画像を描き直す場合も、元の歩行タイミングや各関節の位置まで一度に変更しない方が、見た目の差分を判断しやすくなります。生成プロンプト、使った参照画像、採用した画像、切り出し方法とpivotを記録してください。
