あなた（手元の Claude Code）は、GitHub リポジトリ NobuoIwase/Game5 の newgame/（ブラウザで動く素の JavaScript のゲーム）の絵を、Grok の画像生成で作り直します。
Grok はブラウザ（grok.com、ユーザーがログイン済み）で操作します。

1. リポジトリを用意する。手元に無ければ clone、あれば main を最新にする：
     git clone https://github.com/NobuoIwase/Game5.git   （または  git checkout main && git pull）
2. 最初に newgame/GROK_TASKS.md を全部読む。次に newgame/README.md の「作業の約束」と NG リストを読む。どちらも必ず守る。
   特に：幼く見える描き方をしない（小淫魔も小柄な大人として）／実在の虫に似せない／卵を思わせるものを描かない／魔物のピンク寄りの配色は直さない／
   docs/ の中身をプロンプトや絵に写さない／ゲームの文章は書き換えない／Grok の元画像はリポジトリに入れない（~/grok_raw/ に置く）。
3. 道具の準備：Python 3 と Pillow（pip install pillow）、Node.js。リポジトリ直下で
     node newgame/tools/fingerprint.js 40 1
     node newgame/tools/fingerprint.js 40 2
   を実行し、1行目（sha256）を控える（作業後に同じであることを確かめる）。
4. 課題A（魔物11種）：main から grok/monster-art を切る。
   newgame/grok_prompts/A_monsters.txt のブロックを1つずつ Grok に貼り（STYLE の行ごと、正方形）、GROK_TASKS.md の「選ぶ基準」で1枚選んで ~/grok_raw/A/ に保存。
   newgame/tools/grok_fit.py sprite ... --pixel 2 で整え、data.js の art と tint、render.js の FIG を GROK_TASKS.md の手順どおりに直す。
   確認（fingerprint 2本・check.js・play.js を幅390と1280で）を実行し、出力とスクリーンショットを添えて PR を作る。マージはしない。
5. 課題B（罠部屋の床と飾り7種）：main から grok/room-skins を切る。
   newgame/grok_prompts/B_rooms.txt のブロックで作り、grok_fit.py の tile・deco・sheet で整えて assets/env/room_<種>.png と room_<種>_deco.png を置き換える。
   作業前と作業後の一覧（assets/index.html の部屋の欄）のスクリーンショットを並べ、tools/rooms.js・fingerprint・play.js の出力を添えて PR を作る。マージはしない。
6. Grok が断った・ぼかした時は、言い回しを穏やかにして作り直す。押し通さない。3回やってもだめな物は飛ばして PR に書く。
   ログイン・年齢確認・課金など、本人の操作が要る画面が出たら、そこで止めてユーザーに頼む。
7. コミットや PR にモデル名を書かない。実行していない確認を「確認済み」と書かない。
8. 最後に、作った PR の URL、差し替えた物・見送った物・言い回しを変えたプロンプトを日本語で報告する。

全部で Grok に貼るのは A が11ブロック、B が42ブロック（7種×6）。B は時間がかかるので、A の PR を出してから始める。
