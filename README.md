# GAME5 — v0.9.0

戦乙女リアルタイム・コマンドRPG。ヒロインは性格・視界・聴覚・記憶・学習に基づいて自律行動し、プレイヤーは敵・罠・環境を配置する。

現在のパイロット版は `game/`。

## v0.9.0 — Warrior Motion Complete Pass

戦士1人の基礎モーション一式を完成扱いまで整理。

- 待機、歩行、走行、振り向き、回避
- 通常斬り、破城斬り、盾撃、防御
- 被弾、気絶、拘束・もがき
- エステラ発生〜痙攣〜復帰
- 敗北・脱力
- 8方向の既存戦士リグを利用
- 通常斬りは肩・肘・手首で右腕を実行時分割して関節アニメーション
- 高速移動は run、低速移動は walk を使用
- 技の見た目の命中タイミングを実際の cast 完了へ同期
- `warrior-motion-timing.js` に必須15状態のQAマニフェストを追加
- Motion Labで方向・速度・コマ送り確認可能

グラフィック、ヌテラ・エステラ、敵テーマ等のv0.8.0内容は維持。
