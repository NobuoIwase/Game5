# Game5 — v0.4.0

見下ろし型ダンジョンRPG。ヒロインは性格・知覚・記憶・学習を持つAIとして自律行動し、プレイヤーは敵や罠を配置します。戦闘は接触ダメージ中心ではなく、敵ごとに射程、予兆、踏み込み、攻撃範囲、拘束、状態異常、魔法、反応を持つリアルタイム・コマンドRPGを目指します。

現在のパイロット版は [`game/`](./game/) です。

## v0.4.0
本作固有の中核システム「ヌテラ・エステラ」を実装しました。ヌテラ蓄積→エステラによる行動不能/MP漏出/SP消耗、ルマネ・催眠/魅了、セイル、輪紋、欲求波、輪紋ビーム、Game4参照の敵設計仕様を実装。

敵設計はGame4を参考にしつつ、Game5では全モンスターに固有のヌテラ上昇手段を持たせ、リアルタイムの射程・予兆・回避・拘束・学習へ翻案していきます。
