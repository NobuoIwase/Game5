# Game5 playable prototype

キャラクター移動素材を実際のゲーム側で使うための、依存ライブラリなしのトップダウン試作です。

## 起動

リポジトリ全体を取得し、`game/index.html` をブラウザで開きます。画像は `../character-motion-v1/exports/` の既存スプライトシートを相対パスで読み込みます。

GitHubのファイル閲覧画面では実行されません。必要なら任意の静的HTTPサーバーでも配信できます。

## 操作

- `WASD` / 矢印キー: 8方向移動
- `Shift`: 走行
- `1`〜`4`: 戦士 / 獣人スカウト / 魔女 / シスター切替
- `R`: 最初から
- タッチ端末: 画面下部の方向ボタンと `RUN`

## 次の実装候補

この段階では「移動素材をゲーム内で成立させる」ことを優先しています。攻撃・被弾・敵AI・会話・マップデータ・セーブはまだありません。攻撃アニメーション素材が追加された時点で、戦闘状態を移動状態から分離して実装するのが次の区切りです。
