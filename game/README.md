# Game5 battle pilot — v0.6.0

ヒロインを直接操作せず、AIが視界・聴覚・記憶・性格・敵知識からリアルタイムに行動するパイロット。

## v0.6.0 モーション

### 移動

- 低速追跡 / 音確認 / 旋回: `walk.png`
- 高速接近 / 逃走 / 高速回避: `run.png`
- どちらも8方向×8コマ。

### 剣攻撃

`warrior-motion.js` が既存の戦士リグを読み、右腕を実行時に上腕・前腕・手へ切り抜いて関節ごとに動かす。

`肩 → 上腕 → 肘 → 前腕 → 手首 → 手 + 剣`

通常斬りと破城斬りは、予備動作 → 加速 → 命中 → 振り抜き → 回収。命中の見た目はスキルの `cast` 完了時刻へ同期する。

### 拘束 / エステラ

- 拘束: 両腕・両脚を別位相で動かし、全身一枚を揺らす方式を廃止。
- エステラ: onset / loop / recovery を意識し、左右非対称の短周期収縮を使用。
- 今後は敵側から拘束点データを渡して敵固有姿勢へ発展させる。
