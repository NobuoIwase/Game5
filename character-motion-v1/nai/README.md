# モーションの元絵を NovelAI で作る（ユーザー向け）

作成：Claude（2026-09-26）。一覧と下絵は `node tools/build_nai_jobs.mjs` で作り直せる。

## 何を作るか

どのコマを作るかは決めてある（`jobs.json`）。
- 拘束された姿勢・床・口づけ・拘束なし・張り付きの1枚絵：146コマ。4人それぞれで描く
- ヒロインの自分のモーションのうち、それらとつながるもの：19コマ
  - 尻尾をつかまれる、こわばり、声をこらえる、義腕を縛られる、前垂れがめくれかける

| キャラクター | 枚数 |
|---|---|
| アリア | 146 |
| 斥候 | 153 |
| 魔法使い | 153 |
| ヒーラー | 151 |
| 計 | 603 |

- 1枚絵にしないコマ（中割り・つなぎなど）は、これまでどおり部位の組み立てで作る（`../PRODUCTION_PLAN.md`）
- 攻撃・技・仕草など、ほかの1枚絵は ChatGPT に頼む

## 仕組み

1. ローカルの Claude が、手伝いの枠の「次のコマを入れる」を押す
   - まだ保存していない次のコマが選ばれ、その下絵（姿勢だけのマネキン図、`base/`）が読み込まれる
2. ローカルの Claude が、NovelAI の生成ボタンを押す
3. 送る直前に、手伝いが中身を入れ替える
   - プロンプト：共通（大人の女性1人・全身・白背景）＋キャラクターの見た目＋**「設定」に書いた言葉**＋向き・姿勢・表情の言葉
   - 除外：子ども・流血・卵・虫など
   - 下絵を使う img2img（サイズは 1024×1024）
4. できた画像は、「保存（ユーザー用）」を押すか、「自動保存」をオンにしておくとダウンロードされる
   - ファイル名：`<キャラクター>__<モーション>__<向き>__<コマ>.png`

**触手・縄・スライム・小さな生き物・相手など、つかむもの・包むものの言葉は、こちらからは入れない**（色や種類を決めずに入れると、何でも出てくるため）。
- 下絵のマネキン図にも描かない（姿勢だけ）
- 入れるのは、それが体に与える形だけ（「手首を合わせる」「腕を後ろに回す」「脚を開く」など）
- 出したいときは、「設定」の場面の種類の欄に、色や種類まで書いて足す（例：何色の、どんな形の）

「設定」に書いた言葉は、このブラウザ（Tampermonkey の保存領域）にだけ残る。NovelAI のプロンプト欄にも、リポジトリにも出ない。

## 場面の説明

**`scenes.html`**（https://nobuoiwase.github.io/Game5/character-motion-v1/nai/scenes.html ）に、場面の種類ごとのモーションとコマを全部並べてある。枠の一番上の「場面の説明を開く」からも開ける。
- 何が起きているか、どこを押さえられているかを日本語で書いてある
- 左の絵（`guide/`）：どこを押さえられているか（色の線や塊）。読むためだけの絵で、NovelAI には送らない
- 右の絵（`base/`）：NovelAI に送る下絵（姿勢だけ）
- 絵の下の英語：こちらで入れてある言葉

枠でコマを入れると、そのコマの説明と2枚の絵が枠にも出る。「このモーションだけの言葉」の欄に書くと、そのモーションの全コマ（4人とも）にだけ足される。場面の種類の欄は、その種類の全部のコマに足される。

## 準備

1. ブラウザに Tampermonkey を入れる
2. `https://nobuoiwase.github.io/Game5/character-motion-v1/nai/game5-nai-helper.user.js` を開いて、スクリプトを入れる
3. NovelAI の画像生成の画面を開き、モデルを **NAI Diffusion V4.5 Full** にする
4. **精密参照**（Precise Reference）に、作るキャラクターの参照画像を入れる
   - 公式のおすすめ：無地の背景・ふつうの姿勢の全身を大きく、別に顔のアップ。三面図もよい
   - 何枚も入れると1人に混ざるので、同じキャラクターの画像だけにする
   - ヒーラーは原画 v7 が胸を覆う衣装のままなので、前垂れの衣装の参照画像を先に作る
   - キャラクターを切り替えたら、参照画像も入れ替える
5. 右下の枠の「設定（ユーザー用）」を開いて書く
   - **場面の種類ごと**に1回ずつ（18種類）。空でもよい
   - キャラクターごとの言葉（あれば）
   - 除外する言葉の追加
   - 下絵の強さと自動保存

| 場面の種類 | コマ数（1人あたり） |
|---|---|
| こわばり・絶頂の頂点（ほかの種類に重ねて足される） | 31 |
| 余韻から起き上がる | 19 |
| つかまれる・引きずられる | 17 |
| 拘束されている | 16 |
| 押し倒される・押さえつけられる | 13 |
| ぼんやりする・催眠・胞子・泡 | 13 |
| 倒れる・敗北 | 11 |
| 余韻でぐったりする | 10 |
| 拘束されたまま揺さぶられる | 8 |
| 柔らかい塊に呑まれる | 7 |
| 小さな生き物に張り付かれる | 5 |
| 口づけ | 4 |
| そのほか（押さえつけて揺さぶる・後ろから抱える・誘う・巻きつく・声をこらえる・前垂れ） | 各1〜2 |

## 下絵の強さ（img2img の strength）

- 既定は 0.7
- 上げると NovelAI の絵らしくなるが、姿勢が下絵から離れる。下げると姿勢は合うが、マネキンの形が残る
- 最初に数枚で試して決める。姿勢がずれる → 下げる、人形っぽい → 上げる

## まだ確かめていないこと

- 手伝いは、NovelAI の画面が生成を頼む通信（`/ai/generate-image`）を送る直前に中身を入れ替える。本物の画面ではまだ試していない
  - 最初の1枚で、次の3点を確かめる
    - 下絵どおりの姿勢になっているか
    - 右下の枠に「送信：…」と出るか
    - 生成の履歴のプロンプトが入れ替わっているか
  - 「書き換えられませんでした」と出たら、NovelAI の送り方が想定と違う。その文を教えてもらえれば直す
- V4.5 で透過背景が使えるか。使えない場合は白背景で作り、あとで抜く
- Chrome の Tampermonkey を前提にしている（Firefox では動かない場合がある）

## 置き場所

保存した画像をどこに置くか（リポジトリに入れるか）は、決まったら教えてほしい。組み立てのツールはそこから読むようにする。
