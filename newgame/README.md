# 監査官と魔法少女（新作・初版）

Game2 の報告・監査と潜行の中身、Game5 のリアルタイム探索と戦闘、Game4 の魔物と戦闘エロを合わせた新作。
遊ぶページ：`newgame/index.html`（公開ページ https://nobuoiwase.github.io/Game5/newgame/ ）。設計の決めごとは `DESIGN.md`。

## 遊び方
1. **ギルド（朝）**：受付嬢の話、ひかりの様子（肉体・精神・信頼・疲労・状態異常）を見る
2. **依頼を割り当てる**：ひかりの希望する3件から選ぶ。**依頼書の系統（惑・蕩・絡）を書き換えられる**。
   ひかりは依頼書を見て対策の品を用意してくる（鎮心の香・封肌の衣・覚醒の薬）。その副作用が、本当の中身への弱点になる。
   裏の取引で「行き先のすり替え」を買うと、実際の行き先も差し替えられる
3. **潜行（10階）**：ひかりは自分で考えて動く（見て・聞いて、物陰から覗き、忍び寄って撃ち、下がる）。
   プレイヤーはデッキのカードを選んで、**ひかりに見られていない所**を押すと魔物・罠を置ける。
   階ごとのコスト上限・同時に出せる数・カードの待ち時間がある。オート指揮も使える。「帰還を勧告」でひかりは引き返す
4. **敗北したら観測フェーズ**：救出までの一晩を見る。夜のコストで魔物を呼び足せる。飛ばしてもよい（あとで本人の口から語られる）
5. **口頭報告**：その日の状態・起きたこと・信頼で、話し方と話す順番が毎回変わる。嘘の行は「追及する」で問い詰められる
6. **書類監査**：嘘だと思う行に印を付けて確定。「特に何もなし」は本人が覚えていないだけの欠落で、嘘ではない。
   摘発すると信頼が上がり、再報告へ。見逃した嘘は、ひかりの心に積もる
7. **処置**：状態異常を治すか、残すか（残すと次の潜行に響き、ギルドが澱む）
8. **裏の取引**：澱晶で、デッキの自由枠・同時に出せる数・階ごとのコスト・行き先のすり替えを増やす

依頼書の偽装を続けると、ひかりの「違和感」が積もる。確信されると、澱晶を全部使って「矯正」することになる（ゲームオーバーは無い）。

## ファイル
| ファイル | 中身 |
|---|---|
| `js/data.js` | 魔物21体・罠10種・ダンジョン3つ・準備の品・ひかりの強さと弱さ・数値 |
| `js/map.js` | 1階ぶんの地図の生成（部屋・通路・柱）、見通し、道探し |
| `js/field.js` | 潜行の中身：ひかりのAI、魔物のAI、弾と当たり判定、罠、拘束、配置のルール、オート指揮、観測フェーズ |
| `js/text.js` | 潜行中の文章（吹き出し・記録・重い場面・一晩の場面）。**書き足すとそのまま候補に入る** |
| `js/report.js` | 口頭報告・報告書・監視記録・再報告を組み立てる。**文章の在庫もここ** |
| `js/game.js` | 1日の流れ、堕ち・状態異常・報酬・違和感、監査、処置、裏の取引、セーブの中身 |
| `js/render.js` / `js/ui.js` | 画面 |
| `tools/sim.js` | ブラウザなしで何十日分も回す検査（`node newgame/tools/sim.js 30 7 --dup`）。止まらないか・報告が似ていないかを数える |

## 文章について
エッチな場面・報告・監視記録の文章は、控えめな表現で書いてある。`js/text.js` と `js/report.js` の配列を書き換えたり書き足したりすれば、そのままゲームに出る。
同じ文が続かないよう、直近に使った文（報告は日をまたいで数日分）を避けて選ぶ。
