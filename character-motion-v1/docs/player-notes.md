# 8方向モーション確認プレイヤー

`tools/build_player.py` は PNG シートと `exports/manifest.json` を読み込み、画像と設定を内蔵した `player.html` を作成します。Python の標準ライブラリだけで実行でき、完成した HTML はサーバーを立てずに開けます。

```powershell
python tools/build_player.py
```

別の出力先に保存するときは `--output` を指定します。HTML 以外のファイルを書き換えません。ビルド時にはシートの縦横寸法と方向順を確認します。

## 入力

- `exports/warrior/walk.png` と `run.png`
- `exports/scout/walk.png` と `run.png`
- `exports/manifest.json`

シートは横8コマ、縦8方向です。方向は `front, down_right, right, up_right, back, up_left, left, down_left` の順に並べます。1コマの大きさはマニフェストの `frame_width` と `frame_height` から取得し、未指定の場合のみ 384 × 512 px とします。

マニフェストの `characters` は `id` と `label`、`motions` は `id` と `label` と `frame_ms` を持つ配列です。キャラクターやモーションはマニフェストから組み立てるので、追加キャラクターにも対応します。キャラクター名や性格設定を確定するものではありません。

## 操作

- キャラクターと歩行／走行を選択。
- 再生、一時停止、前後のコマ送り、指定コマの選択。
- 0.5〜2倍の再生速度、65〜135%の表示倍率。
- 暗色背景と明色の透過確認背景を切り替え。
- 空白キーで再生／停止、左右キーでコマ送り。入力欄やボタンにフォーカスがある場合は通常のキー動作を優先します。
- 選択中キャラクターの各 PNG シートと JSON 設定をダウンロード。

8方向を同じコマで表示します。画面の倍率・背景・再生速度はダウンロード素材を変更しません。OS の「視差効果を減らす」設定に相当する `prefers-reduced-motion` が有効な場合、初期表示は一時停止です。

## 表示上の注意

デスクトップでは4列、狭い画面では2列で表示します。内部データは元解像度のまま内蔵し、画面上の Canvas に縮小して描画します。初回ロード時には全キャラクターの歩行・走行画像を読み込むため、素材のファイルサイズに応じたメモリーを使用します。

制作メモは左右の装備を確認するための観点を示すものです。装備の非対称性や全コマの完成度を自動検証したという主張は含めていません。
