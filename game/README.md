## v0.11.0

### ダンジョン
7区画を連続攻略する。

1. 石の前室 — 艶沼ナメクジ / 沼
2. 湿った回廊 — 吸着羽虫 / 湿霧
3. 絹輪の間 — 絹輪ワーム / 輪紋
4. 胞子庭 — ルマネ胞子球 / 胞子
5. 粘花苑 — 粘花 / 花蜜
6. 夢鱗回廊 — 夢鱗蛾 / 夢鱗
7. 灰冠の深室 — 灰冠の粘魔 / 輪紋

敵編成全滅 → 階段発見 → アリアが自律移動 → 次区画。最深部制圧でクリア。

壁には実衝突があり、直進が塞がると斜め・横へ迂回する。

### 複数敵
`state.enemies` に複数体を保持し、`state.enemy` は現在の主対象として互換維持する。

- 後半区画は2〜3体編成
- 敵ごとに独立した詠唱・移動・HP・状態
- 非ターゲット敵にも攻撃予兆とHPバー
- 敵同士の重なりを解消
- アリアは距離、詠唱中、視界内、phase 2 を加味して対象切替
- 学習は種族別に保存

### モンスター7系統
灰冠の粘魔 / 艶沼ナメクジ / 吸着羽虫 / 絹輪ワーム / ルマネ胞子球 / 粘花 / 夢鱗蛾。

各種族は技名、射程、予兆時間、移動速度、拘束時間、Nutera / Sail / Lumane / Hypnosis / Charm の比率を分離。

吸着羽虫は付着後もSPとヌテラへ継続圧力をかけ、移動中は摩擦量が増える。

### ヌテラ方針
ヌテラは痛みではなく、ぬめりの強い摩擦、吸着、包み込み、柔らかな巻き付き、ガス/胞子、催眠/魅了で上昇する。牙、刃、棘による痛みを中心には使わない。

エステラ中は敵AIが漏出MPへ寄る行動を優先する。
