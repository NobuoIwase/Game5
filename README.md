# GAME5 — v0.22.0

戦乙女リアルタイム・コマンドRPG。ヒロインは直接操作せず、自律探索・自律戦闘する。プレイヤーは敵側ディレクターとして罠・環境干渉を配置できる。

現在のパイロット版は `game/`。

## ⚠ ChatGPT（および他のAI）への作業ルール — 必ず最初に読むこと

> 画像素材は、今後は**ローカルの Claude（デスクトップアプリ）がチャット版 ChatGPT を操作して作る**。手順は `LOCAL_CLAUDE_GUIDE.md`、検品は `python3 tools/check_final.py`、見本の画像は `game/asset-refs/png/`（`node tools/export_ref_png.js` で再出力）。

このリポジトリのコードは Claude Code が管理している。ChatGPT がコードや設定を書き換えると、ほぼ毎回ゲームが起動しなくなっている（v0.16.1 と v0.18.0〜v0.18.1 で実際に起きた）。**ChatGPT の担当は素材づくりだけ**とし、以下を守ること。

### 触ってはいけないもの（読むのは可）

| ファイル | 理由・実際に起きた事故 |
| --- | --- |
| `game/index.html` | 読み込み順が厳密に決まっている。2回とも存在しない `battle-utera.js` / `battle-utera-ui.js` に書き換えられ、ヌテラの中核が読み込まれずゲームが真っ暗になった。開始画面の説明や見た目の指定も消えた |
| `game/*.js`（すべて） | 既存の関数を外側から包む作りで、1か所の変更が別の層を壊す。新しい JS を追加して読み込ませることも禁止（v0.16.1 では宝箱・塔・ロゴが二重に描かれた） |
| `game/battle.css` | レイアウトが崩れる |
| `game/assets/*.png` と `game/assets/ext/` | 既存の絵。上書きしない |
| `tools/` | バランス検証用のシミュレーター |
| `character-motion-v1/` | アリアの原画・部位・モーション |
| `README.md`、`game/README.md` | 2回とも文字化けした状態で上書きされた。変更点は下の「連絡メモ」に書く |
| `.github/` | 公開の設定 |
| バージョン番号 | 上げない。版を切るのは Claude Code |

### 触ってよいもの

`game/assets/requested/` の中だけ。

- 完成した画像を `final/` の下に置き、`final/index.json` に名前を足す（置き場所は `game/asset-refs/README.md` §9）
- `species.json`（新モンスター）、`dialogues.json`（台詞）、`room_ideas.json`（区画の一言）の追加・編集
- `manifest.json` の `monsters` / `floors` / `species` の項目の追加（既存のキーは消さない）
- 連絡メモ `game/assets/requested/NOTES_FROM_CHATGPT.md` に、何を追加したかを書く

届いた素材の組み込み・バグ修正・README 更新は Claude Code が行う。

### 画像の条件

- **画像生成で描いた PNG** にする。SVG をコードで組み立てない
- **縮小・減色しない**。v0.18.0 の画像は魔物1体が約40px・16色まで落とされ、紫の点の集まりにしか見えず使えなかった
- **1体（1個）につき1ファイル**。格子状の1枚画像にまとめない（切り出し位置がずれる）
- **ドット絵にしない**。柔らかい手描きイラストで
- 魔物は 256×256px 以上、宝箱・塔・階段は 128px 以上、アイコンは 64px 以上
- **背景は完全な透過**（アルファ付き PNG）。白・黒の背景や、透過を表す市松模様を絵として描き込まない。地面の影・台座・枠・文字も入れない（床タイルだけは不透明）
- **形・配色・サイズは `game/asset-refs/` の見本（Claude 作成の SVG）に合わせる**。一覧は `game/asset-refs/index.html`、詳しい仕様は `game/asset-refs/README.md`
- 依頼文の雛形は `game/ASSET_REQUESTS.md`

### 文字化けを防ぐ

- 日本語を含むファイルは **UTF-8 のまま** 保存する。変換してからアップロードしない
- 既存のファイルを部分的に書き換えるツールで日本語ファイルを編集しない（v0.16.1 の `ASSET_PACK_v0161.md` と v0.18.1 の README が途中から化けた）

## v0.16.0 — ヌテラ・エステラ演出と ChatGPT 連携

### ヌテラ・エステラの演出（`game/nutera-fx-v016.js`）
本作の中心であるヌテラ・エステラに、桃色のハートを軸にした専用の見た目を付けた。
- ヌテラが増えるたびにハートが湧く（増えた量に比例、大きく増えると放射＋波紋）。数値は「♡+5.2」
- アリアの下のゲージをハート型のアイコン＋桃色のバーに変更。ハートは下から満ち、ヌテラが高いほど**鼓動が速くなる**。セイルの増幅はバー上の光の粒
- ヌテラ50%以上で周囲にハートが漂い、75%以上で画面の縁が鼓動に合わせて桃色に脈打つ（エステラ間近の警告）
- **エステラ発動**: ハートが全方位に弾け、大きなハートの閃光、「ESTELLA」の表示（アリアと重ならない側に出す）。発動中はハートがアリアの周りを回り、MP（青）とSP（橙）の粒が漏れ出し、画面の下からハートが立ち上る。終わるとハートがほどけて消える
- 欲求波の山で桃色の波紋、魅了された種族へハートが伝う糸、催眠の段階で頭上に紫の渦、輪紋は足元の回る紋章
- 右のパネルも、ヌテラ75%以上で枠が鼓動し、エステラ中は桃色に光って残り時間を強調

## v0.15.0 — 迷路と洞窟の地形生成

各区画は「1画面の広間に四角い壁が1〜2個」だったのを、**探索のたびに新しく生成される迷路・洞窟の地形**に変えた（`game/terrain-v015.js`）。画面は1画面のまま、30px の格子（32×18）で壁と床を作る。

### 階層ごとの個性

| 区画 | 地形 | 個性 |
| --- | --- | --- |
| 1 石の前室 | 広間と通路 | 4〜5個の部屋を幅3マスの通路で結ぶ。大きな部屋には柱 |
| 2 湿った回廊 | 水路の走る回廊 | 壁2マス厚の迷路＋ループ。通路に水路が走り、踏むと少し足が取られ波紋が立つ |
| 3 絹輪の間 | 同心円の回廊 | 中央の間を二重の輪の回廊が囲み、放射状の切れ目でつながる。隙間に絹糸 |
| 4 胞子庭 | 胞子の洞窟 | 有機的な洞窟。噴出口が数秒ごとに胞子を噴き、近くにいるとルマネ・セイルが上がる |
| 5 粘花苑 | 花苑の洞窟 | 中央の大きな花苑へ細いトンネルで入る洞窟 |
| 6 夢鱗回廊 | 迷宮 | ループの少ない本物の迷路。**一度見た場所も9秒で闇に戻る**（夢のように記憶が薄れる） |
| 7 灰冠の深室 | 柱の円形闘技場 | 1本のトンネルから入る楕円の闘技場。柱が6本の輪になって立つ |

- **探索の暗がり**: アリアがまだ見ていない場所は暗く、見た場所だけが明るくなる（境目はぼかしている）
- 入口・階段・敵の出現位置・環境ゾーン・宝箱・松明・クリスタルは、生成した地形に合わせて置く（階段は入口から最も遠い側）
- 壁は床と違う暗い岩肌。人工の区画は石積み、洞窟はなめらかな岩の輪郭。上の縁に明かり、下に高さのある側面と落ち影
- 区画に入る時のタイトルに地形の種類を表示

### 通れることの保証
体の大きな魔物（半径約30px）でも通れる幅（中心から壁まで1.5マス以上）で「実際に通れるか」を判定し、斜めの細い隙間でしかつながっていない領域は幅3マスの通路を掘って本体とつなぐ。

### 不具合修正
- **区画の敵を全滅させると、支援の敵が満タンのHPで再出現していた**（v0.11 から）。制圧後に編成の初期化がもう一度走っていた
- 突進技が壁を突き抜けて壁の中へ入ることがあった。壁の手前で止まるようにした
- 壁に埋まった物体を押し出す処理が、ループの範囲を押し出しながら広げていて無限ループになることがあった

### バランス（各60回の自動プレイ）
AUTO指揮OFF 約88%、AUTO ふつう 約30%。時間切れ・進行不能 0件。

## v0.14.0 — 床の作り直しと仕上げ

### 床
元の床タイルは石と石の間に太い黒の目地があり、Game4 の石板アトラスはマスが 64px の格子に揃っていない。そのまま並べると黒い帯・ひし形模様・ひび模様がランダムに混ざり、格子状のノイズに見えていた。

`game/floor-v014.js` で、区画ごとに床を一度だけ焼き上げる方式に変えた。
- 元画像から、目地や暗い帯を含まない「石の表面だけ」の範囲を画素の明るさで自動検出して質感に使う
- 不揃いな段違いの石畳に敷き、目地は細く、暗すぎない色にする
- 石ごとの色を区画の基調色に寄せ、最後に全体のコントラストと彩度を下げる（キャラと予兆がいちばん目立つように）
- 区画ごとの色味: 苔石（暖かい灰）／湿った回廊（青・水たまり）／絹輪の間（青灰・ひび）／夢鱗・深室（紫・薄い紋様）
- 内壁は同じ石で、上面と手前の側面がある立体の石塊として描く
- 毎フレーム数十枚のタイルを描く代わりに1枚を描くので、描画も軽くなった

`assets/requested/` に依頼した床を置いた場合は、焼き上げずに届いた絵をそのまま並べる。

### 仕上げ（`game/polish-v014.js`）
- アリアの吹き出し: 大事な場面の独り言だけを頭上に短く出す（普段の戦闘中の独り言は THOUGHT 欄のみ）
- 倒した魔物は、潰れながら消えるアニメーションで消える
- 開始画面に「これまでの探索」（最高到達区画・踏破回数・直近5回）を表示

- 画面全体をやや明るくした

### AI（`game/ai-v012.js`）
- アリアは主対象だけでなく**全敵の予兆**を知覚し、知識・集中・催眠・魅了に応じた反応遅延の後、16方向を評価して最も安全な回避先へダッシュ回避する。避け切れない時は堅守、詠唱中の主対象には盾撃で割り込む
- 壁で視線が切れる。A* 経路探索で壁を迂回し、環境ゾーン・霧・見抜いた影杭を避ける。何も感知できない時は部屋を探索する
- 拘束中はもがいて拘束時間を短縮。区画制圧後はSPが減っていれば小休止してから階段へ向かう
- 敵は役割別の間合い（近接／飛び回り型／遠距離／待ち伏せ）を取り、アリアを包囲するよう散開する。射程内の技だけを選び、同時詠唱数に上限を設け、編成が多いほど1体あたりの行動間隔が伸びる。深い区画ほどアリアの移動を先読みして狙う

## v0.11.0 — Dungeon / Monster Ecology

v0.11.0 では「1画面の戦闘試験」から「区画を連続攻略するダンジョン」へ拡張した。

- 7区画を自律攻略。敵編成を全滅させると階段を発見し、アリアが自分で階段へ移動して次区画へ進む。
- 部屋ごとに壁・通路・階段・沼・霧・胞子・輪紋・花蜜・夢鱗などの環境差を持つ。
- 壁衝突と回避ステアリングを実装。進路が塞がると斜め・横へ迂回する。
- 複数敵を同時運用。後半区画は2〜3体編成。敵同士の重なりも自動で解消する。
- アリアは距離だけでなく、詠唱中・視界内・phase 2 の脅威を加味して主対象を自動切替する。
- 敵ごとの攻撃学習を種族別に保持。支援敵の攻撃経験が別種族へ混ざらない。
- 全敵を実スプライトで描画し、非ターゲット敵にも攻撃予兆と個別HPを表示する。
- 拘束・粘霧・輪紋・環境床・照明を実グラフィック層へ統合。
