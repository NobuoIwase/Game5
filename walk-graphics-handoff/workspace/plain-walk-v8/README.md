# 歩行素体 08 — 首元の線を修正

斜め2方向で、首と胴体の境に出ていた濃い横線を修正しました。原因は胸郭画像の首の切り口に描かれた輪郭が、独立した首パーツの下に露出していたことです。

首の切り口を開いた素材を生成し、その上端2行の内側だけを既存の胸郭へ組み込みました。頭部の形・取付位置・首の高さ・歩行動作はv7を引き継いでいます。原寸で右斜め下6×2 px、右斜め上8×2 pxの修正です。元の透過輪郭と肩の位置も保持しています。

1歩4コマ、1周期8コマ、1コマ120 ms。各方向192×256 px、全40フレームの透過PNGです。`head-neck-comparison.png` はv7とv8の首元の比較です。画像生成の指示は `generation-prompts-v8.txt` に記録しています。

## 開く

`plain-walk-player.html` をブラウザーで開いてください。画像とコードは埋め込み済みで、サーバーやインストールは不要です。

- 5方向の同時再生、追加3方向だけの表示、1方向の拡大表示。
- 一時停止、コマ送り、8コマからの選択。
- 関節・接続線の表示。肘は橙、その他は緑です。
- 方向を選べる分割パーツ一覧。現在使っている足の差分を緑の枠で示します。
- 再生速度、腕振り、肘の曲げの変化量の調整とリセット。
- 現在の全5方向の関節・部品配置をJSONで保存。

動きを抑えるOS設定が有効な場合は停止状態で開きます。

## 向き

斜め方向はどちらも画面右へ進みます。「後ろ向き」は顔を奥へ向け、マップ上方へ進む向きです。

| 素材名 | 向き | スプライトシートの行 |
| --- | --- | --- |
| front | 正面・下 | 1 |
| down_right | 右斜め下 | 2 |
| side | 右向き | 3 |
| up_right | 右斜め上 | 4 |
| back | 後ろ向き・上 | 5 |

## 動作と見え方

- 頭・胸郭・骨盤は歩行に合わせて上下します。前へ出す脚は膝を伸ばしてから踵を着き、支持中から蹴り出しへ足首の向きが変わります。
- 上腕の振りに対し肘の曲げが少し遅れて変化します。標準設定は14〜42度。手首の角度も独立して変わります。
- 新しい3方向は、右向きと同じ脚の伸び・足の浮き・腕の角度を方向に合わせて投影しています。股関節を脚の起点にし、腕と胴の間の余裕を保ちます。
- 斜めでは手前と奥の腕・脚を描き分け、奥行きに応じて胸郭・骨盤との重なりを変えています。上腕と前腕は別々に重なりを判定します。
- 後ろ向きの頭・背中・骨盤・膝の裏は専用素材です。顔の点や正面の胸の陰影は描いていません。
- 首は各胸郭画像の実際の首の開口位置に接続します。首の上下端は胸郭と頭の奥へ重ねています。
- 正面側の足裏は着地前から踵の接地時、背面側の足裏は蹴り出しから脚を戻す初期に見えるよう、足の差分を切り替えます。

これはマップ移動に組み合わせるための、その場歩き素材です。マップ座標の移動や速度との同期はゲーム側で設定してください。

## 分割

1方向あたり17部位です。左右の腕・脚を含む29個の描画パーツを毎コマ組み立てます。正面と追加3方向には足の差分3枚ずつがあり、部位PNGは合計97枚です。

| 部位 | 素材名 |
| --- | --- |
| 頭・首 | head / neck |
| 胸郭・骨盤・腰関節 | upper_body / lower_body / waist |
| 肩関節・上腕・肘関節 | shoulder / upper_arm / elbow |
| 前腕・手首・手 | forearm / wrist / hand |
| 股関節・上腿・膝関節 | hip / thigh / knee |
| 下腿・足首・足 | shin / ankle / foot |
| 足の差分 | foot_heel / foot_swing / foot_toe |

腕は「肩→上腕→肘→前腕→手首→手」、脚は「股関節→上腿→膝→下腿→足首→足」です。足の差分名は形の名前で、実際の使用コマは各方向の `foot_assets` が指定します。

`far` / `near` は左右の部品IDです。旧正面では画面左／画面右、横向きでは奥／手前、新しい斜め方向ではニュートラル姿勢での奥側／手前側の列を表します。後ろ向きでは画面左／画面右です。歩行中に実際に前へ重なる側は奥行きで変わります。

## 調整・再利用

`parts/` が見た目、`config.json` と `rig.js` が動きです。別の見た目を同じ支点に合わせることで歩行を再利用できます。

`assets.json` の `pivot` は部位の支点です。斜め方向の頭は `attachment: skull_base` とし、画像の下端ではなく後頭部内側を支点にしています。上腕・前腕・上腿・下腿は `pivot` から `end` までを隣り合う関節間へ配置します。正面や斜めの `scale[1]` には奥行きによる短縮を含みます。

`rig.json` の `frames[方向][コマ].ops` は奥から手前の描画順です。各画像を `pivot` だけ引き、拡縮、回転、`position` への移動の順に描画します。角度は度単位で、画面上の正の回転は時計回りです。

足の描画IDは `foot_far` / `foot_near` のまま、`asset` が差分名に変わります。足首の `foot_pitch` は前後方向の角度、`foot_angle` は画面上の描画角度です。

新しい3方向の `yaw` は正面を0度として45・135・180度です。足の接地高さは `ground_center` と奥行き×`ground_depth` で決まります。斜め下では `foot_ground_slope` の傾きを持つ接地線に対し、足画像の実際の輪郭から支点の高さを求めます。`foot_pitch_scale` は足の絵に追加する回転の倍率です。遊脚の浮きは右向きの同じ位相を引き継ぎます。

胸郭の `neck_socket` は首の開口位置、斜め方向の `shoulder_sockets` は左右の肩口です。胸郭の回転・位置で変換して頸部を置き、`neck_tip_offset`、`head_offset` で首上端と頭の接続を調整します。腕の横方向の余裕は `front.arm_clearance` を追加3方向でも参照します。背面側の `hand_projection: forearm` は前腕に続く方向から手の角度を計算し、`wrist_flex_scale` で手首の曲げを調整します。

## 再生成

Python 3、Node.js、Pillow、NumPy、@napi-rs/canvas が必要です。

```bash
python -m pip install -r requirements.txt
npm install
python rebuild.py
```

アトラスからの切り出し、関節検証、40フレーム・プレイヤー・プレビューの生成を行います。プレイヤーと画像書き出しは同じ `rig.js` を使います。

素材PNGを直接差し替えた場合は `node render.cjs` と `python assemble.py` で出力してください。`rebuild.py` は元アトラスから `parts/` を作り直します。

## 確認

全40フレームの画素が一つにつながり、首や関節に分離した画素がなく、画面内に収まることを確認しました。正面・右向き・後ろ向き24フレームは前版v7との一致も確認しています。

斜め2方向の首パーツに、頭部・胸郭・腕で覆われず実際に見える画素が全8コマで残ることも検証しています。

関節の両端、首と胸郭の接続、肩口への登録、傾いた地面への足の接地・浮き、背面の手首の折れ角、共通の膝の伸びと肘のタイミングを検証しました。追加3方向の全8コマを見比べ、前後の重なりを確認しています。

5方向の再生、コマ送り、表示方向の絞り込み、関節表示、パーツの方向選択、腕振り・肘・速度の調整、リセット、5方向分のJSON保存をNodeのCanvas実装で確認しました。ブラウザー上のページレイアウトの実機確認はしていません。

部位絵は組み込み画像生成で作成し、切り出し・支点登録・歩行の組み立て・書き出しはコードで行っています。
