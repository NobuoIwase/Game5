# 依頼書：拘束・Hシーンの汎用モーション（Codex / GPT 向け）

作成：Claude（2026-09-26、v1）。参考資料は `references/restraint-v1/`（一覧は同フォルダの README）。

## 1. 目的

触手に捕まったときの拘束と、Hシーンの動き。アリアだけでなく**ほかのキャラクターにも使う汎用モーション**なので、骨格（関節の3D座標）で動きを決めてある。各キャラクターの原画・部位でこれに沿って描いてほしい。

**見せ方**：拘束されたら**正面（こちら）を向く**。体を見せるため。
- お尻を見せる前屈みの拘束（`show_rear`）だけは例外で、**斜め後ろ（`up_right`）または真後ろ（`back`）から見せる**。
- 各モーションの見せる方向は `motions.<id>.view` にある。

- **出力**
  - 各キャラクター・各モーションの、**見せる方向の1方向分**のシート：`exports/<character>/h_<id>.png`（横にコマ）
  - 個別コマ
  - `exports/manifest.json` への追記：`frame_ms` の配列、`loop`、`view`
- **コマの大きさ**：攻撃と同じ **576×576 px、透過**。足裏の基準点 `feet_anchor [288,470]`、体の大きさは歩きのシートと同じ。
- **描くのはキャラクターだけ**。触手はゲームが別に描く（拘束の位置は下の `binds`）。
  - 手首・膝などに巻き付いた触手の「くい込み」や、肌の押されたへこみは描いてよい。
  - 触手そのものは、別レイヤーのシートにできるならそれも歓迎する。
- **装備**：剣と盾は持たない（捕まった時点で落としている）。服はキャラクターごとの衣装のまま。

## 3. 骨格データ

`motion/restraint-poses.json`（生成元は `motion/restraint.mjs`、再生成は `node tools/render_restraint_svg.mjs`）。

- 形式・キャンバス（288×288、中心 x=144）・投影式は `motion/attack-poses.json` と同じ。576×576 のコマでは座標を2倍する。
- `poses.<id>.<direction>[frame]` の中身
  - `joints`：各関節の `position`・`depth`・`world`
  - `phase`：コマの狙い
  - `binds`：拘束
- 追加の関節
  - `face`：頭の中心から見ている方向へ9pxの点。うつむき・のけぞり・顔をそむける向き
  - `crotch`：股のすぐ下
- **拘束 `binds`**（触手の位置）
  - `joint` と `joint2`：2つの関節をまとめて縛る（後ろ手の手首どうしなど）
  - `joint` と `anchor`：関節をその点の方へ引く触手（上から吊る手首、横へ引く膝など）
  - `anchor`→`via`→`anchor2`：股の下を前から後ろへ通る触手（素股）
  - `anchor`→`via`：床から股へ伸びる触手（挿入）

  `anchor` などの名前は `joints` の中の点を指す。
- 骨格で新しく扱えるようにしたもの
  - 爪先を伸ばす角度（地面では爪先立ちになり、宙では爪先が下を向く）
  - 頭の傾き（前後・左右・ひねり）
  - 膝の向き（内股 ⇔ ガニ股）
  - 腰の左右の流れ

## 4. 動きの要点

1. **正面を向いて見せる**：顔・胸・腰がこちらに向く。身をよじっても、顔や肩は正面から大きく外さない（顔をそむけるのは首だけ）。
2. **内股**：
   - 拘束の最初は膝を寄せて閉じる。膝どうしが触れ、足先はハの字に離れ、爪先はやや内向き。
   - 脚を交差させないこと。膝どうしは触れる程度で、重ならない。
3. **ガニ股に開かれる**（`legs_forced_open`）：
   - 触手が膝に巻き付くと、いったん強く締めて抵抗する（1〜2コマ目）。
   - 膝から引き開かれ、足が外へ滑り、腰が落ちる（3〜7コマ目）。
   - 開かれたあとも膝が震え、閉じようとして（9コマ目）、また引き戻される（10コマ目）。
   - 膝は爪先と同じ外向きへ開く。
4. **力で抜けようとする**：
   - `arms_behind_wrench`：肩をひねり、胸を張り、押す側の爪先で伸び上がる。左右交互。抜けられずに力を抜く間もある。
   - `elbows_up_strain`：前腕を立てたまま、片腕ずつ引き下ろそうと力む。力むと背を丸めて膝を曲げ、触手が勝つと爪先立ちに引き上げられる。
5. **素股**（`rub_thrust`・`rub_thrust_closed`）：
   - 腰を前へ突き出すときは肩を後ろへ引き、腰を引くときは胸が前に出る（上体は腰と逆に動く）。
   - 頭は少し遅れてついてくる。
   - 内股版は太ももで挟んだまま小さく揺らし、突き出すたびに爪先立ちになる。
6. **挿入**（`ride_bounce`・`ride_bounce_arms_up`）：
   - 上下の揺れ。下では膝が曲がって体重が落ち、上では爪先立ちに持ち上げられる。
   - 頭と胸は少し遅れてついてくる。
   - 腕を吊られた版では、沈むたびに腕が伸びる。
7. **絶頂**
   - `climax_toes`：踵が上がり、脚が伸び、爪先をピンと伸ばして固まる（頂点）。そのあと小刻みな痙攣、力が抜けて膝が折れ、触手にもたれる。
   - `climax_arch`：腰を前へ突き出して背中が反り、頭を後ろへ投げ出す（頂点）。痙攣のあと、前へ崩れて膝が内に入る。
8. **お尻を見せる**（`show_rear`）：脚を伸ばしたまま上体を前へ倒し、腰を高く後ろへ突き出す。手首は床の前方に縛られる。腰を左右に揺らし、肩越しに振り返る。
9. **表情**：コマの狙い（`phase`）に合わせて変える。
   - 抵抗：歯を食いしばる／目をそらす
   - 素股・挿入：頬を染めて口が開く
   - 絶頂の頂点：目を見開くか固く閉じ、口を大きく開く
   - 余韻：焦点の合わない目

   表情はゲームの顔画像（`portraits`）の段階にも合わせる。
10. **二次の揺れ**：髪・胸・腰の布は、体の上下・前後の動きより1〜2コマ遅れて揺れる。
11. **痛み・流血の表現はしない**（ゲームの禁止事項）。縛られた部分は食い込みまでにとどめる。

## 5. 受け入れの確認

- [ ] 12モーションそれぞれ、見せる方向のシートがある（576×576・透過）
- [ ] 足裏が `feet_anchor` にあり、体の大きさが歩きのシートと同じ
- [ ] 正面向きのモーションで、顔・胸・腰がこちらを向いている
- [ ] 内股で脚が交差していない。ガニ股では膝が爪先と同じ向きに開いている
- [ ] 骨格データの腰・膝・足首・爪先の位置に沿っている（爪先立ち・爪先を伸ばすコマを含む）
- [ ] 拘束の位置（`binds`）に手首・膝などが来ている
- [ ] ループは最後のコマから最初のコマへ自然につながる
- [ ] 痛み・流血の表現がない
