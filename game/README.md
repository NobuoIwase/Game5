# Game5 battle pilot — v0.9.0

## 戦士モーション

戦士パイロットの基礎モーション一式をゲーム状態へ接続済み。

- 移動: 待機 / 歩行 / 走行 / 振り向き / 回避
- 攻撃: 通常斬り / 破城斬り / 盾撃
- 防御: 防御開始 / 防御維持
- リアクション: 被弾 / 気絶 / 拘束・もがき
- 特殊: エステラ発生・痙攣・復帰 / 敗北・脱力

歩行・走行は完成済み8方向スプライトを使用。攻撃・状態モーションは `character-motion-v1/parts/warrior/` の分離パーツと `rigs/warrior.json` の関節を利用する。

通常斬りは右腕を肩・肘・手首で実行時に分割し、剣を手首階層へ追従させる。技の命中モーションは実ゲームのcast完了へ同期。

`warrior-motion-timing.js` は必須15状態のQAマニフェストを公開し、`window.WarriorMotionQA.pass` で欠落状態と既存斬撃QAを確認できる。

検査: `../character-motion-v1/warrior-motion-lab.html`
