# GAME5 — v0.8.0

戦乙女リアルタイム・コマンドRPG。ヒロインは性格・視界・聴覚・記憶・学習に基づいて自律行動し、プレイヤーは敵側ディレクターとして敵・罠・環境を配置します。

現在のパイロット版は `game/` です。

## v0.8.0 — Graphics / Soft Monster Pass

- 生成素材をゲーム用アトラスへ切り出し・圧縮して `game/assets/` に実装。
- 石床3種、壁、階段、扉、結晶、沼、ガス噴出口、輪紋床、瓦礫を戦闘Canvasへ描画。
- 軟体モンスター用スプライトアトラスを実装。現在の敵「灰冠の粘魔」は青/紫の粘体表現。
- 敵の攻撃表現を痛み中心からヌテラ中心へ変更。
  - 粘膜包み
  - 滑走抱擁
  - 粘糸拘束
  - 濃密な粘霧
  - 共鳴波
- 直接HPダメージを低くし、SP・ヌテラ・拘束側を主軸に調整。
- 霧、毒気、柔らかな影、輪紋、紫の歪み、床光などのFXアトラスを実装。
- ヒロイン・燭台・結晶・敵フェーズに応じた暗所ライティングを追加。
- ライティング用オフスクリーンCanvasを再利用し、毎フレーム生成を廃止。
- 既存罠を新FXへ接続。瘴気/粘霧、影杭、囮、輪紋ビームの視認性を向上。
- 牙・棘・剣など「痛そうな敵グラフィック」は不採用。敵側は粘液、吸着、包み込み、絡みつき、ガス、催眠、柔らかな拘束を基本方針とする。
