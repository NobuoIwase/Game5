GAME5 / REAL-TIME COMMAND RPG

灰冠の試練

灰冠の呪術騎士様子をうかがっている
BATTLE PROTOTYPE 0.2

接触ではなく「技」で戦う。

敵味方ともに射程・詠唱・予兆・クールダウンを持ちます。敵はあなたの大技を見て回避や防御を行い、拘束・毒・沈黙・魔法も使います。

移動
WASD / 矢印
1〜4で操作キャラ切替
技
Q / E / R / F
下の技ボタンも使用可能
重要
敵に触れてもダメージなし。
赤い予兆だけが危険。
勝利条件
灰冠の呪術騎士を倒す。
詠唱は一部の技で中断可能。
VICTORY

灰冠を打ち破った

リアルタイム技選択・敵の予兆攻撃・状態異常・割り込みまでの戦闘縦切り試作です。

戦士アルド

前衛。近距離で敵の詠唱を止め、防御で味方を守る。

移動中でも技を選択可能。赤い予兆範囲から離れる／敵の詠唱中に「盾撃」「雷槍」で割り込み。
