# Game5

見下ろし型ゲームの制作資料とキャラクター移動素材。

- **動きの確認**：[軽量なモーション一覧](character-motion-v1/player.html)。戦士・獣人スカウト・汎用素体の歩行／走行を6ページに分割。各ページは約0.4〜0.82 MBで、1ファイルだけでも8方向を再生できます。
- **ゲーム用素材**：[透過PNGと個別コマ](character-motion-v1/exports/)。2キャラクター、歩行・走行各8方向×8コマ。
- **仕様・再出力方法**：[character-motion-v1/README.md](character-motion-v1/README.md)。装備の左右と現在の調整余地も記載しています。
- **引き継ぎ資料**：[walk-graphics-handoff](walk-graphics-handoff/)。提供されたZIPの内容。
- **画像制作の方針**：[ART_DIRECTION.md](ART_DIRECTION.md)。ユーザーの絵と、後から提供される参照画像を優先します。

キャラクター名や性格設定は仮の扱いです。移動素材は動作とデザインを比較するための初稿です。
