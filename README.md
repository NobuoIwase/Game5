# GAME5 — v0.15.0

戦乙女リアルタイム・コマンドRPG。ヒロインは直接操作せず、自律探索・自律戦闘する。プレイヤーは敵側ディレクターとして罠・環境干渉を配置できる。

現在のパイロット版は `game/`。

## v0.15.0 — 迷路と洞窟の地形生成

各区画は「1画面の広間に四角い壁が1〜2個」だったのを、**探索のたびに新しく生成される迷路・洞窟の地形**に変えた（`game/terrain-v015.js`）。画面は1画面のまま、30px の格子（32×18）で壁と床を作る。

### 階層ごとの個性

| 区画 | 地形 | 個性 |
| --- | --- | --- |
| 1 石の前室 | 広間と通路 | 4〜5個の部屋を幅3マスの通路で結ぶ。大きな部屋には柱 |
| 2 湿った回廊 | 水路の走る回廊 | 壁2マス厚の迷路＋ループ。通路に水路が走り、踏むと少し足が取られ波紋が立つ |
| 3 絹輪の間 | 同心円の回廊 | 中央の間を二重の輪の回廊が囲み、放射状の切れ目でつながる。隙間に絹糸 |
| 4 胞子庭 | 胞子の洞窟 | 有機的な洞窟。噴出口が数秒ごとに胞子を噴き、近くにいるとルマネ・セイルが上がる |
| 5 粘花苑 | 花苑の洞窟 | 中央の大きな花苑へ細いトンネルで入る洞窟 |
| 6 夢鱗回廊 | 迷宮 | ループの少ない本物の迷路。**一度見た場所も9秒で闇に戻る**（夢のように記憶が薄れる） |
| 7 灰冠の深室 | 柱の円形闘技場 | 1本のトンネルから入る楕円の闘技場。柱が6本の輪になって立つ |

- **探索の暗がり**: アリアがまだ見ていない場所は暗く、見た場所だけが明るくなる（境目はぼかしている）
- 入口・階段・敵の出現位置・環境ゾーン・宝箱・松明・クリスタルは、生成した地形に合わせて置く（階段は入口から最も遠い側）
- 壁は床と違う暗い岩肌。人工の区画は石積み、洞窟はなめらかな岩の輪郭。上の縁に明かり、下に高さのある側面と落ち影
- 区画に入る時のタイトルに地形の種類を表示

### 通れることの保証
体の大きな魔物（半径約30px）でも通れる幅（中心から壁まで1.5マス以上）で「実際に通れるか」を判定し、斜めの細い隙間でしかつながっていない領域は幅3マスの通路を掘って本体とつなぐ。

### 不具合修正
- **区画の敵を全滅させると、支援の敵が満タンのHPで再出現していた**（v0.11 から）。制圧後に編成の初期化がもう一度走っていた
- 突進技が壁を突き抜けて壁の中へ入ることがあった。壁の手前で止まるようにした
- 壁に埋まった物体を押し出す処理が、ループの範囲を押し出しながら広げていて無限ループになることがあった

### バランス（各60回の自動プレイ）
AUTO指揮OFF 約88%、AUTO ふつう 約30%。時間切れ・進行不能 0件。

## v0.14.0 — 床の作り直しと仕上げ

### 床
元の床タイルは石と石の間に太い黒の目地があり、Game4 の石板アトラスはマスが 64px の格子に揃っていない。そのまま並べると黒い帯・ひし形模様・ひび模様がランダムに混ざり、格子状のノイズに見えていた。

`game/floor-v014.js` で、区画ごとに床を一度だけ焼き上げる方式に変えた。
- 元画像から、目地や暗い帯を含まない「石の表面だけ」の範囲を画素の明るさで自動検出して質感に使う
- 不揃いな段違いの石畳に敷き、目地は細く、暗すぎない色にする
- 石ごとの色を区画の基調色に寄せ、最後に全体のコントラストと彩度を下げる（キャラと予兆がいちばん目立つように）
- 区画ごとの色味: 苔石（暖かい灰）／湿った回廊（青・水たまり）／絹輪の間（青灰・ひび）／夢鱗・深室（紫・薄い紋様）
- 内壁は同じ石で、上面と手前の側面がある立体の石塊として描く
- 毎フレーム数十枚のタイルを描く代わりに1枚を描くので、描画も軽くなった

`assets/requested/` に依頼した床を置いた場合は、焼き上げずに届いた絵をそのまま並べる。

### 仕上げ（`game/polish-v014.js`）
- アリアの吹き出し: 大事な場面の独り言だけを頭上に短く出す（普段の戦闘中の独り言は THOUGHT 欄のみ）
- 倒した魔物は、潰れながら消えるアニメーションで消える
- 開始画面に「これまでの探索」（最高到達区画・踏破回数・直近5回）を表示
- 再探索を押した直後、上部に旧版の敵名（灰冠の呪術騎士）が出ていた表示の不具合を修正
- 画面全体をやや明るくした

## v0.13.0 — Game4 からの移植と新要素

### Game4（ルミナ・サバイバーズ）から持ってきたもの
Game4 は成人向け作品のため、**性的な本文・場面・キャラクター画像は持ち込まず**、ゲームの仕組みと汎用の画像だけを移植した。

- **ディレクターの新しい罠**（Game4 の「夜側のアイテム」と召喚カードから）
  - `5` 粘沼 — 踏むと足が鈍り、SPとヌテラが少しずつ削れる
  - `6` 催眠の塔 — 3.6秒ごとに催眠の電波。アリアは塔を見つけると壊しに来る
  - `7` 偽りの宝箱 — 開けると拘束とヌテラ。一度引っかかると、次からは開ける前に確かめて見破ることがある
  - `8` 増援召喚 — その階層の魔物を1体呼ぶ（同時4体まで）
- **AUTO指揮の狙いのずれ** — Game4 と同じく、アリアが走っているほど設置位置が大きく外れる
- **画像** — VFX 7種（粘液の飛沫、衝撃の閃光、斬撃、浄化の波紋、月の爆光など）と、石板・月石の床タイル・泥沼のタイル（`game/assets/ext/`）

### Game5 の新要素
- **アリアの新技**: Lv5 旋風斬（周囲の敵すべてを斬り、詠唱を止める）、Lv6 清めの構え（ヌテラ・セイル・催眠を払い、吸着した魔物を振り落とす）。どちらもAIが状況を見て使う
- **宝箱**: 各区画に確率で出現。回復薬／清めの水／砥石（ATK+3）／集中の護符。アリアは安全な時か、制圧後に回収する
- **変異個体**: 第4区画以降、主敵が強化個体になることがある（HP×1.45、行動が速い、光の輪）
- **区画ごとの床テーマ**: 苔石・濡れた石板・青い石板・月石。内壁も同じ色調
- **画像の差し替え口**: `game/assets/requested/manifest.json` にファイル名を書くだけで、魔物の絵と床を差し替えられる
- **ChatGPT 向けのアセット依頼書**: `game/ASSET_REQUESTS.md`（床タイル、魔物の個別スプライト、宝箱・塔・階段、罠アイコン、追加キャラクター案、エフェクト。依頼文をそのまま貼れる形）

## v0.12.0 — Quality pass（AI・バランス・グラフィック・UI）

### 不具合修正
- 区画制圧後にアリアが階段へ移動せず、第1区画から先へ進めなかった問題を修正（`decideHero` の移動意図が破棄されていた）
- `index.html` が存在しない `battle-utera-ui.js` を読んでおり、ヌテラ系メーター・キー4・輪紋ビーム描画が動いていなかった問題を修正
- 攻撃・拘束・エステラ中の描画で毎フレーム例外（`scale is not defined`）が出ていた問題を修正
- 種族ヌテラが「基本値＋種族値」で二重加算されていた問題、ATKがダメージに反映されていなかった問題を修正

### AI（`game/ai-v012.js`）
- アリアは主対象だけでなく**全敵の予兆**を知覚し、知識・集中・催眠・魅了に応じた反応遅延の後、16方向を評価して最も安全な回避先へダッシュ回避する。避け切れない時は堅守、詠唱中の主対象には盾撃で割り込む
- 壁で視線が切れる。A* 経路探索で壁を迂回し、環境ゾーン・霧・見抜いた影杭を避ける。何も感知できない時は部屋を探索する
- 拘束中はもがいて拘束時間を短縮。区画制圧後はSPが減っていれば小休止してから階段へ向かう
- 敵は役割別の間合い（近接／飛び回り型／遠距離／待ち伏せ）を取り、アリアを包囲するよう散開する。射程内の技だけを選び、同時詠唱数に上限を設け、編成が多いほど1体あたりの行動間隔が伸びる。深い区画ほどアリアの移動を先読みして狙う

### バランス（`game/balance-v012.js`）
調整値はこの1ファイルに集約。`node tools/sim.js` で各80回の自動プレイにより検証した踏破率：

| 設定 | v0.11.0 | v0.12.0 |
| --- | ---: | ---: |
| AUTO指揮 OFF | 0% | 約85% |
| AUTO やさしい | — | 約65% |
| AUTO ふつう（初期値） | 0% | 約35% |
| AUTO きびしい | — | 約17% |

主な変更：エステラ後の短い鈍化時間とセイル半減（連鎖防止）、拘束解除直後1.6秒の拘束耐性、霧の毒を大幅軽減（痛みではなく粘性・ガスで追い詰める方針に合わせる）、レベル上限Lv8、階段での小休止、敵編成の難度曲線を 1,2,2,2,2,3,3 に平滑化。

### グラフィック（`game/fx-v012.js`）
- 区画ごとに床の変化・松明・クリスタル・瓦礫・入口を配置し、照明もそれに追従。内壁は石積みの質感と影つき
- 階段は制圧まで封印表示、制圧後は光ってアリアに方向矢印
- 予兆を効果別に色分け（拘束=紫、霧=緑、突進=橙、扇=赤、波=水色）し、内側の塗りで残り時間を表示。発動直前は白く点滅
- 読みやすいダメージ数字、ヒット粒子、斬撃の軌跡、画面揺れ、ヒットストップ、影、敵の名前／詠唱中の技名、アリアのSPゲージ
- 区画遷移のタイトルカード、区画制圧バナー、エステラ中・SP低下時の画面縁演出
- 灰冠の粘魔（灰色＋冠）・絹輪ワーム・粘花などを色で判別可能に

### UI（`game/ui-v012.js`）
- 一時停止（Space）、速度 ×1/×2/×4（F）、AUTO指揮の強さ（やさしい／ふつう／きびしい）。設定は保存される
- 複数敵の一覧（HP・行動・詠唱の残り時間）、罠ボタンのENコスト・クールダウン表示、キャンバス上の配置プレビュー
- 観測ログの色分け、結果画面に戦績（踏破区画・時間・与ダメージ・回避/被弾・エステラ回数など）

### 開発ツール
- `node tools/sim.js [回数] [--no-auto] [--intensity=easy|normal|hard] [--set=<JSON>]` — ブラウザなしでダンジョンを高速に自動プレイし、踏破率・敗因・SP/HP減少の内訳・被弾率を集計する
- `node tools/shot.js <出力先>` — Playwright でゲームを起動してスクリーンショットとコンソールエラーを取得する（`:8765` で静的サーバが必要）

## v0.11.0 — Dungeon / Monster Ecology

v0.11.0 では「1画面の戦闘試験」から「区画を連続攻略するダンジョン」へ拡張した。

- 7区画を自律攻略。敵編成を全滅させると階段を発見し、アリアが自分で階段へ移動して次区画へ進む。
- 部屋ごとに壁・通路・階段・沼・霧・胞子・輪紋・花蜜・夢鱗などの環境差を持つ。
- 壁衝突と回避ステアリングを実装。進路が塞がると斜め・横へ迂回する。
- 複数敵を同時運用。後半区画は2〜3体編成。敵同士の重なりも自動で解消する。
- アリアは距離だけでなく、詠唱中・視界内・phase 2 の脅威を加味して主対象を自動切替する。
- 敵ごとの攻撃学習を種族別に保持。支援敵の攻撃経験が別種族へ混ざらない。
- 全敵を実スプライトで描画し、非ターゲット敵にも攻撃予兆と個別HPを表示する。
- 拘束・粘霧・輪紋・環境床・照明を実グラフィック層へ統合。

### モンスター7系統

牙・剣・棘による痛みではなく、ヌテラは **ぬめり・摩擦・吸着・包み込み・柔らかな巻き付き・胞子/ガス・催眠/魅了** で上昇する。

| 種族 | 主な特徴 |
| --- | --- |
| 灰冠の粘魔 | ぬめり包み、粘膜拘束、粘霧、共鳴波 |
| 艶沼ナメクジ | 吸着巻き、ぬめり滑走、種族魅了 |
| 吸着羽虫 | 急降下吸着、まとわり吸着。付着中は移動で摩擦増加 |
| 絹輪ワーム | 長い全身巻き付き、輪動共鳴 |
| ルマネ胞子球 | 遠距離から Sail / Lumane を蓄積 |
| 粘花 | 待ち伏せ型。柔蔓絡み、花蜜霧、誘引花粉 |
| 夢鱗蛾 | Hypnosis 主体。夢鱗粉、催眠眼紋 |

エステラ中はモンスターが漏出MPへ寄る行動を優先する。
