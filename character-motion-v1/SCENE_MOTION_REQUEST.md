# 依頼書：床の姿勢・口づけ・拘束なしの姿勢・体に張り付く小さな生き物の汎用モーション（Codex / GPT 向け）

作成：Claude（2026-09-26、v1）。参考資料は `references/scene-v1/`（一覧は同フォルダの README、全モーションの一覧ページは `references/index.html`）。

## 1. 目的

キャラクターの姿勢と動きの追加分。
- 押されて床に倒れる、床の上で押さえられる、起き上がる
- 口づけ（相手の顔と触れている状態）
- 拘束のない立ち姿勢・座り姿勢
- 体に張り付く小さな生き物を払おうとする動き

アリアだけでなく**ほかのキャラクターにも使う汎用モーション**なので、骨格（関節の3D座標）で姿勢を決めてある。各キャラクターの原画・部位を、この骨格に沿って描いてほしい。

- **図の見方**：参考図は、`references/` のほかの資料と同じ無地のマネキン。青が本人の右半身、橙が左半身、紫が拘束、紫の点線の円が相手の頭。桃色の丸に羽が付いたものが、張り付く小さな生き物。
- **向き**：各モーションの向きは `motions.<id>.view` にある。
  - 床の姿勢と口づけは真横（`right`）
  - 膝を開いて押さえられる床の姿勢は斜め前（`down_right`）
  - それ以外は正面（`front`）
- **服装**：キャラクターごとの衣装のまま。剣と盾は持たない。
- **描かないもの**：拘束具・相手・張り付く生き物はゲームが別に描く。本人だけを描く。位置は下の `binds`。押さえられた手首や、生き物が張り付いた部分の、服のわずかな押されやしわは描いてよい。

## 3. 骨格データ

`motion/scene-poses.json`（生成元は `motion/scenes.mjs`、再生成は `node tools/render_scene_svg.mjs`）。

- 形式・キャンバス（288×288、中心 x=144）・投影式は `motion/restraint-poses.json` と同じ。576×576 のコマでは座標を2倍する。
- `poses.<id>.<direction>[frame]` の中身
  - `joints`：各関節の `position`・`depth`・`world`
  - `phase`：コマの狙い
  - `expr`：参考図に描いた表情の目安
    - `shut`：目を閉じる
    - `o`：口を開ける
    - `line`：口を結ぶ
  - `binds`：拘束・相手・生き物の位置
- 追加の点
  - `face`、`eye_left` / `eye_right`
  - `crotch`
  - `chest_left` / `chest_right` / `belly`：胸の左右と下腹。生き物が張り付く位置
- **`binds`**
  - `joint` と `joint2`：2つの関節をまとめる帯（後ろから抱きすくめられた両肘など）
  - `joint` と `anchor`：関節をその点へ押さえる・引く（床に押さえられた手首、左右へ開かれる膝など）
  - `partner`：相手の頭の中心（`anchor` の点）。本人の顔が触れる位置の目安
  - `creature`：その点に張り付いた小さな生き物。手の点（`hand_right` など）にあるときは、手でつかんでいる

## 4. 部位ごとの描き方

1. **床に倒れる**（`down_fall_back`）：
   - 押されて上体が後ろへ傾き、両腕が前に出る
   - 膝が抜けて手を後ろへつき、尻もちをつく
   - 背中から倒れ、頭が床に触れ、足が一瞬浮く
   - 仰向けで止まる
2. **仰向けで押さえられる**：
   - 手首は頭の上の床に押さえられ、腕は頭の両脇を通って上へ伸びる
   - 顔は横へそむける
   - `down_pinned_kick`：膝を立てた脚を片方ずつ蹴り上げ、腰をひねる
   - `down_pinned_spread`：立てた膝が左右へ開かれ、足裏どうしが近づく（M字）。閉じようとして膝がわずかに戻り、腰をよじる
   - `down_pinned_rock`：体全体が頭の方へ押されては戻る。頭は少し遅れて揺れ、押されたときに口が開く
3. **うつ伏せ**（`down_face_down`）：
   - 顔は床に向け、少し横を向く
   - 手首は頭の先の床に押さえられている
   - 膝から下を片方ずつ跳ね上げてもがく
4. **腰を上げる**（`down_hips_up`）：
   - 膝をついて太ももを立て、胸と顔を床につける
   - 手首は顔の前の床に押さえられている
   - 腰が前後に揺れ、そのたびに背中の反りが変わる
5. **起き上がる**（`get_up`）：肘と手で上体を起こす → 座る → 片膝を立てる → 立ち上がる。
6. **口づけ**（相手の頭は紫の点線の円。本人の顔がその円に触れている）：
   - `kiss_forced`
     - 顔を少し上に向けて相手に口を塞がれる
     - 両手で相手の胸を押し返す
     - 腰をよじる
     - 目は閉じ、口元は固い
   - `kiss_tension`
     - 押し返していた腕の力が抜ける
     - 爪先立ちでこわばり、手が開く（頂点）
     - 震える
     - 膝が内に崩れ、口で支えられるように前へもたれる
   - `kiss_respond`
     - 自分から爪先立ちで身を寄せ、首を傾ける
     - 両腕を上げて相手の首へ回す
     - 目は閉じ、表情は柔らかい
7. **拘束なしの立ち姿勢**：
   - `tempt_pose`
     - 脚を開いて腰を前に出し、ゆっくり左右に揺らす
     - 片手を胸に、もう片手を太ももに
     - 首を傾けて見下ろす
   - `chain_splay`
     - 膝ががに股に開いたまま、膝と腰が小刻みに震える
     - 腕は力なく垂れ、頭は後ろへ倒れる
   - `tension_free`
     - 胸と下腹を手で押さえてこらえる（膝が内に入る）
     - 背中を反らせて爪先立ち（頂点）
     - 震える
     - 膝から崩れて女の子座り
   - `sit_afterglow`：女の子座り（膝を前でそろえ、すねを左右の外へ流して床につける）で、肩を上下させて息をつく
   - `held_from_behind`
     - 後ろの相手に両腕ごと胴を抱えられ、腕は脇に付いたまま
     - 腰をひねり、片足ずつ浮かせてもがき、肩越しに振り返る
8. **張り付く生き物**（胸の左右と下腹。ゲームが描くので本人だけを描く）：
   - `clinger_peel`
     - 見下ろして気づく
     - 片手で胸の1匹をつかみ、体から引き離す
     - 手からはじかれて元に戻り、手が外へ跳ねる
     - 反対の手でも同じことをする
     - 最後に身をすくめ、下腹に両手を当てる
   - `clinger_tension`
     - 胸を両手で押さえてこらえる
     - 腕を後ろへ振り、背中を反らせて爪先立ち（頂点）
     - 震える
     - 座り込む
   - `clinger_accept`
     - 振り払うのをやめて腕を垂らす
     - 胸を前に出し、頭を後ろへ倒す
     - 腰をゆっくり揺らす
9. **体の後ろにある部位**：正面から見て胴体の後ろにある腕は、胴体の陰に隠れる（骨格の `depth` と胴体の向きで判断する）。
10. **表情**：`phase` と `expr` に合わせる。
    - 抵抗：口を結ぶ
    - 押される・揺れる：口が開く
    - こわばりの頂点：目を固く閉じて口を開く
    - 脱力：焦点の合わない目
    - 応える：穏やかに目を閉じる
11. **髪・服の揺れ**：体の動きより1〜2コマ遅れて揺れる。仰向けでは髪が床に広がる。
12. **痛み・流血の表現はしない**。

## 5. 受け入れの確認

- [ ] 18モーションそれぞれ、向きの1方向分のシートがある（576×576・透過）
- [ ] 体の大きさが歩きのシートと同じで、床の位置が `feet_anchor` にそろっている
- [ ] 骨格データの腰・膝・足首・爪先・頭・手首の位置に沿っている
- [ ] 押さえられた手首・膝が `binds` の位置にある
- [ ] 口づけのコマで、顔が相手の頭の位置（`partner`）に触れている
- [ ] 張り付く生き物・相手・拘束具を描いていない
- [ ] 体の後ろにある腕が胴体の前に出ていない
- [ ] ループは最後のコマから最初のコマへ自然につながる
- [ ] 痛み・流血の表現がない
