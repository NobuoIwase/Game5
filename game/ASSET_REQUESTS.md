# Game5 アセット依頼書（ChatGPT 向け）

> **ChatGPT へ**: 作業の前にリポジトリ直下の `README.md` 冒頭「ChatGPT への作業ルール」を読むこと。触ってよいのは `game/assets/requested/` の中だけ。画像は画像生成の PNG を、縮小・減色せず1体1ファイルで置く。

Game5 v0.16.0 で ChatGPT と連携できる部分の一覧です。画像（§1〜§7）に加えて、**新しいモンスターの設計そのもの**（§8）と、台詞・階層の案（§9）も頼めます。
各節の「依頼文」をそのまま ChatGPT に貼って使えます。

```
【共通仕様】
・用途: ブラウザ用 2D トップダウン（やや斜め上から見下ろす 3/4 視点）ダンジョンRPG

```

## 1. 優先度A — 区画ごとの床タイル ★

いまの床は、元の苔石と Game4 の石板から「石の表面」だけを切り出して区画ごとに焼き上げています。専用の床が届けば、それを並べた上に迷路・洞窟の壁を重ねます（地形は毎回生成されるので、床は模様の揃ったシームレスな素材が向いています）。
区画の名前に合う専用の床がほしい。

**形式**: 256×128px、64px のマスが 4列×2段。左3列が普通の床（6種）、右端の列が紋様入りの床（2種、まれに出る）。

| `floors/room1.png` | 石の前室 | 苔むした灰色の石畳。ところどころ湿った苔 |
| `floors/room2.png` | 湿った回廊 | 濡れて光る黒い石板。水たまりの反射 |
| `floors/room3.png` | 絹輪の間 | 白い絹糸が薄く張り付いた石床。紋様は輪 |
| `floors/room4.png` | 胞子庭 | 黄緑の菌床と石が混ざった床。紋様は胞子の輪 |
| `floors/room5.png` | 粘花苑 | 桃色の花弁と蔓が這う石床 |

**依頼文**
```
（共通仕様）
256×128ピクセルのトップダウン床タイルシートを作ってください。64×64のマスが横4列×縦2段です。

```

## 8. 優先度A — 新モンスターの設計を ChatGPT に頼む ★

モンスターは**データを置くだけで追加できます**（`species-v016.js`）。ChatGPT に下の書式で種族を設計してもらい、JSON を保存してください。絵があれば一緒に置きます（なければ既存の絵の色違いで出ます）。

### 置き方
1. ChatGPT の出力を `game/assets/requested/species.json` として保存（配列。何体でも可）
2. `game/assets/requested/manifest.json` に `"species": "species.json"` を足す
3. 絵を頼んだ場合は `monsters/<type>.png` に置き、JSON の `image` に書く

見本: `game/assets/requested/species.example.json`（鏡面スライム）

### 依頼文
```
ダンジョンRPG「Game5」の新しいモンスターを、下のJSON形式で3体設計してください。出力はJSON配列だけにしてください。

世界観:
・戦士アリアが7区画のダンジョンを降りる。魔物は牙や刃で傷つけるのではなく、粘液・吸着・柔らかい巻き付き・胞子・催眠でアリアを消耗させる
・アリアの敗北条件はSP（スタミナ）0。「ヌテラ」が100%に達すると「エステラ」（数秒の行動不能とMP/SP流出）になる
・既存の種族: 灰冠の粘魔、艶沼ナメクジ、吸着羽虫、絹輪ワーム、ルマネ胞子球、粘花、夢鱗蛾。これらと役割が被らないこと
・全年齢向けの表現にすること

形式（1体分）:
{
 "type": "英小文字のID",
 "name": "日本語名",
 "family": "英小文字の系統ID", "familyName": "〇〇種",
 "hp": 170〜400, "r": 20〜32（体の半径px）, "speed": 40〜110,
 "look": { "sprite": 0〜3, "filter": "CSSのfilter（色を変える。例 hue-rotate(120deg) saturate(1.2)）" },
 "image": "monsters/<type>.png",
 "role": { "pref": 好む間合いpx(90〜260), "ranged": 遠距離なら true, "dart": 攻撃直前に詰める間合いpx(省略可), "ambush": 待ち伏せ距離px(省略可), "label": "移動中の行動説明" },
 "weights": ["cleave","charge","bind","fog","bolt"] から5〜6個（多いほどよく使う）,
 "skills": {
   "cleave": 近接の扇形。{ "name", "cast": 0.5〜0.8秒, "range": 100〜150, "step": 0〜40 }
   "charge": 直線の突進。{ "name", "cast": 0.65〜1.0, "range": 240〜360, "width": 56〜90, "travel": 110〜210 }
   "bind":   円形の拘束。{ "name", "cast": 0.84〜1.1, "range": 240〜330, "r": 64〜90, "status": { "bind": 0.7〜2.4 } }
   "fog":    円形の霧。  { "name", "cast": 0.94〜1.2, "range": 330〜440, "r": 92〜120 }
   "bolt":   直線の波。  { "name", "cast": 1.0〜1.2, "range": 355〜460, "width": 64〜92 }
 },
 "nutera": { 技ごとに命中時の効果。"nutera": 4〜22, "sail": 3〜10, "lumane": 7〜24, "hypnosis": 7〜38, "charm": 8〜18 から1〜3個 },
 "floors": [出現する区画番号。0〜6。1体につき1〜2個]
}
区画番号: 0 石の前室(広間) / 1 湿った回廊(水路の迷路) / 2 絹輪の間(同心円) / 3 胞子庭(洞窟) / 4 粘花苑(洞窟) / 5 夢鱗回廊(迷宮) / 6 灰冠の深室(闘技場)
技の名前と見た目は、その魔物らしい柔らかい表現にしてください。
```

### 注意
- `floors` に書いた区画では、既存の支援の魔物1体と**入れ替わります**（編成の数は変わらないので難易度が大きく崩れない）。1体増やしたい時は `"mode": "add"` を付けてください
- 数値は上の範囲に収まっていれば、そのまま動きます。範囲外でも動きますが、バランスはシミュレーター（`node tools/sim.js`）で確認してから入れます

## 9. 優先度B — 台詞と階層の案 ☆

### アリアの台詞
いまの独り言は1場面1文です。場面ごとに3〜5種類あると、繰り返しが減ります。
```
戦士アリア（引っ込み思案、愛想笑いで緊張を隠す、戦闘の天賦は高い）の独り言を、次の場面ごとに5つずつ、20文字前後で書いてください。
場面: 初めて見る予兆 / 見たことのある予兆を避ける / 拘束されて動けない / ヌテラが高くなってきた / エステラから復帰した / 宝箱を見つけた / 偽物の宝箱に気づいた / 区画を制圧した / 迷路で敵を見失った / 囲まれた
全年齢向けで、戦闘中の短い独り言として自然にしてください。
```

### 第8区画以降の案
地形の生成方式（広間・迷路・同心円・洞窟・闘技場）と、階層の個性（水路・胞子の噴出口・記憶が薄れる迷宮など）の組み合わせで、新しい区画の案を頼めます。
```
トップダウンのダンジョンRPGの新しい区画を3つ考えてください。各区画について、名前、地形（広間と通路／迷路／同心円／洞窟／円形闘技場のどれか）、その階層だけの仕掛け（例: 水路で足が取られる、胞子の噴出口、見た場所が闇に戻る迷宮）、出現する魔物の方向性を、それぞれ3行で。
```

## 受け取ったら

1. `game/assets/requested/` の下に、表のファイル名で置く
2. ★の素材は `game/assets/requested/manifest.json` に1行足す（例は§1・§2・§8）
3. ☆の素材は置いたうえで「組み込んで」と依頼してください。コード側で繋ぎます
