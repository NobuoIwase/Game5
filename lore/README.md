# Game5 設定集（lore）

ChatGPT が設定を書き溜める場所です。Claude Code はここを読んで、新しい魔物・区画・台詞・演出をゲームに起こします。
**ゲームには直接は読み込まれません**。自由に書いてかまいませんが、次のルールは守ってください。

## ルール

- ここに置くのは **Markdown（.md）だけ**。画像・コード・JSON は置かない
- 文字コードは UTF-8。既存のファイルを丸ごと書き換えない。**追記する**（見出しに日付を付ける）
- 既に決まっていること（下の「決まっていること」）と矛盾する設定を書くときは、「案」と明記する
- ゲームの数値（HP・ダメージ・確率など）は書かなくてよい。Claude Code が調整する
- 露骨な性描写は書かない。雰囲気・生態・仕組みで表現する

## ファイルの分け方

| ファイル | 中身 |
| --- | --- |
| `world.md` | 世界観、灰冠の試練の由来、ダンジョンの成り立ち |
| `floors.md` | 区画ごとの設定（見た目、空気、住む魔物、仕掛け）。新しい区画の案もここ |
| `characters.md` | アリアと仲間候補（シスター・魔女・斥候）の性格、口調、関係 |
| `monsters/<type>.md` | 魔物1種につき1ファイル（下のテンプレート）。`<type>` は英小文字（例 `gazer.md`） |
| `systems.md` | ヌテラ・エステラ・ルマネ・催眠・魅了・セイル・輪紋の、世界の中での意味づけ |
| `ideas.md` | まだ形になっていない思いつき |

## 魔物のテンプレート（`monsters/<type>.md`）

```
# <和名>（<type>）

- 住む区画: 第N区画（なぜそこにいるか）
- 分類: 肉々しい／肌や粘膜に触れる／それ以外（色の方針に関わる。ピンクはこの前の2つだけ）
- 見た目: 形、大きさ、目、特徴。色（床の色と被らないもの）
- 生態: 何を食べ、どう増え、なぜアリアを狙うか
- 戦い方: 5つの技の案（近接・突進・拘束・霧・遠距離光線の5枠）と、それぞれの予兆
- ヌテラとの関わり: どの技で何が溜まるか（ヌテラ／ルマネ／催眠／魅了／セイル）
- アリアの反応: 初見の一言、2回目以降の一言（各1〜3行）
- NovelAI 用の色タグ案: 英語で1行（例 `glowing turquoise mushroom cap, wet violet gills`）
```

## 決まっていること（2026-09-26 時点）

- 主人公は戦士アリア。直接操作せず、自分で考えて戦う。プレイヤーは敵側の仕掛け（罠）を置く
- ダンジョン「灰冠の試練」は7区画。最奥に灰冠の粘魔（ボス）
- 区画: 1 石の前室 / 2 湿った回廊 / 3 絹輪の間 / 4 胞子庭 / 5 粘花苑 / 6 夢鱗回廊 / 7 灰冠の深室

- 色の方針: ピンク〜肉色は「肉々しい種」「肌や粘膜に直接触れる種」だけ。ほかは肉々しい質感で、色は別
- 見た目の見本: `game/asset-refs/`（形・配色）
