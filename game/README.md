# Game5 battle prototype

Game4の固定Canvas・状態管理・入力/UI分離を参考にしつつ、Game5では自動接触ダメージ型ではなく、ドラゴンクエストをイメージしたリアルタイム・コマンドRPG戦闘を試作しています。

## 戦闘の柱

- 敵に触れただけではダメージを受けない
- 敵味方の技は射程、詠唱時間、クールダウン、MPを持つ
- 敵の攻撃は扇・直線・円など明確な攻撃範囲を予兆表示する
- 拘束、毒、鈍足、沈黙、気絶、防御を実装
- 敵もプレイヤーの大技に対して回避・防御反応を行う
- 盾撃、雷槍、破城斬りなどで敵の詠唱を中断できる
- HP低下で敵が第二段階に入り、行動頻度が上がる
- 4人パーティをリアルタイムで切り替えて操作する

## 操作

- `WASD` / 矢印: 移動
- `1`〜`4`: 操作キャラクター切替
- `Q` / `E` / `R` / `F`: 各キャラクターの4技
- 画面下の技ボタン: マウス/タッチ操作
- スマートフォン: 方向パッド + 技ボタン

## パーティ

- 戦士アルド: 近接、詠唱中断、防御
- 斥候ミラ: 遠距離、毒、拘束
- 魔女セラ: 火・氷・雷・大魔法
- シスター・ノア: 攻撃魔法、回復、浄化、聖域

## 現在の敵

灰冠の呪術騎士。大薙ぎ、灰槍突進、影縛り、蝕毒の霧、黒雷を使います。攻撃は接触判定ではなく、各技固有の範囲判定で成立します。

## 起動

静的HTTPサーバーから `game/index.html` を開きます。GitHub Pagesではリポジトリ直下の `index.html` から `game/` に転送します。
