# Game5 Dungeon System — v0.11.0

Date: 2026-09-23  
Model: GPT-5.6 Sol

## 目的

Game5 を1画面の戦闘試験から、アリアが自律探索・自律戦闘しながら複数区画を降りるリアルタイムダンジョンへ拡張する。

プレイヤーはアリアを直接操作しない。敵側ディレクターとして罠・環境干渉を配置でき、AUTOへ委任もできる。

## 進行

1. 区画へ入る
2. アリアが視界・聴覚・記憶を使って探索する
3. 敵編成と接触すると自律戦闘する
4. 敵編成を全滅させる
5. 階段を発見し、アリアが自分で階段へ移動する
6. 次区画へ移る
7. 最深部制圧でクリズ

壁には実衝突があり、進路が塞がる場合は斜め・横へ迂回する。敵も同じ壁制約を受ける。

## 複数敵互換層

`state.enemies` に全敵を保持し、従来の `state.enemy` は現在の主対象として維持する。

アリアは以下を加味して主対象を自動で切り替える。

- 距離
- 詠唱中か
- 視界内か
- phase 2 か

各敵は独立してHP、詠唱、移動、状態、予兆を持つ。敵同士が重なった場合は押し分ける。

## 種族別学習

学習値は `knowledgeBySpecies` に保存する。

ナメクジの拘束を学習しても、初見のワーム拘束へそのまま完全適用はしない。同種または類似種との経験として蓄積し、現在対象の種族へフォーカスしてAI判断へ渡す。

## モンスター7系統

ヌテラは痛みではなく、ぬめりの強い摩擦、吸着、包み込み、柔らかな巻き付き、胞子/ガス、催眠/魅了で上昇する。

### 灰冠の粘魔
ぬめり包み、滑走抱擁、粘膜拘束、濃密な粘霧、共鳴波。

### 艶沼ナメクジ
粘尾なで、ぬめり滑走、吸着巻き、粘液膜、誘引しずく。種族魅了を得意とする。

### 吸着羽虫
羽擦り、吸着急降下、まとわり吸着、湿った鱗粉、誘眠瞬き。身体へ付着した後も継続的にSPとヌテラへ圧力をかけ、移動中は摩擦量が増える。

### 絹輪ワーム
体擦り、柔輪すべり、全身巻きつき、湿り気の膜、輪動共鳴。長めの拘束を得意とする。

### ルマネ胞子球
胞子吐息、ふわり接近、浮遊膜、甘い胞子霧、ルマネ波。遠距離から Sail / Lumane を積み上げる。

### 粘花
花弁なで、蔓のすべり寄せ、柔蔓絡み、花蜜霧、誘引花粉。低速の待ち伏せ型。

### 夢鱗蛾
鱗粉の羽撫で、漂い接近、羽膜包み、夢鱗粉、催眠眼紋。Hypnosis を主軸とする。

## エステラ連携

エステラ中は敵AIが通常の間合い管理より漏出MPへの接近を優先する。

環境床も Nutera / Sail / Lumane / Hypnosis / Charm を組み合わせ、敵と環境が別々の経路からエステラを狙う。
