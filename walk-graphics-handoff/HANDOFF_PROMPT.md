# 次の担当へ渡すコンテキスト

このZIPの歩行グラフィック制作を引き継いでください。現在の基準は `workspace/plain-walk-v13/` です。まず `plain-walk-player.html` と斜め歩行GIF、`docs/01_GOAL_AND_DECISIONS.md`、`docs/02_ASSEMBLY.md` を確認してください。

元は添付の天使キャラクター「ルミナ」の歩行制作でした。正面・横向きの修正を重ねた後、ユーザーの指示で頭・胴体・骨盤・上腕・前腕・手・上腿・下腿・足・各関節を分けたプレーンな素体へ一般化しました。現在は正面、右斜め下、右、右斜め上、後ろの5方向です。1歩4コマ、左右合わせて8コマ、120 ms/コマ、補間なし。その場歩きで、マップ移動処理は含みません。

見た目を重視してください。撫で肩、短めの胴・骨盤、腕と胴体の余裕、細く緩い曲線の腕、股関節からの脚運び、前脚を伸ばしてから踵を着く動き、肘と手首の時間差、足裏・踵・蹴り出しの変化が重要です。骨格計算が通るだけでは十分ではありません。

特に斜めの首と頭で修正が続きました。斜めの頭の高さは他方向に揃えません。胴体に描かれた首へさらに棒を継ぎ足して頭を浮かせないでください。首の起点は肩の間、頭の支点は頭蓋底です。首の線・突起・消失と、顔の向き・耳・顎・後頭部の関係も見てください。

v9で頭が前へ出すぎたため、ユーザーに従って段階的に背中側へ戻しました。最終v13の `neck_tip_offset` は down_right = `[-2,-9]`、up_right = `[-3,-11]`、両方 `head_offset=[0,0]`、頭のpivotは `[26,60]` です。最後の指示は「あともう2px」で、両方をv12から画面左へ2 px動かしました。高さ・胴体・腕・脚は維持しました。v13をユーザー承認済みと断言しないでください。

少量の位置調整では現在の設定から差分を加えます。さらに背中側へ2 pxなら、それぞれの `neck_tip_offset[0]` から2を引きます。Yを変えず、首の接続と頭を一緒に動かします。画像の描き直しは位置調整とは別の作業です。

`config.json` は動きと位置、`assets.json` は部品寸法・pivot・接続口、`rig.js` は骨格・重なり・描画、`rig.json` は全40コマの計算済み配置です。描画ではopsを配列順に奥から手前へ置き、pivotを引き、scale→rotate→translateします。ops.positionは計算済み画面座標で、parentの移動を二重に加えません。

正面と横向きは以前「だいぶ良くなった」と評価された流れを保っています。新しい方向の修正で他方向を一括変更しないでください。元ルミナの衣装・翼・髪の素材は別の履歴に残っていますが、最新の素体の肘・脚の動きを昔の試作へ巻き戻さないでください。
