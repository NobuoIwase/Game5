# GAME5 — v0.7.0

見下ろし型リアルタイム・コマンドRPG。ヒロインは性格・視界・聴覚・記憶・学習に基づいて自律行動し、プレイヤーは敵側ディレクターとして敵・罠・環境を配置する。

現在のパイロット版は `game/`。

## v0.7.0 — Warrior Motion baseline complete

戦士アリアのパイロット用モーション一式を接続した。

- 待機、歩行、走行、振り向き、回避
- 通常斬り、破城斬り、盾撃、防御
- 被弾、気絶
- 拘束、もがき
- エステラ、エステラ後復帰
- 敗北・脱力
- 8方向対応
- walk/run は既存8方向×8コマ完成スプライトを使用
- slash/heavy は既存リグの肩・肘・手首を利用した関節カットアウト
- その他状態は方向別の腕・脚・胴・剣・盾パーツを組み合わせる状態レンダラー
- `character-motion-v1/warrior-motion-lab.html` で0.5x/1x/1.5x/2x、停止、コマ送り、8方向を確認可能

この時点を「戦士の基礎モーション一式完成」とする。今後追加する敵固有拘束、表情、髪・布の二次揺れ、高等技専用演出は基礎モーションの未完成ではなく個別拡張として扱う。
