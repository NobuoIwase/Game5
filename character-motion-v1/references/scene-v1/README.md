# 床・口づけ・拘束なし・張り付きのモーション参考資料 scene-v1

依頼書は `../../SCENE_MOTION_REQUEST.md`。全モーションを動かして見られる一覧ページは `../index.html`。

`motion/scenes.mjs` の骨格を `tools/render_scene_svg.mjs` で描いたマネキン図。
- 青は本人の**右**半身、橙は**左**半身
- 紫は拘束（関節に巻いた輪と、押さえる先へ伸びる線、2つの関節をまとめる帯）
- 紫の点線の円は、口づけの相手の頭
- 羽の付いた桃色の丸は、体に張り付く小さな生き物
- 顔の目と口は `expr` の目安（閉じた目、開いた口、結んだ口）
- コマは 288×288（ゲーム用は2倍の 576×576）

| ファイル | 内容 |
|---|---|
| `<id>_keys_<view>.svg` | 見せる向き（真横 `right`・斜め前 `down_right`・正面 `front`）の全コマを大きく並べ、各コマの狙いと表示時間を書いたもの。赤い点線は腰の動きの軌跡 |
| `<id>_keys_down_right.svg` / `<id>_keys_right.svg` | もう1つの向き（真横のモーションは斜め前、それ以外は真横） |
| `<id>_sheet.svg` | 4方向×全コマ |
| `<id>_preview.svg` | ブラウザで開くと4方向が動くアニメーション |

`<id>` は依頼書の表のとおり25種類。
