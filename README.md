# Game5 — v0.3.0

見下ろし型ダンジョンRPG。主人公チームは性格・知覚・記憶・学習をもとに自律行動し、プレイヤーは敵や罠を配置します。配置も AI に任せられる構成を目指します。

現在は `game/` に戦士1人のパイロット版を実装しています。v0.3.0 では、リアルタイムの間合い/踏み込み/命中判定、HP/MP/SP、視界と聴覚、敵知識の学習、レベル/技習得、敵の明確な攻撃範囲・拘束・状態異常、敵側の罠配置/AUTO指揮、観測HUDを追加しました。

詳細: [`game/README.md`](game/README.md)
