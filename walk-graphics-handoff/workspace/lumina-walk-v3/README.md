# ルミナ 歩行グラフィック試作 03

正面（マップ下方向）と右向き。部位素材を組み合わせた8コマの歩行ループです。

## 今回の修正

- 正面の腕は反対側の脚と連動し、前後へ交互に振ります。前後の奥行きに応じて腕の見かけの長さを変え、引いた腕はスカートの奥、前へ出した腕は手前に描きます。肩支点は胴に追従します。
- 手を含む左右の腕を描き直しました。指は下向きに揃え、右向きの両手は親指を進行方向側に配置しています。輪郭色も既存素材の薄紫に合わせました。
- 横向きの腰を後ろへ戻し、上半身を腰の支点から6度前傾させました。首・肩・翼の位置を同じ胴体から計算し、姿勢の変更で首が外れないようにしています。
- 足首を固定せず、踵からの着地、足裏での支持、踵の持ち上げ、つま先での蹴り出し、遊脚を区別しました。脚は一枚の素材を連続して変形し、膝と足首に切り口を作りません。
- 1歩4コマ、1周期8コマ、1コマ120 ms（約8.33 fps）。補間はしません。

## 再生

`lumina-walk-player.html` をブラウザーで開いてください。画像は埋め込み済みです。再生・停止、1コマ送り、フレーム選択、速度変更、部位一覧を操作できます。OSの動きを抑える設定が有効なら停止状態で開きます。

`lumina-walk-preview.gif` は背景付きの比較用GIFです。影とマス目は確認用で、素材PNGには含みません。

## 素材

| ファイル | 内容 |
| --- | --- |
| lumina-walk-spritesheet.png | 8列×2行、1536×512 px。上段が正面、下段が右向き。各行を左から右へ再生 |
| lumina-front-8frames.png / lumina-side-8frames.png | 方向別の8コマ横並び |
| lumina-front-walk.png / lumina-side-walk.png | 透過APNG。非対応ビューアーでは先頭コマのみ表示 |
| frames/front/、frames/side/ | 各方向の独立した透過PNG、00〜07 |
| parts/front/、parts/side/ | 組み立て用PNG。横向きの脚は元画像と8種類の変形済み画像を含む |
| rig.json | 部位画像、支点、座標、角度、スケール、描画順、腕の奥行き、足首角度 |
| source-atlases/ | 元の部位素材と今回描き直した腕の素材 |
| generation-prompts.txt / generation-prompts-v3.txt | 素材生成のプロンプト |

各コマ192×256 px、透過RGBAです。足元の地面は y=242。マップ上でのキャラクター移動は含まない、その場歩き素材です。頭と輪は一体、前髪は頭に含みます。

far / near は、正面では画面左 / 右、横向きでは奥側 / 手前側を表します。右向きの両脚の足先はいずれも画面右へ向いています。

## 調整・再出力

Python 3、Pillow、NumPy が必要です。

```bash
python -m pip install -r requirements.txt
python rebuild.py
```

同じフォルダーのPNG、GIF、リグ、プレイヤーを上書きします。`pose_front` の腕の奥行き、`pose_side` の胴体姿勢と足首角度、`whole_leg` の連続変形、`DURATION` のコマ時間を調整できます。

リグは各フレームの配列順に背面から描画します。ローカル支点を引き、スケール、回転、座標移動の順で変換します。角度は度単位です。`hierarchy` は連動関係の説明で、描画用の変換値は計算済みです。

## 確認した内容

正面の腕・横向きの姿勢と手・両方向の足を全8コマ拡大して確認しました。支持中の足の最下端は全コマ y=242、遊脚の最下端は y=231〜239です。脚の画像に穴や分離した画素がないことも確認しています。キャンバス再生のコマ送り、再生、速度変更、部位表示を確認しました。

素材の描画には組み込み画像生成ツールを使用し、切り出し・部位の変形・アニメーションの組み立てにはコードを使用しています。
