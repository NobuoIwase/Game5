# Game5 アセット参考画像（Claude 作成）

ChatGPT などの画像生成に頼む素材の**見本**です。形・配色・大きさ・向きはこの SVG に合わせてください。
画像生成では、この見本の**線や塗りをそのまま写すのではなく、同じデザインで手描きイラストとして描き直す**のが目標です。

- 一覧（ブラウザで開く）: `game/asset-refs/index.html`
- 各カード: 左が見本（市松模様＝透過部分）、右がファイル名・サイズ・配色（hex）・注意点
- `sprites/` はカードの枠を外した見本そのもの。**本番の絵が届くまでゲーム内でこれを使っています**
- 見本の作り直しは `python3 tools/make_asset_refs.py`（SVG はすべてこのスクリプトから出力。直接編集しない）
- チャットに添付する PNG 版は `png/`（`card_<名前>.png` がカード、`<名前>.png` が絵だけ）。SVG を直したら `node tools/export_ref_png.js` で出し直す

> ChatGPT へ: このフォルダは**読むだけ**。書き換え・追加はしないこと。作った画像の置き場所は下の「納品のしかた」を参照。

## 1. v0.18 のドット絵は作り直し

v0.18 で届いた `generated/monsters_v018.png`・`extras_v018.png` は、1体が約40px・6〜8色まで縮小されていて、拡大しても**何の絵か分かりませんでした**。v0.19 で機械的に補正して使いましたが、判読できないため v0.20 で使用をやめ、補正版（`processed/`）も削除しました。

**魔物11種・宝箱・偽りの宝箱・階段・催眠の塔・粘沼は、すべて描き直しをお願いします。**

作り直しの条件:

| | ダメだった点（v0.18） | 今回の条件 |
| --- | --- | --- |
| 大きさ | 1体 約40px | 魔物 **256×256px**、小物は表のとおり。**描いたあとに縮小しない** |
| 色数 | 6〜8色＋ディザ（点々） | 減色しない。なめらかなグラデーションのまま |
| まとめ方 | 1枚の格子に全員 | **1体（1個）＝1ファイル** |
| 画風 | ドット絵 | **ドット絵にしない**。柔らかい手描きイラスト（見本のような太めの輪郭＋2〜3段の陰影） |
| 背景 | 一部が不透明 | **完全な透過**（次の節） |

## 2. 背景透過のルール（必須）

届いた画像の背景が透けていないと、ゲームでは魔物の周りに四角い箱が出てしまいます。次を必ず守ってください。

1. **本物のアルファチャンネル付き PNG**（RGBA）で保存する。JPEG・WebP は不可
2. 背景は**完全に透明**（アルファ 0）。白・黒・灰色・単色の背景を塗らない
3. **市松模様（グレーと白のチェック）を絵として描き込まない**。画像生成でよく起きる失敗で、見た目は透過っぽいのに実際は不透明な模様になる。見本の市松模様は「ここは透明」という意味の表示でしかない
4. 地面の影・台座・床・枠線・文字・署名を入れない（影はゲームが描く）
5. 輪郭の外側に**白いフチ（ハロー）を残さない**。暗い背景に置いたとき白い線が出ないこと
6. 絵の周りに**上下左右 8〜12% の余白**。ただしはみ出し（見切れ）は不可
7. 例外: **床タイルだけは不透明**（全面を塗る）

納品前の確認: 画像を**黒い背景と白い背景の両方**に置いて、四角い枠・白いフチ・チェック模様が見えないこと。

## 3. 共通の画風

- 視点: やや上から見下ろす 3/4 視点（床と小物は真上）。光源は**左上**
- 輪郭: 暗い色（その魔物の一番暗い色、真っ黒ではない）で太さ 3〜4px（256px 時）
- 陰影: 2〜3段＋左上に白いツヤ。スライム系は半透明感
- 雰囲気: **柔らかい・丸い・少しかわいい**。牙・刃・棘・血・目玉がたくさん、などの怖い表現はしない
- 顔: 丸い目2つ＋ハイライト。口はほぼ描かない
- 彩度: 1体につき強い色は1か所まで（例: 灰冠の粘魔は紫の核だけ）。床より明るく、キャラより目立ちすぎない
- 接地: 地面に立つ魔物は**足元を画像の下端近く**（下から約15%）にそろえる。浮遊する魔物は下に少し余白

## 9. 納品のしかた

1. 完成した画像を `game/assets/requested/final/` の下に、上の表のパス（例 `final/monsters/slug.png`）で置く
2. `game/assets/requested/final/index.json` の該当する配列に名前を足す（例: `"monsters": ["slug"]`、`"props": ["tower", "pool"]`）
3. `game/assets/requested/NOTES_FROM_CHATGPT.md` に、何を置いたか書く

いま `index.json` の名前で自動的に差し替わるのは、魔物11種・`tower`・`pool` です。それ以外（宝箱・階段・ヌテラ・アイコン・床）は、置いてもらえれば Claude Code が組み込みます。
コード・`index.html`・このフォルダには触らないこと（リポジトリ直下 `README.md` の作業ルール）。
