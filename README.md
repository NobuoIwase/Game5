# GAME5 — v0.10.1

戦乙女リアルタイム・コマンドRPG。ヒロインは性格・視界・聴覚・記憶・学習に基づいて自律行動し、プレイヤーは敵・罠・環境を配置します。パイロット版は戦士1人で開発中です。

## v0.10.1 — Real Graphics Integration

戦闘画面の仮描画を、既存の実画像アセットを使う描画経路へ接続しました。

- `game/assets/dungeon.png` を床・壁・階段・扉・結晶・沼・ガス噴出口・輪紋床・瓦礫として本編へ直接描画
- `game/assets/enemies.png` を現在の敵「灰冠の粘魔」の実スプライトとして使用
- 通常 / phase 2 / 粘糸拘束 / 粘霧 / 共鳴波の状態で敵スプライトと周辺FXを切替
- 拘束時は敵とヒロインの間に柔らかい粘糸リボンを描画
- `game/assets/fx.png` を霧・輪紋・罠・発光・エステラ歪みに使用
- 戦闘レンダリング順を `床 → 罠下層 → 攻撃予兆 → ヒロイン → 敵 → 拘束 → 罠上層 → 大気FX → ライティング` に整理
- ヒロイン中心の視認域、固定光源、周辺暗化を画像レイヤーと合成
- 従来の円形敵描画・単色床はアセット未読込時だけのフォールバックへ変更

グラフィック実装本体:
- `game/battle-render.js`
- `game/graphics-enhance.js`
- `game/graphics-live-v0101.js`

既存の戦士モーション、攻撃リーチ、踏み込み、敵攻撃予兆、ヌテラ/エステラ系システムは維持しています。
