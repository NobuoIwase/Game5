# Warrior Motion Plan — v0.7.0

Date: 2026-09-23  
Model: GPT-5.6 Sol

## 完成基準

パイロット版の戦士アリアについて、ゲーム中に必要な基礎状態が一通り視覚的に切り替わり、8方向で破綻しないことを基準とする。

## 完成した基礎モーション

1. 待機 — 呼吸、微小な重心移動
2. 歩行 — 8方向×8コマ完成スプライト
3. 走行 — 8方向×8コマ完成スプライト
4. 振り向き — 停止中の方向変更
5. 回避 — 高速退避・予兆回避
6. 通常斬り — 肩→肘→手首→剣
7. 破城斬り — 大振り・長い予備動作
8. 盾撃 — 盾腕の踏み込み
9. 防御 — 盾構え保持
10. 被弾 — のけぞり
11. 気絶 — 重心崩れ
12. 拘束/もがき — 四肢の非同期抵抗
13. エステラ — onset / loop /収束
14. エステラ後復帰 — 脱力から姿勢復帰
15. 敗北 — 転倒・脱力

## 資産方針

戦士は8方向それぞれに次の透明PNGを持つ。

`body / arm_left / arm_right / leg_left / leg_right / sword / shield / scabbard`

歩行・走行は既存完成スプライトを優先し、戦闘・状態モーションでのみパーツリグを使用する。

通常斬り・破城斬りは `rigs/warrior.json` の shoulder / elbow / wrist と腕polygonを使用し、既存 `arm_right.png` を実行時に上腕・前腕・手へ切り分ける。これにより肩一軸の棒振りを避ける。

## 歩行制作時から継承する基準

- 撫で肩を維持し、首を棒状に伸ばさない
- 脚は股関節から運ぶ
- 前脚伸展 → 踵接地 → 支持 → 蹴り出しを読む
- 腕は肩だけでなく肘・手首に遅れを持たせる
- 斜め方向の頭を全方向で無理に同じ高さへ強制しない
- 方向ごとの装備レイヤー順を尊重する

## 本編への接続

`game/warrior-motion.js`
- 既存の関節斬撃、拘束、エステラ

`game/warrior-motion-extra.js`
- 待機、振向、回避、盾撃、防御、被弾、気絶、復帰、敗北の状態描画

`game/warrior-motion-hooks.js`
- 実ゲームのskill / hurt / stun / guard / dodge / Estella終了 / defeatと描画状態を結ぶ

`battle-render.js`
- 状態モーションが無い移動時はwalk/runへフォールバック

## 検査

`warrior-motion-lab.html` で以下を選択可能。

`walk / run / idle / turn / dodge / slash / heavy / bash / guard / hit / stun / bind / estella / recovery / defeat`

各状態は8方向、0.5x / 1x / 1.5x / 2x、停止・コマ送りで確認する。

v0.6時点の関節曲線QAでは通常斬り/破城斬りに急な角度ジャンプなし。v0.7では状態遷移の種類を増やし、移動モーションを壊さず状態時だけカットアウトへ切り替える構成にした。
