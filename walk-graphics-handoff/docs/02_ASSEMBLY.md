# 組み合わせる位置とデータの読み方

正本は `workspace/plain-walk-v13/` です。以下のパスはパッケージ直下からの相対パスです。

## 正確な値の所在

| データ | 内容 |
| --- | --- |
| `workspace/plain-walk-v13/assets.json` | 全97素材の画像パス、寸法、pivot、端点、接続口 |
| `workspace/plain-walk-v13/config.json` | 体格、方向別配置、歩行周期、腕・脚・足の設定 |
| `workspace/plain-walk-v13/rig.json` | 全5方向×8コマの関節座標と29個ずつの描画配置 |
| `data/assets.csv` | 素材の寸法・支点を表形式にしたもの |
| `data/frame-placements.csv` | 1160個の描画操作。並び順、座標、角度、倍率、画像内支点 |
| `data/joints.csv` | 全コマの関節位置・親・補足情報 |
| `data/diagonal-placement-history.csv` | 斜めの頭と首の数値の履歴 |

CSVはUTF-8 BOM付きです。正確な浮動小数値はJSONが正本です。表の丸め値をJSONへ戻して精度を落とさないでください。

## 座標と描画

画面左上が原点、Xは右が正、Yは下が正。角度は度、画面上で正が時計回りです。ローカル画素 `p`、画像内支点 `pivot` に対し、画面位置は次です。

`world = position + Rotate(angle) × Scale(scale_x, scale_y) × (p - pivot)`

`rig.json` の各 `ops` を配列順に奥から手前へ描きます。`position` は計算済み画面座標です。`parent` は接続関係を示す情報であり、描画時に親の移動をもう一度加算しません。負のscale_xは左右反転です。

画像はNearest Neighborで扱います。拡大表示の倍率を座標に混ぜないでください。PNGは192×256、通常の確認表示は2倍です。

## 部位と連動

1方向17基本部位、正面と追加3方向に足差分3枚ずつ、合計97素材です。左右の腕・脚へ素材を使い回すため、1コマは29描画操作です。

| 系統 | 接続 |
| --- | --- |
| 中心 | root → sacrum → lumbar → thorax → cervical → neck → head |
| 腕 | shoulder → elbow → wrist → hand |
| 脚 | hip → knee → ankle（足はankleへ配置） |
| 腰 | lumbar → waist、腰の位置へ胸郭・骨盤を配置 |

上腕・前腕・上腿・下腿は `pivot` から `end` までを隣接する関節間へ伸縮・回転させます。基本長は上腕22、前腕17、上腿26、下腿28 pxです。斜め・正面では画面への投影による短縮もscale_yへ入ります。

`far` / `near` は部品の識別名です。正面では画面左／右、横では奥／手前、斜めではニュートラル姿勢の奥／手前の列に由来します。歩行中の実際の重なりはdepthで変わります。名前だけで全コマの前後を固定しないでください。

## 現行の斜め頭・首：v13

| 項目 | down_right | up_right |
| --- | --- | --- |
| 頭画像サイズ | 64×65 | 64×65 |
| 頭pivot | (26, 60) | (26, 60) |
| 胸郭pivot | (16, 32) | (16, 32) |
| 首の絵の開口 `neck_socket` | (16.5, 2) | (16, 2) |
| 頸部の起点 `cervical_socket` | (16.5, 9) | (16, 9) |
| `neck_tip_offset` | **(-2, -9)** | **(-3, -11)** |
| `head_offset` | (0, 0) | (0, 0) |
| 手前肩socket | (6, 13) | (27, 13) |
| 奥肩socket | (27, 12) | (5, 11) |

`neck_socket` と `cervical_socket` を混同しないこと。前者は絵の切り口、後者が現行の斜めの骨格の起点です。上へ首を継ぎ足さず、肩の間から支えます。

1. 胸郭の画像内 `cervical_socket` を、胸郭のpivot・回転・位置で画面へ変換する。
2. `neck = cervical + neck_tip_offset`。このoffsetは現行実装では画面座標の差分です。
3. `head = neck + head_offset`。
4. 頭の画像を `head` へpivot基準で配置する。

首の下端の描画基準は `cervical + (0, 3.5)`。上端との中間に首素材を置き、長さへ合わせて回転・伸縮します。下端は胸郭、上端は頭に重なります。実装は `rig.js` の `makeTurnedPose` が正本です。

先頭コマの検算値（小数6桁に丸め）：

| 向き | cervical画面座標 | neck＝head画面座標 | 頭画像の左上（回転0） |
| --- | --- | --- | --- |
| down_right | (96.572517, 137.019346) | (94.572517, 128.019346) | (68.572517, 68.019346) |
| up_right | (96.072669, 137.007006) | (93.072669, 126.007006) | (67.072669, 66.007006) |

これは歩行の1コマ目の値で、全コマ共通の絶対座標ではありません。上下動と左右の微動は親座標へ連動します。斜め2方向の頭の高さはこの配置で別々です。

## 背中側へさらに動かすとき

今の斜め2方向は右を向いているので、今回の調整での背中側は画面左です。原寸で2 pxなら、対象方向の `neck_tip_offset[0]` から2を引きます。首の上端と頭が同時に移動します。高さを保つ場合、Y、頭pivot、`head_offset` は変えません。

画像のpivotを変える修正と、首上端の座標を変える修正を重ねると二重に移動します。どちらを変えたかを明記し、全8コマの差分で確認します。

## 肩・脚・足・描画順

斜めの肩は胸郭画像の `shoulder_sockets` へ登録しています。絵と骨格がずれないよう、肩の補正量を肘・手首にも同じだけ加えます。

脚は股関節が起点です。横向きの脚軌道を元に方向へ投影し、奥行きで骨盤・太腿・膝・下腿の順序を変えます。足画像の `opaque_corners` は接地計算用です。足を差し替える場合、見かけの矩形の底ではなく、不透明画素の輪郭と足首pivotを更新します。

正面・横向きの基準地面はy=242。追加3方向は `ground_center=237.5` とdepthに基づく高さを使用し、斜め下は地面の傾きも考慮します。

頭は現行では最後、首は胸郭の前に描かれて胸郭が下端を覆います。腕・脚の順序は位相で変わるため、全コマ共通の固定一覧を手で再現せず、各コマのops順を使ってください。
