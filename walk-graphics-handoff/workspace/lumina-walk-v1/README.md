# ルミナ 歩行グラフィック試作 01

正面（マップ下方向）と右向き。参照キャラクターを部位素材として生成し、部位ごとの移動・回転・重なり順で歩行を組み立てた試作です。

- 1歩4コマ、左右の足を合わせて1周期8コマ。
- 1コマ120 ms（約8.33 fps）、1周期960 ms。フレーム補間なし。
- 1コマ192 × 256 px、透過RGBA。基準の足元は概ね (96, 242)。
- 頭・胴の上下動は基準位置から最大±2 px。髪、翼、裾は少し遅れて揺れます。
- 腕は肩を支点に振り、横向きの脚は腿・脛・足に分けて膝を曲げます。
- マップ上での移動処理は含めず、その場歩きのループを収録しています。

## 見る

`lumina-walk-player.html` をブラウザーで開くと、正面と横向きを並べて再生します。画像は埋め込み済みで、インターネット接続は不要です。

「一時停止」「1コマ進む」「部位を見る」、再生速度変更、フレーム選択が使えます。「部位を見る」は元の12部位の一覧表示です。横向きの脚の追加分割はPNGとリグに含まれます。OSでアニメーション抑制を指定している場合は停止状態で開きます。

`lumina-walk-preview.gif` は比較用の背景付きGIFです。確認用のマス目と影は素材PNGに含みません。

## 素材

| ファイル | 内容 |
| --- | --- |
| lumina-walk-spritesheet.png | 8列 × 2行、1536 × 512 px。上段=正面、下段=右向き。各行を左から右に再生 |
| lumina-front-8frames.png | 正面8コマ、1536 × 256 px |
| lumina-side-8frames.png | 右向き8コマ、1536 × 256 px |
| lumina-front-walk.png / lumina-side-walk.png | 透過APNG、192 × 256 px。非対応ビューアーでは先頭コマを表示 |
| frames/front/、frames/side/ | 各方向の独立した8枚の透過PNG（00〜07） |
| parts/front/、parts/side/ | 組み立て用の透過PNG。頭と輪は一体、前髪は頭に含む |
| rig.json | 部位画像、フレームごとの支点・座標・回転・スケール・描画順 |
| source-atlases/ | 部位を切り出す前の生成素材。緑は抜き色 |
| generation-prompts.txt | 素材生成に使ったプロンプト |

正面の far / near は画面左 / 右の識別名、横向きでは奥側 / 手前側です。部位の画風と形は画像生成ツールで作り、切り出し・抜き色処理・最近傍でのサイズ調整・歩行の組み立てはコードで行っています。

## 調整・再出力

Python 3 と Pillow、NumPy が必要です。

```bash
python -m pip install -r requirements.txt
python rebuild.py
```

再出力は同じフォルダーのPNG、GIF、リグ、プレイヤーを上書きします。`pose_front` / `pose_side` で各部位の動き、`SIZES` で組み立て寸法、`DURATION` でフレーム時間を調整できます。

リグの回転角は度単位です。部位のローカル支点を引き、スケール、回転、座標移動の順で変換します。フレーム内の配列順に背面から描画します。`hierarchy` は連動関係の説明で、各フレームの最終的な変換値はすでに計算済みです。

## 確認

全16コマの透明背景、画像枠への収まり、フレーム数を確認し、全コマの並びと主要ポーズを目視確認しています。GIF・APNGは8コマのループです。

生成方式: 組み込み画像生成ツール。画像API / CLIは使用していません。
