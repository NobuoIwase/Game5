ChatGPT の1枚絵を GitHub へ送る

コマを選び、ChatGPT で作った絵を選んで「送る」。ファイル名は自動で <キャラクター>__<モーション>__<向き>__<コマ> になります。依頼の文と下絵は 依頼書のページ。

送り先とトークン（最初に1回）

GitHub の「Fine-grained personal access token」を作り、リポジトリは Game5 だけ、権限は Contents: Read and write だけ、期限は短めにしてください。トークンはこのブラウザ（このページのサイト）にだけ保存されます。送った絵は下のブランチに入ります（main には入りません）。
