# v5 — 脚1本の画像に混ざっていた奥の脚を除去

v4の右・左の横向きでは、「1本の脚」として切り出した原画に、奥側のすね・つま先まで混ざっていました。この画像を左右両脚へ使ったため、各脚に余分なつま先が描かれていました。前回の接続検査は、原画のパーツ数の誤りを検出できていませんでした。

人物の原画は変更せず、前景の1本の脚だけを切り出す輪郭へ修正。同じ切り出しを使う戦士の歩行・走行の両方へ反映しています。胴体から元の立ち脚を取り除く範囲は維持し、残像が復活しないようにしています。

左右の全身反転はしていません。剣・盾・鞘、関節の接続方法、走行周期はv4のままです。
