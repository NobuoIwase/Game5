# Astra への作業依頼：キャラクターのアニメーション用の1枚絵

作成：Claude（2026-09-27）。リポジトリ（Game5）を直接読み書きできる前提の手順です。

## やること

`character-motion-v1/chatgpt/jobs.json` の `batches`（25回ぶん・329枚）を上から順に描き、決まった名前の PNG で保存し、検品して、ブランチ `chatgpt-output` に push する。

## 読むもの

| 何 | 場所 |
|---|---|
| 一覧（何を何枚描くか） | `character-motion-v1/chatgpt/jobs.json` |
| キャラクターの見た目（絵柄・頭身・衣装・色の基準） | `jobs.json` の `characters.<キャラクター>.ref`（例 `art/warrior-source.png`。ゲームの8方向の絵）と `sheet`（設定画） |
| キャラクターごとの決まり | `jobs.json` の `characters.<キャラクター>.common`（この文の「・」の項目がそのまま描き方の決まり） |
| 1回ぶんの内容 | `jobs.json` の `batches[i].ask`（番号 → ファイル名・向き・何コマ目・ポーズ） |
| 1回ぶんのポーズ一覧（番号つき） | `batches[i].sheet`（例 `sheet/aria__slash__1.png`） |
| 1枚ずつのポーズの図 | `frames[j].pose`（例 `pose/slash__front__0.png`） |

パスは `character-motion-v1/chatgpt/` からの相対パス（`ref`・`sheet` は `character-motion-v1/` から）。

## 描き方（全部の絵で同じ）

- 見た目の画像のキャラクターを、同じ絵柄・同じ頭身（小さめのデフォルメ）・同じ衣装と色で描く
- 姿勢・向き・手足と持ち物の位置は、ポーズの図（マネキン）に合わせる
  - 図の色：青＝キャラクター本人の右半身、橙＝左半身、灰色＝胴と頭
  - 図の線・色・関節の丸・番号は描かない
- 1コマ＝1枚の別々の画像。正方形 1024×1024 以上
- 全身が入るように上下左右に1割くらいの余白。立っているときの足元は、どの絵も画像の下から1割くらいの高さ。キャラクターの大きさも全部の絵でそろえる
- 背景は透明（できなければ真っ白の無地）。影・床・効果線・文字・枠は描かない
- 動きの途中のコマでも、1枚の絵として自然に見えるように描く

## 保存と検品

1. 保存先：`character-motion-v1/chatgpt/out/<キャラクター>/<frames[j].file>`（例 `out/aria/aria__slash__front__0.png`）
2. **描いた絵をプログラムで縮小・減色・切り抜き・背景除去しない。** 生成されたままの PNG を置く（前に、縮小・減色された使えない PNG が届いたことがある）
3. 1回ぶん描いたら、検品する：
   ```
   cd character-motion-v1 && node tools/check_chatgpt_out.mjs
   ```
   - `NG` と出た絵は、描き直して置き直す（直そうとしてプログラムで加工しない）
   - 最後の行に、まだの回と枚数が出る
4. 検品が通ったら、ブランチ `chatgpt-output` にコミットして push する（`main` には push しない）。1回ぶんごとにコミットしてよい
