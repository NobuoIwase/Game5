# Game5 battle pilot — v0.4.0

Game5は、ヒロインを直接操作せず、ヒロインAIが視界・聴覚・記憶・性格・敵知識からリアルタイムに行動を選ぶ、敵側ディレクター型のリアルタイム・コマンドRPGです。

## v0.4.0 — ヌテラ・エステラ基盤

- ヌテラ0〜100%を実装。付与が止まると自然減少。
- ヌテラ100%でエステラ。一定時間行動不能、MP少量漏出、SP大消耗。
- エステラ中はヌテラが高速減少し、終了時20〜30%程度を残す。
- ルマネ、催眠、種族別魅了を「0〜100蓄積→段階上昇」の3段階状態として実装。
- ルマネに欲求の波を実装。段階と波が高いと、ヒロインAIの逃走/接近判断が変化。
- セイル0〜100%を実装。高いほどヌテラ増加量が増幅。
- 輪紋を実装。状態の自然回復に下限を設定できる。
- 敵側ツールに「輪紋ビーム」を追加。命中時、輪紋Ⅰがルマネ段階1・セイル24%を回復下限として固定。
- 現パイロット敵の影縛り、霧、黒雷などにヌテラ/ルマネ/催眠/魅了/セイル効果を接続。
- HUDにヌテラ、エステラ、ルマネ、催眠、魅了、セイル、輪紋、欲求波を追加。
- Game4のモンスター構成を参照し、今後の敵を「固有のヌテラ手段を必ず持つ」設計へ統一。

詳細仕様: [`NUTERA_SYSTEM.md`](./NUTERA_SYSTEM.md)

## 操作
ヒロインは操作しません。戦場をクリックして敵側の配置を行います。

- `1`: 影杭
- `2`: 瘴気壺
- `3`: 囮鐘
- `4`: 輪紋ビーム
- `A`: AUTO指揮 ON/OFF

## 既存の戦闘基盤
- 視界外は音をぼんやり認識し、振り向いて確認。
- 敵攻撃を観察/被弾/回避して知識を蓄積。
- 近接技は射程と踏み込みを分離し、発生時点の位置/角度で命中判定。
- HP / MP / SP。HPまたはSPが0で敗北。
- EXP/レベルアップと技習得。
- 敵攻撃には予兆、攻撃範囲、拘束、状態異常、魔法を持たせる。
