# 向き・装備・走行姿勢の修正

ユーザーからの指摘：正面が斜めを向く、左斜め前の顔の向きが合わない、剣・盾の動きが不自然、背面で盾が腕を貫通して見える、走行の前傾が弱い。

## 原画

内蔵の画像生成ツールを使い、戦士の正面と左斜め前の2方向を修正しました。正面は顔・肩・胴体・腰を正面へ揃え、左斜め前は頭と胴体を同じ方向へ揃えています。元の服装と、本人基準の右肩の肩当てを維持しています。

- [生成時の指示文](../art/warrior-body-v2-prompt.txt)
- [生成された2方向の原画](../art/warrior-front-downleft-v2-source.png)
- [組み込んだ8方向の原画](../art/warrior-body-v2.png)
- [正面単体](../art/warrior-front-body-v2.png)
- [左斜め前単体](../art/warrior-down_left-body-v2.png)

他の6方向は元画像の画素をそのまま使用しています。2方向は新しい原画に合わせて腕・脚・関節を再設定しています。方向間の小さな描き分けや体形の差は残ります。

## 動き

汎用走行は前傾を24度にし、骨盤を中心に腰・胸郭・肩・首・頭を同じ姿勢へ載せました。描画側もその投影に合わせています。歩行の元となるv13の足運びと中立姿勢は維持しています。

装備は本人の右手に剣、左前腕に盾、左腰に鞘を取り付けます。方向ごとの握り位置と描画の前後関係を校正し、腕と装備の別々の回転がずれを生む処理を見直しています。

左斜め後ろの左脚は、膝を曲げたときに脛当てが分離して見えないよう、装甲を膝下パーツへまとめました。関節そのものの位置は変更していません。
