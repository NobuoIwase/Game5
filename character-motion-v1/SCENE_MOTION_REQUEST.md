# 依頼書：床の姿勢・口づけ・拘束なしの姿勢・体に張り付く小さな生き物の汎用モーション（Codex / GPT 向け）

作成：Claude（2026-09-26、v3）。参考資料は `references/scene-v1/`（一覧は同フォルダの README、全モーションの一覧ページは `references/index.html`）。

## 1. 目的

キャラクターの姿勢と動きの追加分。
- 押されて床に倒れる、床の上で押さえられる、起き上がる
- 口づけ（相手の顔と触れている状態）
- 拘束のない立ち姿勢・座り姿勢
- 体に張り付く小さな生き物を払おうとする動き

アリアだけでなく**ほかのキャラクターにも使う汎用モーション**なので、骨格（関節の3D座標）で姿勢を決めてある。各キャラクターの原画・部位を、この骨格に沿って描いてほしい。

- **図の見方**：参考図は、`references/` のほかの資料と同じ無地のマネキン。青が本人の右半身、橙が左半身、紫が拘束、紫の点線の円が相手の頭。桃色の丸に羽が付いたものが、張り付く小さな生き物。
- **向き**：各モーションの向きは `motions.<id>.view` にある。
  - 床の姿勢と口づけは真横（`right`）
  - 膝を開いて押さえられる床の姿勢は斜め前（`down_right`）
  - それ以外は正面（`front`）
- **服装**：キャラクターごとの衣装のまま。剣と盾は持たない。
- **描かないもの**：拘束具・相手・張り付く生き物はゲームが別に描く。本人だけを描く。位置は下の `binds`。押さえられた手首や、生き物が張り付いた部分の、服のわずかな押されやしわは描いてよい。

## 3. 骨格データ

`motion/scene-poses.json`（生成元は `motion/scenes.mjs`、再生成は `node tools/render_scene_svg.mjs`）。

- 形式・キャンバス（288×288、中心 x=144）・投影式は `motion/restraint-poses.json` と同じ。576×576 のコマでは座標を2倍する。
- `poses.<id>.<direction>[frame]` の中身
  - `joints`：各関節の `position`・`depth`・`world`
  - `phase`：コマの狙い
  - `expr`：参考図に描いた表情の目安
    - `shut`：目を閉じる
    - `o`：口を開ける
    - `line`：口を結ぶ
  - `binds`：拘束・相手・生き物の位置
- 追加の点
  - `face`、`eye_left` / `eye_right`
  - `crotch`
  - `chest_left` / `chest_right`：胸の左右。`groin`：脚の付け根の前。生き物が張り付く位置
  - `belly`：下腹
- **`binds`**
  - `joint` と `joint2`：2つの関節をまとめる帯（後ろから抱きすくめられた両肘など）
  - `joint` と `anchor`：関節をその点へ押さえる・引く（床に押さえられた手首、左右へ開かれる膝など）
  - `partner`：相手の頭の中心（`anchor` の点）。本人の顔が触れる位置の目安
  - `creature`：その点に張り付いた小さな生き物。手の点（`hand_right` など）にあるときは、手でつかんでいる
  - `coil`：その関節の高さで胴を一周する輪（`r` は半径）。腕が脇にあれば腕ごと巻く
  - `engulf`：床から `level` の高さ（世界座標のy）まで、体を包む柔らかい塊
  - `bubble`：体全体を包む泡

## 4. 部位ごとの描き方

1. **床に倒れる**（`down_fall_back`）：
   - 押されて上体が後ろへ傾き、両腕が前に出る
   - 膝が抜けて手を後ろへつき、尻もちをつく
   - 背中から倒れ、頭が床に触れ、足が一瞬浮く
   - 仰向けで止まる
2. **仰向けで押さえられる**：
   - 手首は頭の上の床に押さえられ、腕は頭の両脇を通って上へ伸びる
   - 顔は横へそむける
   - `down_pinned_kick`：膝を立てた脚を片方ずつ蹴り上げ、腰をひねる
   - `down_pinned_spread`：立てた膝が左右へ開かれ、足裏どうしが近づく（M字）。閉じようとして膝がわずかに戻り、腰をよじる
   - `down_pinned_rock`：体全体が頭の方へ押されては戻る。頭は少し遅れて揺れ、押されたときに口が開く
3. **うつ伏せ**（`down_face_down`）：
   - 顔は床に向け、少し横を向く
   - 手首は頭の先の床に押さえられている
   - 膝から下を片方ずつ跳ね上げてもがく
   - 足の甲は床につき、爪先は頭と反対の後ろへ向く。跳ね上げた脚では、爪先がすねの延長線上で上を向く
4. **腰を上げる**（`down_hips_up`）：
   - 膝をついて太ももを立て、胸と顔を床につける
   - 手首は顔の前の床に押さえられている
   - 腰が前後に揺れ、そのたびに背中の反りが変わる
5. **起き上がる**（`get_up`）：
   - 肘をついて上体を起こす
   - 膝を立てたまま座り、手を後ろの床につく
   - 前へ体重を移してしゃがむ（手は前の床）
   - 膝に手を当てて立ち上がる
   - 両脚は左右に並んだまま曲げ伸ばしするだけで、交差したり横へ流れたりしない
6. **口づけ**（相手の頭は紫の点線の円。本人の顔がその円に触れている）：
   - `kiss_forced`
     - 顔を少し上に向けて相手に口を塞がれる
     - 両手で相手の胸を押し返す
     - 腰をよじる
     - 目は閉じ、口元は固い
   - `kiss_tension`
     - 押し返していた腕の力が抜ける
     - 爪先立ちでこわばり、手が開く（頂点）
     - 震える
     - 膝が内に崩れ、口で支えられるように前へもたれる
   - `kiss_respond`
     - 自分から爪先立ちで身を寄せ、首を傾ける
     - 両腕を上げて相手の首へ回す
     - 目は閉じ、表情は柔らかい
7. **拘束なしの立ち姿勢**：
   - `tempt_pose`
     - 脚を開いて腰を前に出し、ゆっくり左右に揺らす
     - 片手を胸に、もう片手を太ももに
     - 首を傾けて見下ろす
   - `chain_splay`
     - 膝ががに股に開いたまま、膝と腰が小刻みに震える
     - 腕は力なく垂れ、頭は後ろへ倒れる
   - `tension_free`
     - 胸と下腹を手で押さえてこらえる（膝が内に入る）
     - 背中を反らせて爪先立ち（頂点）
     - 震える
     - 膝から崩れて女の子座り
   - `sit_afterglow`：女の子座り（膝を前でそろえ、すねを左右の外へ流して床につける）で、肩を上下させて息をつく
   - `held_from_behind`
     - 後ろの相手に両腕ごと胴を抱えられ、腕は脇に付いたまま
     - 腰をひねり、片足ずつ浮かせてもがき、肩越しに振り返る
8. **張り付く生き物**（胸の左右と脚の付け根の前。ゲームが描くので本人だけを描く）：
   - `clinger_peel`
     - 見下ろして気づく
     - 片手で胸の1匹をつかみ、体から引き離す
     - 手からはじかれて元に戻り、手が外へ跳ねる
     - 反対の手でも同じことをする
     - 最後に身をすくめ、下腹に両手を当てる
   - `clinger_tension`
     - 胸を両手で押さえてこらえる
     - 腕を後ろへ振り、背中を反らせて爪先立ち（頂点）
     - 震える
     - 座り込む
   - `clinger_accept`
     - 振り払うのをやめて腕を垂らす
     - 胸を前に出し、頭を後ろへ倒す
     - 腰をゆっくり揺らす
   - `clinger_peel` は16コマ。つかむ・引く・はじかれるの各動作の間に中割りのコマがある
9. **こわばりのあとの余韻と立ち直り**（各 `*_afterglow` は、こわばりのモーションの最後のコマと同じ姿勢から始まる）：
   - 余韻（ループ）：
     - 肩を上下させて息をつく。頭は垂れるか横を向く
     - 6コマ目だけ、体が一度ぴくっと跳ねる（腰・爪先・手）
   - `down_afterglow`：仰向けで膝が左右へ倒れ、腕は頭の上に投げ出したまま
   - `kiss_afterglow`：相手が顔を離したあと（点線の円は少し離れた位置）、膝が抜けたままふらつく
   - `sit_afterglow` / `clinger_afterglow`：女の子座りのまま
   - 立ち直り（1回）：
     - `down_recover`：膝を閉じ、`get_up` の最初のコマにつながる
     - `kiss_recover`：手の甲で口元をぬぐい、もう片方の手を前に出して一歩下がる
     - `sit_recover` / `clinger_recover`：床に手をつく → 膝立ち → 片足を前に出す → 立ち上がる
10. **追加分（v3）**
   - `down_tension`（押さえられたままのこわばり）
     - 腰が床から浮き、背中が反る
     - 頭を床に押しつけるように後ろへ反らせ、爪先を伸ばす
     - 震え → 腰が落ち、膝が左右に倒れる
   - `engulf_*`（柔らかい塊に包まれる。塊は半透明の桃色で、ゲームが描く）
     - 塊に入っている部分は動かない。脚は立ったまま
     - `engulf_sink`：塊が足元から膝、太もも、腰へと上がってくる。見下ろし、腕を広げて釣り合いを取り、片脚を抜こうとして抜けない
     - `engulf_struggle`：胸から上だけをひねり、片手ずつ塊を押し下げる
     - `engulf_rock`：塊の中で腰が前へ跳ね、そのたびに背中が反って頭が後ろへいく（1ループに2回）
     - `engulf_tension`：両腕を上へ振り上げて反る（頂点）→ 震え → 塊の上に前腕を乗せて前へ崩れる
   - `wrap_*`（紫の輪が胸の下・腰・骨盤のまわりを、腕ごと巻いている。輪はゲームが描く）
     - 腕は脇に付いたまま動かない
     - `wrap_squeeze`：輪が締まるにつれて背中が反り、肩がすくみ、爪先立ちになる。緩むと息をつく
     - `wrap_tension`：輪の中で大きく反る（頂点）→ 震え → 膝が内に入って輪に支えられる
   - `ankle_grabbed`
     - 左の足首が後ろへ引かれ、前へつんのめる
     - 反対の足で片足跳びをして腕を振り回す
     - 両手と右膝をつく。つかまれた脚は後ろへ伸びたまま
     - 肩越しに振り返る
   - `break_free`：輪に巻かれたまま身を縮めて力を溜める → ひねって両腕を大きく広げ、振りほどく（1コマ短い）→ 一歩よろける → 両手を前に上げ、膝を柔らかくして構え直す
   - `edge_pull`：腰が先に前へ出て、足がついて一歩寄る → はっとして前屈みになり、下腹を両手で押さえる → 一歩下がる
   - `walk_unsteady`
     - 歩幅は小さく内股。片手は下腹に当て、もう片手は少し外へ出して釣り合いを取る
     - 6コマ目で膝がかくんと落ちかける
     - 歩きなので、ほかの歩きのシートと同じく8方向で描く
   - `gaze_trance`：棒立ちで腕は垂れたまま。顔は正面から動かさず、小さく頷く。口がわずかに動く
   - `spore_inhale`：片手で口を覆い、顔を横へそむける。3コマ目と7コマ目で吸い込み、咳き込むように少し前屈みになり、膝が内に折れる
   - `shiver_hug`：両手で反対側の二の腕を抱く。肩をすくめ、膝を寄せて小刻みに震え（コマごとに左右へわずかに揺れる）、5コマ目で爪先立ちに跳ねる
   - `bubble_float`
     - 泡（半透明の青い円。ゲームが描く）の中で、足が床から浮く
     - 体を少し丸め、両手のひらを泡の内側に当てる
     - 口を開け閉めする
   - `daze_sway`：力の抜けた立ち姿勢で、首を左右にかしげながらゆっくり揺れる
   - `reach_toward`：前にある何かへ片手を伸ばして一歩寄る → はっとして手を胸に引き寄せ、目をそらして下がる
   - `trip_fall`：後ろ足のつま先が引っかかり、腕を前に出してつんのめる → 両手と両膝をつく → 顔を上げる → 片膝を立てて立ち上がる
   - `defeat_collapse`：膝から崩れて膝立ちになる → 前へ倒れ、うつ伏せで止まる（痛みの表現はしない）
   - `grabbed_flinch`：構えた姿勢から、肩をすくめて爪先立ちに跳ねる（1コマ短い）→ 捕まった足元を見下ろす → もがき始める
11. **体の後ろにある部位**：胴体の後ろにある腕や脚は、胴体の陰に隠れる。胴体の縁をかすめる部位は、前後のコマで隠れたり出たりさせない。
   - 参考図は、胴体を背骨まわりの楕円柱として扱って判断している（`tools/check_occlusion.mjs` で確認）
12. **脚を交差させない**：どのコマでも、左右の膝は触れる程度まで。骨格データは膝どうしが8px（576pxのコマでは16px）より近づかないようにしてある（`tools/check_legs.mjs` で確認）。
13. **表情**：`phase` と `expr` に合わせる。
    - 抵抗：口を結ぶ
    - 押される・揺れる：口が開く
    - こわばりの頂点：目を固く閉じて口を開く
    - 脱力：焦点の合わない目
    - 応える：穏やかに目を閉じる
14. **髪・服の揺れ**：体の動きより1〜2コマ遅れて揺れる。仰向けでは髪が床に広がる。
15. **痛み・流血の表現はしない**。
