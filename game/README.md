# Game5 battle pilot — v0.3.0

Game5 は、接触ダメージ中心のヴァンサバ型ではなく、ヒロインが自律的に技を選ぶリアルタイム・コマンドRPGとして開発します。パイロット版は戦士アリア1人です。

## v0.3.0
- ヒロインは直接操作せず、視界・聴覚・直近記憶・性格から移動/回避/技を判断
- 視界外は音を曖昧に認識し、振り向いて確認
- 敵技を観察・被弾・回避して知識を蓄積し、次回以降の対処へ反映
- HP / MP / SP を実装。HP または SP が0で敗北
- EXP/レベルアップと Lv2「盾撃」、Lv3「破城斬り」
- 近接技に `range` と `step` を分離実装。踏み込み後の位置/角度で命中判定し、敵が抜ければ空振り
- 敵に大薙ぎ、灰槍突進、影縛り、蝕毒の霧、黒雷。拘束/毒/鈍足/沈黙/SP攻撃あり
- プレイヤーは敵側で「影杭」「瘴気壺」「囮鐘」を配置。`A` で AUTO 指揮切替
- HUD に HP/MP/SP、能力値、思考、知覚、敵知識、技、敵の行動/予兆を表示
- Canvas に視界、聴覚圏、敵攻撃予兆、近接射程、罠を表示

操作: `1` 影杭 / `2` 瘴気壺 / `3` 囮鐘 / `A` AUTO切替。戦場クリックで罠を配置します。
