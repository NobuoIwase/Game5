# 拘束された姿勢のモーション参考資料 restraint-v1

依頼書は `../../RESTRAINT_MOTION_REQUEST.md`。全モーションを動かして見られる一覧ページは `../index.html`。

`motion/restraint.mjs` の骨格を `tools/render_restraint_svg.mjs` で描いたマネキン図。
- 青は本人の**右**半身、橙は**左**半身
- 紫は拘束（関節に巻いた輪と、引っ張る先へ伸びる線、2つの関節をまとめる帯）
- 頭の上の点は目
  - こちらを向いているときは両目、横顔では片目を描く
  - 後ろを向いているときは髪（茶色の影）を描く
- コマは 288×288（ゲーム用は2倍の 576×576）

| ファイル | 内容 |
|---|---|
| `<id>_keys_front.svg`（`bent_over` は `_keys_up_right.svg` と `_keys_back.svg`） | 見せる向きの全コマを大きく並べ、各コマの狙いと表示時間を書いたもの。赤い点線は腰の動きの軌跡 |
| `<id>_keys_right.svg` | 真横から。腰の前後の動き・背中の反り・爪先立ちが分かる |
| `<id>_sheet.svg` | 見せる向き・斜め・真横・反対側の4方向×全コマ |
| `<id>_preview.svg` | ブラウザで開くと4方向が動くアニメーション |

`<id>` は依頼書の表のとおり16種類。
