# 依頼書：ほかのヒロインのモーション（Codex / GPT 向け）

作成：Claude（2026-09-26、v1）。
- 参考資料：`references/heroine-v1/`（全モーションの一覧ページは `references/index.html` の「ほかのヒロイン」）
- 骨格データ：`motion/heroine-poses.json`（生成元は `motion/heroines.mjs`、再生成は `node tools/render_heroine_svg.mjs`）

- **使い回し**：ほかのコマと同じ絵で済むコマは `REUSE_LIST.md`（`motion/reuse.json`）にまとめてある。
- **作り方の計画**：どのコマを1枚絵で描き、どのコマを部位の組み立てで作るかは `PRODUCTION_PLAN.md`（`motion/plan.json`）。キャラクターごとの量もそこにある。
  - 部位は1枚絵から切り出さず、部位として描く（のりしろ付き・切り口に輪郭線なし・関節は別の絵）。

## 1. 目的

戦士アリア以外の3人について、それぞれの技・仕草のモーションを作る。
- 骨格・キャンバス・投影は、ほかのモーション資料と同じ。
- 拘束・床の姿勢・口づけ・張り付き・つなぎなどの共通のモーション（`RESTRAINT_MOTION_REQUEST.md` / `SCENE_MOTION_REQUEST.md`）も、3人それぞれで描く。そのときの違いは4章。
- 見た目の基準：各人の8方向の原画（`art/scout-source.png`、`art/witch-source.png`、`art/sister-source-v7.png`）と設定画（`references/scout.jpg`、`witch-reference.jpg`、`sister-reference.jpg`）。

## 2. 3人の特徴

### 斥候（シーフ） `look: scout`
- 狐（フェネック）の獣人の商人
- **見た目**
  - 大きな耳、桃色がかった尻尾
  - 大きなバックパック（上に丸めた寝袋）を**いつも背負っている**
  - 腰にナイフ（ほかに小さなナイフ）
- **動き**
  - スタミナがあり、足が速い。動きは軽く小刻み
  - 罠や敵の気配に敏感で、よく耳を立てて辺りをうかがう

### 魔法使い `look: mage`
- 無口で落ち着いている
- **見た目**
  - 大きなとんがり帽子、長いコート
  - **両腕の肘から先が機械の義腕**
  - 右手に紫の宝珠の杖
- **動き**
  - 遠くからの魔法が得意
  - 魔力は、杖と同じように義腕を通して強めて撃つ（腕を向けて放つ）
  - 声を上げるのを嫌い、こらえるときは口を結ぶ・義腕の手で口を押さえる

### ヒーラー `look: healer`
- エルフの聖職者。回復と、味方を強める・敵を弱める魔法の担当
- **見た目**
  - 長い耳、金の十字の杖（右手）、白い長手袋
  - 胸は大きく、動くとよく揺れる
  - 胸は前に下がる2枚の細い前垂れだけで覆われている
- **性格**
  - 表向きは聖職者だが、ひそかに別の神を信じている（弱体の魔法のときだけ、それがわずかにのぞく）
  - いやらしいことを強く嫌う
- **原画との違い**：いまの原画（v7）は胸を覆う身ごろになっており、前垂れだけの衣装とは違う。衣装の原画を直してから描く

- **部位ごとの要点**
  - `scout_knife_combo`：低い構えから踏み込み、左へ払い、返して右へ払い、両足で小さく跳んで下がる。斬る2コマは短い
  - `scout_throw`：ナイフを頭の後ろへ引き、反対の手で狙う。腕をまっすぐ振り抜く。投げたコマからナイフは手にない。最後に腰から次の1本を抜く
  - `scout_sense`：立ち止まって耳を立てる → 身を低くし、片手を上げて「待て」 → 首を左右に振る → 気配の方を指す
  - `scout_disarm`：片膝をつき、両手を床近くで細かく動かす。尻尾がゆっくり揺れる
  - `scout_rummage`：肩越しに手を伸ばしてバックパックを探り、取り出した品を差し出して見せる。小さく笑う
  - `mage_bolt`：杖は右手で体の横に立てたまま。義腕の左腕を曲げて持ち上げ、まっすぐ狙い、放った瞬間に腕が少し跳ね上がる
  - `mage_area`：杖と義腕を高く掲げて溜め、杖を前の床へ振り下ろすと同時に腕を横へ払う
  - `mage_suppress` / `mage_suppress_tension`：膝を寄せ、義腕の手で口を押さえる。こわばるときも**背中を反らさず、前へ丸まる**（声を上げない人らしく）。最後は杖を床について片膝をつく
  - `healer_pray`：杖を立て、左手を胸に当て、目を閉じてうつむく
  - `healer_buff`：杖を頭上へ掲げてから、祝福する相手へまっすぐ向ける
  - `healer_hex`：杖は立てたまま、腰の横の低い所で左手が印を結ぶ。目は冷たく横を見る。すぐ何事もなかったように戻る
  - `healer_disgust`：一歩下がって顔を大きく背け、左腕で胸をかばい、杖を斜めに構えて間に入れる。目を固く閉じる

## 4. 共通のモーションを各人で描くときの違い

骨格は同じものを使い、次の点だけ変える。

### 斥候
- **バックパック**
  - いつも背負っている
  - 仰向けの姿勢（`down_*` など）では、バックパックが背中の下に入り、上体が少し持ち上がった形になる
  - うつ伏せ・四つん這いでは、背中の上に載る
- **尻尾**
  - ふだんはゆっくり揺れる
  - 驚く・こわばると、ぴんと立って毛がふくらむ
  - 力が抜けると垂れる
- **耳**：驚くと立ち、怖がる・恥ずかしがると後ろへ伏せる
- **動き**：どの動きも少し素早く、跳ねるように

### 魔法使い
- **義腕**
  - 肘から先は硬い金属で、曲がるのは関節だけ（前腕はしならない）
  - 床に手をつくときは、手のひらの金属板で支える
- **表情**：声を上げないので、参考図で口が開いている（`expr` に `o` を含む）コマも、次のように描く
  - 口を結ぶか唇をかむ
  - こわばりの頂点は、目を固く閉じて口を結ぶ
  - ときどき義腕の手で口を押さえる（`mage_suppress` と同じ手）
- **帽子**：頭が大きく動いても落ちない。のけぞると後ろへずれる
- **コート**：裾は体の動きより1〜2コマ遅れて揺れる

### ヒーラー
- **胸の動き**
  - 胸は体の動きに1〜2コマ遅れてついてくる
  - 上下・前後に揺れるモーション（`bounce_*`、`hip_rock_*`、`down_pinned_rock` など）では大きく揺れる
  - 自分のモーションの骨格データには、その遅れの量（`chest_lag`）がある
  - 共通のモーションでは、胸の点（`chest_left` / `chest_right`）の動きを1コマ遅らせて描く
- **前垂れ**
  - 胸と一緒に揺れ、動きが大きいとめくれそうになる
  - めくれそうなときは、手で押さえる（`healer_cover` の手）
- **嫌がり方**
  - 抵抗するコマ（`expr` に `line` を含むもの）は、ほかの人より強く顔を背け、眉をしかめる
  - 手が空いていれば胸をかばう

## 5. 骨格データ

形式はほかの骨格データと同じ。追加の項目は次のとおり。
- `motions.<id>.look`：だれのモーションか（`scout` / `mage` / `healer`）
- `motions.<id>.all8`：8方向で描くもの
- `poses.<id>.<direction>[frame]`
  - `prop`：手に持つ杖・ナイフ（`joints[prop.from]` から `joints[prop.to]` まで）。ないコマは手に何も持たない
  - `chest_lag`（ヒーラーのみ）：そのコマで胸が体から遅れる量（288pxの図で x, y）

参考図の描き方：
- 斥候は耳・尻尾・バックパック
- 魔法使いは帽子と金属色の前腕
- ヒーラーは長い耳と胸の前垂れ（遅れの量だけずらして描く）

どれも位置の目安。

## 6. 受け入れの確認

- [ ] 15モーションがそろっている（`all8` は8方向、ほかは向きの1方向。576×576・透過）
- [ ] 骨格データの関節・杖やナイフの位置に沿っている
- [ ] 斥候はどのコマでもバックパックを背負っている
- [ ] 魔法使いの前腕が金属としてしならない
- [ ] 魔法使いの共通モーションで、口を大きく開けていない
- [ ] ヒーラーの胸が体の動きに遅れてついてくる
- [ ] 左右反転で描いていない（装備の左右がどの向きでも合っている）
- [ ] 痛み・流血の表現がない
