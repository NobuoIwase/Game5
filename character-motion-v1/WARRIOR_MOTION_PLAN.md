# Warrior motion plan — v0.6.0

Date: 2026-09-23  
Model: GPT-5.6 Sol

## 方針

戦士アリアのモーションは、既存の `character-motion-v1` を基盤にする。歩行・走行は完成済み8方向×8コマのスプライトを使い、戦闘・拘束・エステラは既存の方向別パーツと `rigs/warrior.json` の関節情報を使うカットアウト方式とする。

### 歩行・走行で守る基準

- 撫で肩を維持し、首を棒状に伸ばさない。
- 脚は股関節から運び、前脚伸展 → 踵接地 → 支持 → 蹴り出しを読む。
- 腕は肩だけで振らず、肘・手首に遅れを作る。
- 斜め方向の頭を全方向で同じ高さへ強制しない。
- 良い方向を壊すための一括補正を避ける。

## 既存資産

戦士は8方向すべてで次の透過パーツを持つ。

`body / arm_left / arm_right / leg_left / leg_right / sword / shield / scabbard`

移動スプライト:

- `exports/warrior/walk.png` — 8方向×8コマ、120ms/frame
- `exports/warrior/run.png` — 8方向×8コマ、80ms/frame
- `generic/generic-walk-8dir-8frames.png`
- `generic/generic-run-8dir-8frames.png`

## v0.6.0 実装

### 通常斬り / 破城斬り

`game/warrior-motion.js` が `rigs/warrior.json` の右腕ポリゴンと shoulder / elbow / wrist を読み、既存の `arm_right.png` を実行時に次の3領域へマスク切り抜きする。

1. 上腕
2. 前腕
3. 手

各領域は9px重ねて切り、回転時に透明な隙間が見えにくいようにする。剣は手首階層へ追従する。

階層:

`肩 → 上腕 → 肘 → 前腕 → 手首 → 手 + 剣`

方向ごとに手作業で座標を作らず、8方向それぞれの既存リグを使う。これにより同じ時間設計を8方向へ投影できる。

通常斬りの流れ:

`予備動作 → 踏み込み/溜め → 加速 → 命中 → 振り抜き → 回収`

破城斬りは同じ骨格を使うが振幅を大きくし、回収時間を長くする。

**重要:** 命中フレームは固定パーセントではなく、ゲーム側スキルの実際の `cast` 完了時刻へ同期する。通常斬りと破城斬りで詠唱時間が違っても、見た目の刃が当たる時刻とダメージ判定がずれない。

### 拘束

現在のパイロットでは、両腕を別支点で引き、両脚にも別位相の小さい抵抗運動を入れる。全身一枚を左右へ振る方式にはしない。

今後は敵ごとに `leftHand / rightHand / leftFoot / rightFoot / torso` の拘束点を渡し、ワーム・触手・付着型などで姿勢を変える。

### エステラ

1. onset — 発生あ姿勢が崩れる
2. loop — 左右非対称の短周期収縮
3. recovery — 振幅を落として脱力から戻る

頭・腕・脚を同周期で上下させる「画像全体の震え」にはせず、各部位の周波数と位相をずらす。

## 本編接続

- 低速追跡・旋回・音確認: `walk.png`
- 高速接近・逃走・高速回避: `run.png`
- 通常斬り・破城斬り: 関節カットアウト描画
- 拘束中: 関節カットアウト描画
- エステラ中: 関節カットアウト描画

戦闘状態でない時は完成済みwalk/runスプライトへ戻るため、既存移動モーションは壊さない。

## Motion Lab

`warrior-motion-lab.html` は本編と同じ `game/warrior-motion.js` を読み込む。

確認可能:

- walk / run
- 通常斬り / 破城斬り
- 拘束 / エステラ
- 8方向
- 0.5x / 1x / 1.5x / 2x
- 停止 / 1コマ前後

walk/run時のみ汎用素体を同方向・同フレームで並べ、投影崩れを比較する。

## 数値QA

240分割サンプルで関節角の連続性を検査。

| motion | 実ゲーム命中比率 | 最大関節変化 / sample | 加速ピーク | 判定 |
| --- | ---: | ---: | ---: | --- |
| 通常斬り | 54.5% | 2.613° | 51.7% | 急変なし |
| 破城斬り | 69.6% | 2.414° | 61.3% | 急変なし |

時間曲線は8方向共通で、左右群では符号を反転するため、方向変更だけで関節速度が飛ぶ設計にはしていない。

## 残作業

「戦士モーションを完成」と呼ぶには次を行う。

1. Motion Labで実画像を8方向×全モーション目視し、肩・肘・手首の切れ目を微調整。
2. 必要なら攻撃専用の上腕/前腕/手PNGを書き出し、実行時マスクから置き換える。
3. 拘束点データを敵側から渡すAPIを追加し、敵固有拘束へ対応。
4. エステラ用の表情・髪・盾/剣の脱力差分を追加。
5. 高等技ごとの専用モーションを追加。

実装は「骨格的に動く」だけで完了とせず、Motion Labの通常速度・0.5x・コマ送りで違和感がないことを基準にする。
