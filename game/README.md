# Game5 battle pilot — v0.7.0

ヒロインを直接操作せず、AIが知覚・記憶・性格・敵知識からリアルタイムに行動するパイロット。

## 戦士アリア — モーション

v0.7.0でパイロット用の基礎モーション一式を本編へ接続。

| 状態 | 描画 |
| --- | --- |
| 待機 | 呼吸・微小な重心揺れ |
| 歩行 | `exports/warrior/walk.png` |
| 走行 | `exports/warrior/run.png` |
| 振り向き | 停止中の方向転換に短い体幹・脚の切返し |
| 回避 | 敵予兆への高速退避時に全身を倒し、脚を切り返す |
| 通常斬り | 肩→肘→手首→剣の関節カットアウト |
| 破城斬り | 通常斬りより大きい振幅。実際のcast完了へ命中を同期 |
| 盾撃 | 盾腕の踏み込み・突き出し |
| 防御 | 盾を前へ出して保持。微小な呼吸揺れ |
| 被弾 | ダメージ発生時の短いのけぞり |
| 気絶 | 重心を崩した持続姿勢 |
| 拘束 | 左右腕・左右脚を非同期でもがかせる |
| エステラ | 発生→非対称痙攣→収束 |
| 復帰 | エステラ後の脱力姿勢から復帰 |
| 敗北 | 転倒・脱力 |

歩行/走行は完成済みスプライトを維持し、戦闘・状態時だけ必要に応じてカットアウト描画へ切り替える。

検査ページ:
`../character-motion-v1/warrior-motion-lab.html`

8方向、0.5x/1x/1.5x/2x、停止、コマ送りで確認できる。
