# ヌテラ・エステラ システム仕様 — v0.4.0

## 位置づけ
ヌテラ・エステラは Game5 の戦闘、敵AI、ヒロインAI、罠、地形、ダンジョン生成を横断する中核システム。HPを削る以外に、敵側は「拘束・付着・特殊攻撃・環境」でヌテラを蓄積し、エステラによるMP/SP消耗を狙う。

## ヌテラ
- 0〜100%。
- 拘束中の特殊攻撃、付着、霧、罠、敵固有攻撃などから増加。
- 付与源がなくなると、少し間を置いて自然減少する。
- セイルが高いほど同じ攻撃から得るヌテラ量が増える。
- 100%到達でエステラを発生させる。

## エステラ
- 発生中はヒロインが痙攣し、一定時間行動不能。
- MPを少量漏出し、SPを大きく失う。
- 発生中、ヌテラは高速で減少する。
- 終了時はヌテラを0にせず、約20〜30%を残す。
- 敵はMP漏出とSP消耗を戦術目標として利用する。

## 段階状態
ルマネ、催眠、魅了は「段階」と「次段階までの蓄積%」を持つ。

- 内部値は0〜300。
- 0〜99 = 段階0、100〜199 = 段階1、200〜299 = 段階2、300 = 段階3。
- 100%蓄積するたびに1段階進む。
- 付与されていない間は徐々に回復し、段階を下がることもある。
- 輪紋による下限がある場合、そのラインより下には回復しない。

### ルマネ
ヌテラ上昇を求める欲求を生む。段階が高いほど強くなる。欲求には時間的な「波」があり、高い波ではヒロインAIが逃走判断をためらう、敵へ近づきかける、ヌテラ付与を求める仕草をする場合がある。

### 催眠
危険認識や回避判断を遅らせる段階状態。今後、敵固有の暗示命令や認識改変へ拡張する。

### 魅了
モンスター種族ごとに別トラックを持つ。対象種への魅了が高いほど、その種族からヌテラを受けたい欲求が強くなり、AI判断へ作用する。

## セイル
0〜100%の連続値。高いほどヌテラ上昇量を増幅する。自然回復するが、輪紋で下限を固定できる。

## 輪紋
罠、ビーム、敵固有攻撃などによって刻まれる持続効果。ルマネ、セイル、催眠、将来的には種族別魅了の回復下限を固定できる。

v0.4.0の輪紋Ⅰ:
- ルマネ下限: 100（段階1）
- セイル下限: 24%
- 敵側の「輪紋ビーム」で刻印

## ヒロインAIへの影響
- ヌテラ高 + 欲求低: 積極的に距離を取る。
- ルマネ高 + 欲求波高: 逃走が遅れる、近づきかける。
- 対象種魅了高: その種への欲求補正が追加される。
- 催眠高: 敵予兆への反応失敗が増える。
- エステラ中: 行動を完全停止する。

## Game4から継承する敵設計の方向
Game4のモンスターは役割をそのままコピーするのではなく、Game5のリアルタイム攻撃範囲・予兆・拘束・ヌテラ系状態へ翻案する。

- ナメクジ系: 種族別魅了 + 接近/接触型ヌテラ。
- 吸液羽虫系: 付着し、剥がされるまで継続ヌテラ。
- 地上ワーム系: 四肢拘束 + SP消耗 + 拘束中ヌテラ。
- ガス玉系: セイル/ルマネ蓄積 + エリア内継続ヌテラ。
- 小淫魔系: 周囲の敵のヌテラ付与効率や行動頻度を強化。
- 触手茱系: 設置・待ち伏せ・繋留拘束。
- 眼魔/ビーム系: 扇・直線予兆、催眠、輪紋刻印と相性が良い。
- 上位個体: 新種を増やすだけでなく、同系統の固有能力を強化した個体として実装する。

## 実装原則
すべてのモンスターは最低1つ、固有の「ヌテラを上昇させる手段」を持つ。単純接触ダメージだけの敵は作らない。攻撃には射程、予兆、命中条件、回避可能性、拘束/状態異常、学習可能な特徴を持たせる。
