# Game5 battle pilot — v0.10.1

戦士1人の自律戦闘パイロット。本編は `game/index.html`。

## 実グラフィック化

v0.10.1 で仮図形中心だった戦闘描画を実画像アセットへ接続しました。

- 壁
- 扉

- 結晶
- 沼
- ガス噴出口
- 輪紋床
- 瓦礫

### Enemy
`assets/enemies.png`

現在の敵「灰冠の粘魔」を64pxセルの実スプライトで描画します。戦闘状態に応じて通常・phase 2・粘糸拘束・粘霧・共鳴波の見た目を切り替えます。牙・刃・棘など痛み中心の表現は使わず、粘液・吸着・包み込み・柔らかい拘束・ガス・共鳴を基本方針とします。

### FX
`assets/fx.png`

霧、輪紋、罠、発光、紫の歪み、エステラ周辺表現へ使用。

## 描画順

1. ダンジョン床・壁・環境チップ
2. 罠/沼/霧の下層FX
3. 敵とヒロインの攻撃予兆
4. 戦士モーション
5. 敵実スプライト
6. 拘束粘糸
7. HPバー/ヒットFX
8. 罠上層FX・霧
9. 大気FX
10. ライティング・周辺暗化

`battle-render.js` が `window.Game5Graphics` を呼び、`graphics-enhance.js` が実描画を担当します。

## 戦士モーション

待機、歩行、走行、振り向き、回避、通常斬り、破城斬り、盾撃、防御、被弾、気絶、拘束/もがき、エステラ、復帰、敗北/脱力。walk/runは完成8方向スプライト、戦闘状態は分離パーツと `rigs/warrior.json` を使用。
