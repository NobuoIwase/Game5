# 通常戦闘のピクセルエフェクト

Game5 / newgame の通常攻撃用。基準は main `8ebb600`（遙の刀戦闘 `19cb956` を含む）。既存の人物画像・敵画像・攻撃判定・威力・MP・乱数は変更しない。

## 制作と再生成

1. `PROMPT.txt` を built-in image_gen に渡し、透過原画を生成。
2. 採用原画は `source-atlas.png`。画像生成を省いた図形描画の代用品ではない。
3. リポジトリ直下で `python newgame/tools/fx/pixelize.py newgame/tools/fx/source-atlas.png`（Pillowが必要）。
4. 薄い生成グローを除去、セル間の混入を切り落とし、縮小、共通8色へ量子化、二値アルファ化。原画のシルエットから4コマを作る。
5. 遙は `BLADE_PROMPT.txt` → `blade-source.png`。`python newgame/tools/fx/pixelize.py newgame/tools/fx/blade-source.png blade` で白銀・淡青の素材を作る。
6. `node newgame/tools/fx/check-latest.cjs` と `node newgame/tools/fx/check-parry.cjs` で技・受け流し・返しの発生経路を検査。

素材は `assets/fx/` の12枚。各256×64（64×64の4コマ）、PNG合計21,121 bytes。ひかり8色、遙8色、同じピクセル密度。
原画のSHA-256と加工情報は `assets/fx/manifest.json` に保存。
遙の原画情報は `assets/fx/blade-manifest.json`。

## 遙の刀（最新版）

- 斬：`blade-slash`、本人から前方へ。実際の間合いを受け取る。0.22秒。
- 突き穿ち：`blade-thrust`、強化された刀の突き。0.22秒。
- 居合：`blade-iai`＋`blade-spin`、抜き打ちと本人の足元の余韻。0.35／0.3秒。
- 飛刃／二連：`blade-flight`、実弾の位置と速度方向。1発／2発。
- 風車／大風車：`blade-spin`、本人中心、実際の効果半径。0.45秒。
- 受け流し：`blade-parry`、相手と本人の間、成功時のみ。0.25秒。
- 返し：`blade-iai`、返しが当たった相手の位置。0.35秒。
- 破邪の一閃：`blade-spin`、本人中心、押し返し半径。0.7秒。
- 居合の溜め：足元の輪を8段階で満たす。実際の `h.zan` を表示するだけ。
- 踏み込み／捌き：移動方向の足元へ短い残光。実際のdashTと速度のみ参照。

二人出撃で弾を処理する手番が替わっても命中素材が混ざらないよう、飛刃か光弾かを描画専用引数で `hurtMon` に渡す。

| 技・出来事 | 素材 | 起点・向き・タイミング |
| --- | --- | --- |
| ルミナ・ストライク | staff-sweep | 本人の杖から前方へ弧、攻撃解放時、0.25秒 |
| スター・スピア | staff-thrust | 本人から狙う方向への細い突き、解放時、0.25秒 |
| ショット／ツインショット | star-bolt | 実際の弾の位置・速度方向。尾は後方。2発なら2個 |
| バスター／ノヴァ | light-burst | 対象地点、解放時。実際の半径を使用、0.7秒 |
| フラッシュ／フラッシュ・ヴェール | repel-ring | 本人中心、押し返し発生時。実際の半径、0.7秒 |
| 敵への命中 | hit-spark | hurtMon の既存命中位置、0.3秒 |
| 通常攻撃の詠唱 | hit-spark | 杖付近の小さい光。変身演出は対象外 |

`combatFx` は既存エフェクトに加えた描画専用メタデータ。
変身、敵の特殊演出、性的な演出は既存の描画に残す。
画像が未読込・失敗の場合は既存Canvas描画へフォールバックする。

全ての素材は1マス24pxの中間Canvasに描画。32方向に回転した結果を最近傍で拡大するため、
広い魔法と小さい弾でピクセル密度が揃う。回転・サイズ・コマ別キャッシュ上限256。
ファイル読込・量子化・画像生成は戦闘フレーム内で行わない。
4コマは生成原画を加工した拡縮コマであり、独立した4枚のAI生成画像ではない。
